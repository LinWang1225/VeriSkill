# 最终答案单位量纲自检：量纲跟踪 → 与所问物理量比对

## 触发情形

解题得到数值结果后须贴单位。典型翻车：公式推导无误、数值正确，但给结果贴了错误的单位（如把电荷结果的单位标成电容单位 F 而非 C、把能量标成功率单位 W 而非 J、把压强标成力单位 N 而非 Pa）。这类错只查誊写/概念混淆，不查数值，但会让 checker 判错。

## 硬约束

1. **量纲跟踪**：从最终使用的公式出发，把每个代入量的单位带入，逐步相乘/相除/相消，算出公式给出的自然单位。不要凭"这个量大概是什么单位"猜——要跟踪。
2. **与所问物理量比对**：题目问的是哪个物理量（电荷、电容、能量、压强…）？该量的标准单位是什么？量纲跟踪得到的单位与该标准单位是否一致？
   - 一致 → 贴该单位。
   - 不一致 → 回查公式是否选对、单位换算是否漏了某步。
3. **题面声明单位与物理量矛盾时**：题面有时声明"答案单位为 X"但 X 与所问物理量的量纲不符（如问电荷却标 F、问能量却标 W）。此时须在解答中显式标注"题面声明单位 X 与所求物理量（量纲 Y）不符；本解按物理量正确单位 Y 报出"，按物理量正确单位贴标。不得默默按题面错误单位贴标、也不得默默按正确单位贴标而不标注矛盾。
4. **常见易混单位对**（提交前逐对排查）：
   - 电荷 C vs 电容 F（F = C/V，不是电荷单位）
   - 能量 J vs 功率 W（W = J/s，不是能量单位）
   - 压强 Pa vs 力 N（Pa = N/m²，不是力单位）
   - 应力 Pa/MPa vs 力 N（应力 = 力/面积）
   - 磁通 Wb vs 磁通密度 T（T = Wb/m²）
   - 浓度/密度 g/cm³ vs 质量 g

## 执行步骤

1. **确定所问物理量**：题目问的是哪个物理量？写出其量纲（如电荷→[I·T]，电容→[I²·T⁴/(M·L²)]）。
2. **量纲跟踪**：从最终公式出发，逐个代入量带入单位，逐步算出公式的自然单位。
   - 例：Q = ε₀·ε_r·A·E，单位 = (F/m)·(无量纲)·(m²)·(V/m) = F·V/m = C/m… 逐步化简到基本单位。
   - 若中间出现不熟悉的单位组合（如 F·V），用定义展开（F = C/V → F·V = C）。
3. **比对**：量纲跟踪得到的单位与第 1 步的物理量单位是否一致？
   - 一致 → 贴该单位，进入第 4 步。
   - 不一致 → 回查公式结构、单位换算、是否漏了某物理量的单位。
4. **题面单位核对**：题面是否声明了答案单位？
   - 声明且与量纲跟踪一致 → 确认，贴该单位。
   - 声明但与量纲跟踪矛盾 → 标注矛盾，按物理量正确单位贴标（第 3 步结果）。
   - 未声明 → 按量纲跟踪结果贴标。
5. **自查（硬门控）**：
   - 我贴的单位是量纲跟踪算出来的还是凭直觉猜的？凭直觉 → 回第 2 步做量纲跟踪。
   - 量纲跟踪的单位与所问物理量的标准单位一致吗？不一致 → 回查公式。
   - 题面声明单位与物理量矛盾时我是否标注了？未标注而默默按某一方贴标 → 回第 4 步补标注。

## 举例（通用占位，非任何具体题目）

用公式 P = f(a, b) 算某量，a 的单位为 U_a、b 的单位为 U_b。量纲跟踪：P 的单位 = U_a · U_b²（假设公式为 P = a·b²）。若题目问的是能量，能量单位为 J，而 U_a·U_b² 化简后 = J → 一致，贴 J。若化简后 = W（功率）→ 不一致，回查公式或单位换算。

判定动作：提交前把最终公式中每个量的单位代入逐步化简，看化简结果是否等于所问物理量的标准单位；不等 → 回查。
