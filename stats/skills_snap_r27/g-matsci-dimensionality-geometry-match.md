# 几何律维度匹配：面现象用二维律，体现象用三维律

## 触发情形

推导中要把"间距 λ"和"体积分数 f"（或数密度 n、阵列周期 d）之间的几何关系代入模型，须先判该现象由几维几何控制。典型翻车：位错在**滑移面**上弯曲绕过粒子，控制量是滑移面内二维平面间距，却套用了三维简单立方点阵的立方律 f ∝ (d/λ)³，使算出的体积分数系统偏低（或偏高）。凡是"在某个面/界上发生的过程"都要警惕维度错配。

## 判别流程

1. **定现象的控制维度**：问自己——该过程发生在体内（三维）还是某个面/界上（二维）？
   - **体现象（三维）**：体形核、体扩散控制的长大、三维点阵数密度、电阻率散射…→ 用三维几何律：数密度 n ∝ 1/λ³，体积分数 f ∝ (d/λ)³。
   - **面现象（二维）**：滑移面上位错绕过粒子（Orowan）、界面/晶界上二维形核、薄膜面内扩散、滑移面上平面阵列…→ 用二维几何律：面数密度 n_s ∝ 1/λ²，面分数 f_s ∝ (d/λ)²；若要换算成体积分数须额外乘以面间距（f = f_s · d/面间距），不要直接把三维立方律当默认。
   - **线现象（一维）**：沿位错线沉积、一维扩散…→ 线密度 n_l ∝ 1/λ。

2. **确认 λ 的物理含义**：λ 是体间距（三维点阵中粒子中心距）还是面间距（滑移面上粒子中心距）？模型公式里的 λ 须与几何律的维度一致。Orowan 公式 Δτ = Gb/λ 中的 λ 是**滑移面上**粒子间距，故配套的 f–λ 关系必须是二维的。

3. **代入前比对**：写下要用的几何关系（f ∝ (d/λ)^n），确认指数 n 等于第 1 步判定的控制维度。n=3 仅用于体现象，n=2 用于面现象，n=1 用于线现象。

4. **自查**：我用的几何律指数是否与现象的控制维度一致？若现象发生在面上（滑移面、界面）而我用了立方律 (d/λ)³ → 维度错配，回第 1 步改用平方律 (d/λ)² 再重新推导。若不确定维度 → 先定性判断"该过程在几维空间中展开"再落笔，不要默认三维。

## 常见易错配对

- **Orowan 绕过强化**：位错在滑移面上弯曲 → 二维 → f–λ 用平方律，不是立方律。
- **切过（cutting）强化**：位错切过体分布粒子 → 视具体机制，但间距仍须与模型所用 λ 的维度一致。
- **晶界/界面二维形核**：面现象 → 二维形核势垒用面面积，不是体体积。
- **体均匀形核**：体现象 → 三维，临界核用球体积。

## 举例（通用占位，非任何具体题目）

滑移面上粒子面数密度 n_s、平均面间距 λ、粒子直径 d：
- 面现象（Orowan）→ n_s ∝ 1/λ²，面分数 f_s ∝ (d/λ)²。若题面要体积分数 f，由 f = f_s · (d/面间距) 换算，不要直接写 f ∝ (d/λ)³。
- 体现象（体分布粒子数密度 n）→ n ∝ 1/λ³，f ∝ (d/λ)³。

判定动作：代入 f–λ 关系前先问"该过程在几维空间中展开"，指数 = 控制维度；滑移面/界面 → 2，体 → 3。默认三维是常见错源，面现象时必须主动降维。
