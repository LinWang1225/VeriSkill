## 题目
Find the solubility of b in a at $860^{\circ} \mathrm{C}$, if $\Omega=-30,000 \mathrm{~J} / \mathrm{mol}$. Given universal gas constant is $R=8.134$.

## 激活技能
- g-sci-model-validity-range
- g-sci-explicit-assumptions
- g-sci-independent-verify
- g-matsci-sigfig-rounding

## 过程
Regular-solution model for the solubility of B in A. With the given sign convention, the regular-solution activity coefficient of B is ln γ_B = -Ω x_A²/(RT); at infinite dilution (x_A→1) γ_B^∞ = exp(-Ω/RT), and the solubility (a_B = γ_B x_B = 1, pure-B reference) gives the textbook dilute formula x_B = exp(Ω/RT). Inputs: Ω = -30000 J/mol, R = 8.134 J/mol/K, T = 860°C = 1133.15 K, so RT = 9217.04, Ω/(RT) = -3.2548, giving the dilute value x_B = 0.0386. Validity check (g-sci-model-validity-range): the dilute/Henry formula is valid only at x_B→0; here the self-consistent activity coefficient at saturation is γ_B = exp((|Ω|/RT)(1-x_B)²), so the exact solvus is ln x_B + (|Ω|/RT)(1-x_B)² = 0. Solving this (brentq, independently re-checked by bisection) gives x_B = 0.05449. The activity correction (1-x_B)² shifts the exponent by ~7.6% and the composition by ~41%, so the dilute model is outside its reliable regime — switched to the exact activity-corrected solvus. Sig figs: Ω=-30,000 and T=860 each carry ≈2 sig figs (ambiguous trailing zeros, conservative), so report 2 sig figs: 0.054.

（执行证据）
Dilute regular-solution formula x_B=exp(Ω/RT)=exp(-30000/(8.134×1133.15))=0.0386. Validity check: exact solvus ln x_B+(|Ω|/RT)(1-x_B)²=0 with |Ω|/RT=3.2548 solved by brentq and confirmed by bisection gives x_B=0.05449. Dilute approximation is ~41% low, so per g-sci-model-validity-range the exact activity-corrected value is reported. Rounded to 2 sig figs: 0.054.

## 最终答案
0.054  (mole fraction of b in a, ≈ 5.4 at%)
