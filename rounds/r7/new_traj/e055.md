## 题目
When the aluminum impurity level in a silicon bar has reached 1 ppb , what would have been the purity of the liquid on the previous pass?The unit of the answer is ppm.

## 激活技能
- g-sci-missing-input-no-fabrication
- g-sci-explicit-assumptions
- g-matsci-sigfig-rounding

## 过程
This is a zone-refining / segregation problem for Al in Si. The governing relation is the equilibrium segregation (distribution) coefficient k = C_s/C_l, where C_s is the impurity concentration in the solid just frozen and C_l is that in the liquid melt it froze from. For k<1 the impurity partitions into the liquid, so the solid is purified relative to the liquid.

The problem does not state k, so I must use the standard tabulated equilibrium segregation coefficient for Al in Si: k0 ≈ 2×10⁻³ = 0.002 (source: standard semiconductor doping tables; Al in Si is a well-known small-k impurity, cf. B≈0.8, P≈0.35, Al≈0.002). This is an external standard value, declared explicitly per g-sci-explicit-assumptions; it is not a fabricated 'tidy' input.

The bar (solid) has reached C_s = 1 ppb Al. This solid froze from the liquid of the previous pass, so
  C_s = k·C_l  →  C_l = C_s / k = 1 ppb / 0.002 = 500 ppb.
Converting to the requested unit ppm: 500 ppb = 500×10⁻⁹ / 10⁻⁶ ppm = 0.5 ppm.

Code check: Cs=1 ppb, k=0.002 → Cl=500.0 ppb = 0.5 ppm.

Sig-fig: inputs are '1 ppb' (1 sig fig) and k≈0.002 (1 sig fig) → report to 1 sig fig → 0.5 ppm.

（执行证据）
Used the segregation relation C_s = k·C_l with the standard equilibrium segregation coefficient for Al in Si, k₀ ≈ 2×10⁻³ (declared external standard value). With C_s = 1 ppb, C_l = 1/0.002 = 500 ppb = 0.5 ppm. Python confirms: 1/0.002 = 500.0 ppb = 0.5 ppm.

## 最终答案
0.5\ \text{ppm}
