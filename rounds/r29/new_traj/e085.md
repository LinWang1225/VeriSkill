## 题目
Determine the expected diffraction angle for the first-order reflection from the (310) set of planes for BCC chromium (Cr) when monochromatic radiation of wavelength 0.0711 nm is used.The unit of the answer is ${\circ}$.

## 激活技能
- g-matsci-param-lookup-consistent-source
- g-matsci-sigfig-rounding
- g-sci-missing-input-no-fabrication

## 过程
BCC reflection rule: h+k+l even → (310) allowed (3+1+0=4). Cr lattice parameter from Callister standard table R=0.125 nm, BCC relation a=4R/√3=0.2887 nm (single consistent source). Cubic d_310=a/√(3²+1²+0²)=0.2887/√10=0.09129 nm. Bragg nλ=2d sinθ with n=1, λ=0.0711 nm → sinθ=0.0711/(2·0.09129)=0.3894 → θ=arcsin(0.3894)=22.92°. Code output: sinθ=0.38943, θ=22.919°. Inputs have 3 sig figs → round to 22.9°.

（执行证据）
Computed a=4(0.125)/√3=0.28868 nm, d_310=0.09129 nm, sinθ=0.0711/(2·0.09129)=0.38943, θ=arcsin(0.38943)=22.92°, rounded to 3 sig figs (limited by λ=0.0711 and R=0.125) gives 22.9°.

## 最终答案
22.9^{\circ}
