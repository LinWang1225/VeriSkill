## 题目
Calculate the heat (in calories and joules) required to raise the temperature of 1 kg of the following materials by $50^{\circ} \mathrm{C}$ : (a) lead, (b) $\mathrm{Si}_3 \mathrm{~N}_4$

Give your answer as a tuple: (lead_heat_cal, Si3N4_heat_cal).The units of each required answer are (cal, cal), respectively.

## 激活技能
- g-matsci-param-lookup-consistent-source
- g-matsci-sigfig-rounding
- g-sci-given-unit-faithful-conversion

## 过程
This is a straightforward heat-capacity calculation Q = m c_p ΔT. The problem does not supply specific heats, so they must be looked up from a single standard source (Callister, Materials Science and Engineering, Table 19.1, Room-Temperature Thermal Properties) — both materials taken from the same table to satisfy param-lookup-consistent-source.

From Callister Table 19.1:
  c_p(Pb)    = 128 J/(kg·K)
  c_p(Si3N4) = 700 J/(kg·K)

Given m = 1 kg, ΔT = 50°C = 50 K (a temperature *difference*, so °C and K increments are identical — faithful unit conversion, no prefix rescaling).

(a) Lead:   Q = (1 kg)(128 J/kg·K)(50 K) = 6400 J = 6400/4.184 = 1529.6 cal
(b) Si3N4:  Q = (1 kg)(700 J/kg·K)(50 K) = 35000 J = 35000/4.184 = 8365.2 cal

Using 1 cal = 4.184 J (Callister convention). Code confirms: 1529.64 cal and 8365.20 cal.

Sigfig check: c_p(Pb)=128 (3 sf), c_p(Si3N4)=700 (table precision ~3 sf), ΔT=50 and m=1 are the weakest inputs (~1–2 sf). Reporting to ~3 significant figures is consistent with the table precision: 1530 cal and 8365 cal.

（执行证据）
Q = m c_p ΔT with c_p from Callister Table 19.1 (single source for both materials): Pb c_p = 128 J/(kg·K), Si3N4 c_p = 700 J/(kg·K). Lead: 1·128·50 = 6400 J = 6400/4.184 = 1529.6 ≈ 1530 cal. Si3N4: 1·700·50 = 35000 J = 35000/4.184 = 8365.2 ≈ 8365 cal.

## 最终答案
(1530, 8365)
