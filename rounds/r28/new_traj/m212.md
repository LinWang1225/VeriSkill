## 题目
The density of BCC iron is $7.882 \mathrm{~g} / \mathrm{cm}^3$, and the lattice parameter is 0.2866 nm when hydrogen atoms are introduced at interstitial positions. Calculate (a) the atomic fraction of hydrogen atoms; and (b) the number of unit cells on average that contain hydrogen atoms. Give your answer as a tuple: (atomic_fraction_of_hydrogen, number_of_unit_cells_on_average_that_contain_hydrogen_atoms.).The units of each required answer are (, ), respectively.

## 过程
BCC Fe has Z=2 Fe atoms per unit cell (conventional cubic cell, V=a³). With interstitial H, the unit cell still holds 2 Fe atoms plus n_H H atoms. The density relation is ρ·V·N_A = n_Fe·A_Fe + n_H·A_H. Convert a = 0.2866 nm = 2.866×10⁻⁸ cm (faithful SI-prefix conversion), V = a³ = 2.3541×10⁻²³ cm³. Using Callister atomic weights A_Fe = 55.85 g/mol, A_H = 1.008 g/mol, N_A = 6.022×10²³: ρ·V·N_A = 7.882 × 2.3541×10⁻²³ × 6.022×10²³ = 111.739 g/mol-equiv per cell; n_Fe·A_Fe = 2×55.85 = 111.700. Thus n_H = (111.739 − 111.700)/1.008 = 0.03894 H atoms per unit cell. (a) Atomic fraction of H = n_H/(n_Fe+n_H) = 0.03894/(2+0.03894) = 0.0191. (b) Fraction of unit cells containing an H atom ≈ n_H (dilute, one interstitial per cell), so on average 1/n_H = 25.7 unit cells per H-containing cell. Inputs have 4 sig fig, but the result hinges on a small difference of near-equal numbers, so I report 3 sig fig.

（执行证据）
Density relation ρ·V·N_A = n_Fe·A_Fe + n_H·A_H with BCC Z=2 gives ρ·V·N_A = 111.739 and 2·A_Fe = 111.700, so n_H = 0.03894 H atoms/cell. Atomic fraction x_H = n_H/(2+n_H) = 0.0191. Reciprocal 1/n_H = 25.7 unit cells on average per H-bearing cell.

## 最终答案
(0.0191, 25.7)
