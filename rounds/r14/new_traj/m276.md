## 题目
Find the solubility of b in a at $860^{\circ} \mathrm{C}$, if $\Omega=-30,000 \mathrm{~J} / \mathrm{mol}$. Given universal gas constant is $R=8.134$.

## 激活技能
- g-matsci-regular-solution-sign-convention
- g-sci-explicit-assumptions

## 过程
Ω = −30000 J/mol < 0 → attractive A–B interaction, complete miscibility, no miscibility gap; per the sign-convention skill the solvus equation ln x_B + Ω(1−x_B)²/(RT)=0 has no physical root in (0,1) here, so the dilute-solution formula x_B = exp(Ω/RT) with the SIGNED Ω is the intended method (not |Ω|, not the solvus equation). T = 860°C = 860+273 = 1133 K (题面给定口径); R = 8.134 J/mol·K (题面给定). Exponent = −30000/(8.134×1133) = −3.25527. x_B = exp(−3.25527) = 0.038570. Code output: 1133 → 0.038570 (3.857%); with 273.15 → 0.038587 (3.859%), negligibly different. Report mole fraction ≈ 0.0386.

（执行证据）
Sign check: Ω=−30000<0 ⇒ use dilute formula exp(Ω/RT) with signed Ω, not solvus equation and not |Ω|. Exponent = −30000/(8.134×1133) = −3.25527. exp(−3.25527) = 0.038570 ≈ 0.0386.

## 最终答案
x_B \approx 0.0386 \; (\text{mole fraction, } \approx 3.86\%)
