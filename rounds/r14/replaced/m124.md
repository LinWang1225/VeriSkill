## 题目
The fatigue data for a steel alloy are given as follows:

| Stress Amplitude [MPa (ksi)] | Cycles to Failure |
| :--: | :--: |
| $470(68.0)$ | $10^{4}$ |
| $440(63.4)$ | $3 \times 10^{4}$ |
| $390(56.2)$ | $10^{5}$ |
| $350(51.0)$ | $3 \times 10^{5}$ |
| $310(45.3)$ | $10^{6}$ |
| $290(42.2)$ | $3 \times 10^{6}$ |
| $290(42.2)$ | $10^{7}$ |
| $290(42.2)$ | $10^{8}$ |

(a) What is the fatigue limit for this alloy?
(b) Determine fatigue lifetimes at stress amplitudes of 415 MPa (60,000 psi).
(c) Estimate fatigue strengths at $2 \times 10^{4}$ and $6 \times 10^{5}$ cycles.\

Give your answer as a tuple (fatigue limit, fatigue lifetimes of 415 MPa, fatigue strengths at $2 \times 10^{4}$ cycles, fatigue strengths at $6 \times 10^{5}$ cycles).The units of each required answer are (MPa, cycles, MPa, MPa), respectively.

## 激活技能
- g-matsci-sn-fatigue-loglog-interpolation
- g-matsci-sigfig-rounding

## 过程
(a) Fatigue limit = stress at which the S-N curve becomes horizontal. The table shows S=290 MPa yielding failure at 3×10^6, 10^7, and 10^8 cycles (constant stress, life unbounded), so the fatigue limit is 290 MPa. (b) For S=415 MPa, bracket between (440 MPa, 3×10^4) and (390 MPa, 10^5). Local log-log linear interpolation solving for N: log N = log(3×10^4) + [log(10^5)−log(3×10^4)]·[log(415)−log(440)]/[log(390)−log(440)] = 53787 ≈ 5.38×10^4 cycles. (c) Fatigue strength at 2×10^4 cycles: bracket (470,10^4)–(440,3×10^4); log S = log(470)+[log(440)−log(470)]·[log(2×10^4)−log(10^4)]/[log(3×10^4)−log(10^4)] = 450.84 ≈ 451 MPa. Fatigue strength at 6×10^5 cycles: bracket (350,3×10^5)–(310,10^6); log S = log(350)+[log(310)−log(350)]·[log(6×10^5)−log(3×10^5)]/[log(10^6)−log(3×10^5)] = 326.38 ≈ 326 MPa. Each interpolation used only the two surrounding points (no whole-curve regression). Sigfigs: ksi column gives 3 sig figs, so report 3. Code outputs: b=53787.5, c1=450.842, c2=326.380.

（执行证据）
Fatigue limit read from the flat 290 MPa tail (3×10^6 to 10^8 cycles all at 290 MPa). Local two-point log-log interpolation gave N(415 MPa)=53787≈5.38×10^4, S(2×10^4)=450.84≈451 MPa, and S(6×10^5)=326.38≈326 MPa; each value lies between its bracketing data points, confirming consistency.

## 最终答案
(290\ \text{MPa},\ 5.38\times10^{4}\ \text{cycles},\ 451\ \text{MPa},\ 326\ \text{MPa})
