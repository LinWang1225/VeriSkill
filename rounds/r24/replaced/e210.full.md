## 题目
Calculate the length of the Burgers vector in copper. The lattice parameter of copper $(\mathrm{Cu})$ is 0.36151 nm . The close-packed directions.The unit of the answer is nm.

## 激活技能
- g-matsci-sigfig-rounding
- g-sci-explicit-assumptions

## 过程
Copper has an FCC crystal structure. In FCC, dislocations glide on the close-packed {111} planes along the close-packed ⟨110⟩ directions, and the Burgers vector magnitude is b = a/√2, where a is the lattice parameter. Given a = 0.36151 nm (5 significant figures). Computed b = 0.36151/√2 = 0.25562617... nm. Per sigfig-rounding skill, the input has 5 sig figs so the final answer is rounded to 5 sig figs: 0.25563 nm. The only external fact used (Cu is FCC) is standard crystallographic knowledge; the lattice parameter itself is given in the problem statement, so unit alignment (nm) is satisfied.

（执行证据）
Cu is FCC → Burgers vector along ⟨110⟩ close-packed direction → b = a/√2. With a = 0.36151 nm, Python gives b = 0.25562617... nm, which rounds to 0.25563 nm at 5 significant figures.

## 最终答案
0.25563 nm
