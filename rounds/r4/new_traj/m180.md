## 题目
A high-strength, low-alloy steel is strengthened by precipitates of VC. If the diameter of the particles is 50 nm, what volume percent particles would be required to increase the strength by 100 MPa? For iron, $G = 80$ GPa, and the atomic diameter is 0.248 nm.The unit of the answer is %.

## 激活技能
- g-sci-explicit-assumptions.md
- g-sci-independent-verify.md
- g-matsci-sigfig-rounding.md

## 过程
BCC Fe Burgers vector b = a√3/2 = 2R = atomic diameter = 0.248 nm (so the given atomic diameter is exactly b). Orowan equation Δσ = Gb/(λ−d) with d = 50 nm, Δσ = 100 MPa, G = 80 GPa gives λ = d + Gb/Δσ, hence λ/d = 1 + Gb/(d·Δσ) = 1 + (80×0.248)/(50×0.1) = 1 + 3.968 = 4.968. For a cubic array of spherical precipitates, volume fraction f = (πd³/6)/λ³ = π/[6(λ/d)³] = π/[6·(4.968)³] = π/735.6 = 4.270×10⁻³. Vol% = 0.4270%. Independent re-derivation via f = π/{6[1+Gb/(d·Δσ)]³} gives the identical 0.4270%. Inputs are ~2 s.f. → report 0.43%.

（执行证据）
b = 0.248 nm (= atomic diameter for BCC Fe). λ/d = 1 + Gb/(d·Δσ) = 4.968, so λ = 248.4 nm. f = π/[6·(4.968)³] = 4.270×10⁻³ → 0.427 vol%, rounded to 2 s.f. = 0.43%.

## 最终答案
0.43
