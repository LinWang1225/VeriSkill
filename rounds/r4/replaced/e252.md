## 题目
After finding the electrical conductivity of cobalt at $0^{\circ} \mathrm{C}$, we decide we would like to double that conductivity. To what temperature must we cool the metal? Give your answer as the value of required_temperature_degC.The unit of the answer is °C.

## 激活技能
- g-sci-explicit-assumptions
- g-sci-independent-verify
- g-matsci-sigfig-rounding

## 过程

For a metal, electrical resistivity follows the linear law ρ(T)=ρ_ref[1+α_ref(T−T_ref)], and conductivity σ=1/ρ. Cobalt's temperature coefficient of resistivity is α=0.00604 °C⁻¹ at the standard table reference T_ref=20 °C (Callister, Materials Science, Table of temperature coefficients; this is the only external value needed since the resistivity itself cancels). Doubling the conductivity at 0 °C means halving the resistivity: σ(T)=2σ(0) ⟹ ρ(T)=ρ(0)/2. Using the 20 °C-referenced law for both ρ(T) and ρ(0): ρ₂₀[1+α(T−20)] = ρ₂₀[1+α(0−20)]/2 = ρ₂₀(1−20α)/2. Solving, 1+α(T−20)=(1−20α)/2 ⟹ T = 20 − (1+20α)/(2α). Substituting α=0.00604: T = 20 − (1+0.1208)/(0.01208) = 20 − 92.784 = −72.78 °C. Independent verification: a bisection root-find on σ(T)−2σ(0)=0 (using a different placeholder ρ₂₀ and a numerical solver, not the closed form) gives T=−72.7815 °C with σ(T)/σ(0)=2.000, matching the analytic result. Assumption: the linear resistivity law is extrapolated below 0 °C; this is the standard textbook model for this problem (the true Bloch–Grüneisen law would deviate far below the Debye temperature, but the problem intends the linear approximation). Sig figs: α has 3 significant figures, so the answer is reported to 3 sig figs.
