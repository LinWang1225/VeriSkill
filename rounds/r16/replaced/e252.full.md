## 题目
After finding the electrical conductivity of cobalt at $0^{\circ} \mathrm{C}$, we decide we would like to double that conductivity. To what temperature must we cool the metal? Give your answer as the value of required_temperature_degC.The unit of the answer is °C.

## 激活技能
- g-sci-model-validity-range
- g-sci-explicit-assumptions
- g-sci-independent-verify
- g-matsci-sigfig-rounding

## 过程
The problem follows a prior part that found σ of cobalt at 0°C using the linear resistivity model ρ(T)=ρ_ref[1+α(T−T_ref)] with the standard Callister reference values for cobalt: α = 0.00604 (°C)⁻¹ at T_ref = 20°C (Table 18.2); ρ(20°C)=6.24×10⁻⁸ Ω·m (Table 18.1). Doubling conductivity means halving resistivity: σ(T)=2σ(0°C) ⟺ ρ(T)=ρ(0)/2. With ρ(0)=ρ20(1−20α) and ρ(T)=ρ20(1+α(T−20)):
  1+α(T−20) = (1−20α)/2  →  T = 10 − 1/(2α).
Note ρ20 cancels, so the answer depends only on α. Substituting α=0.00604: T = 10 − 1/0.01208 = 10 − 82.7815 = −72.7815°C. Independent numerical check (using ρ20 explicitly, solving for T giving 2σ(0)) reproduces −72.7815°C and confirms σ(T)/σ(0)=2.000. Sigfig: α has 3 sig figs → report 3 sig figs: −72.8°C.
Model-validity caveat (g-sci-model-validity-range): T≈200 K is below cobalt's Debye temperature Θ_D≈385 K, where strictly Bloch–Grüneisen (ρ∝T⁵) replaces the linear law. However, the textbook exercise explicitly uses the linear model throughout (part a already applied it at 0°C=273 K, also below Θ_D), so the linear model is the intended one; the result is a textbook linear-model extrapolation.

（执行证据）
Using ρ(T)=ρ20[1+α(T−20)] with cobalt α=0.00604 (°C)⁻¹ at 20°C, doubling σ(0°C) means ρ(T)=ρ(0)/2, which reduces to T=10−1/(2α)=10−1/0.01208=−72.78°C. The ρ20 reference cancels, so only α enters. Independent numerical re-solution with ρ20=6.24×10⁻⁸ Ω·m gives the same −72.78°C with σ(T)/σ(0)=2.000. Rounded to 3 sig figs (limited by α): −72.8°C.

## 最终答案
-72.8
