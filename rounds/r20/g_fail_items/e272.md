## 题目
Consider the freezing of pure aluminum. Estimate the temperature gradient in the solid near the liquid-solid interface if the interface moves at $5 \mathrm{~mm} / \mathrm{min}$. For aluminum, the thermal conductivity $k=4.8 \mathrm{Jm} /(\mathrm{Ks})$, the latent heat of freezing is $397 \mathrm{~kJ} /$ kg , and the density is $2.7 \mathrm{mg} / \mathrm{m}^3$. Give your answer as the value of temperature_gradient.The unit of the answer is K/m.

## 过程

This is a Stefan solidification problem. At a planar solid–liquid interface moving at velocity v, the latent heat released per unit interface area per unit time (ρ L v) must be conducted away through the solid by Fourier conduction (k dT/dx). Heat balance:

  k (dT/dx) = ρ L v  ⇒  dT/dx = ρ L v / k.

Unit corrections (noted explicitly, not silently substituted):
- Density is written '2.7 mg/m³'. Taken literally (2.7×10⁻⁶ kg/m³) this is ~10⁹ below aluminum's real density and gives a nonsensical gradient ~10⁻⁵ K/m. Standard aluminum density is 2.7 g/cm³ = 2700 kg/m³ = 2.7 Mg/m³; the symbol is a case typo (mg → Mg). Using ρ = 2700 kg/m³ (source: CRC/Callister standard value for Al).
- k = 4.8 Jm/(Ks) is read as thermal conductivity 4.8 W/(m·K) = 4.8 J/(s·m·K); use given numerical value.

Inputs:
  v = 5 mm/min = 5×10⁻³/60 = 8.3333×10⁻⁵ m/s
  ρ = 2700 kg/m³, L = 397×10³ J/kg, k = 4.8 W/(m·K)

  dT/dx = (2700)(397000)(8.3333×10⁻⁵)/4.8 = 18609.375 K/m.

Independent check (different path — energy per unit volume × growth rate = flux): in dt a slab of thickness v·dt freezes, releasing ρL·v·dt per area = 2700·397000·8.333e-5 = 8.93×10⁴ W/m²; conducted flux k·∇T = 4.8·18609 = 8.93×10⁴ W/m². Match ✓. Limit checks: v→0 ⇒ ∇T→0 ✓; k→∞ ⇒ ∇T→0 ✓; linear in v ✓.

Sigfig: weakest inputs (5, 4.8, 2.7) → n_min = 2 ⇒ report 1.9×10⁴ K/m.
