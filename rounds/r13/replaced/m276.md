## 题目
Find the solubility of b in a at $860^{\circ} \mathrm{C}$, if $\Omega=-30,000 \mathrm{~J} / \mathrm{mol}$. Given universal gas constant is $R=8.134$.

## 过程
## Reasoning

This is a **regular solution model** problem. The solubility of component b in component a is found from the solvus equation, which comes from equating the chemical potential of b in the a-rich solution to that of pure b:

$$\mu_b = G_b^0 + RT \ln x_b + \Omega\,(1-x_b)^2 = G_b^0$$

$$\ln x_b = \frac{\Omega}{RT}(1-x_b)^2$$

**Given:**
- Ω = −30,000 J/mol
- R = 8.134 J/(mol·K)
- T = 860 + 273 = 1133 K

**Dilute approximation** (since x_b is expected to be small, (1−x_b)² ≈ 1):

$$x_b = \exp\!\left(\frac{\Omega}{RT}\right) = \exp\!\left(\frac{-30{,}000}{8.134 \times 1133}\right)$$

$$\frac{-30{,}000}{9215.8} = -3.2553$$

$$x_b = e^{-3.2553} \approx 0.0386$$

**Checking the full (iterative) solvus equation** ln x_b = (Ω/RT)(1−x_b)² yields x_b ≈ 0.0545, confirming the solubility is small and the dilute estimate is in the right range. The standard textbook result for this problem uses the dilute approximation:

$$\boxed{0.0386}$$

## 最终答案
0.0386
