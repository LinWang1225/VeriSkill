## 题目
Determine the minimum radius of an atom that will just fit into(a) the tetrahedral interstitial site in FCC nickel; and(b) the octahedral interstitial site in BCC lithium. Give your answer as a tuple: (tetrahedral_site_radius_FCC_Ni, octahedral_site_radius_BCC_Li).The units of each required answer are (Å, Å), respectively.

## 激活技能
- g-matsci-unitcell-formula-unit-scaling
- g-matsci-sigfig-rounding
- g-sci-explicit-assumptions

## 过程
For an interstitial atom that 'just fits', its radius r equals (distance from interstitial-site center to nearest host-atom center) minus the host atomic radius R. I derived the site-radius ratios from the unit-cell geometry (no memorized ratio needed).

(a) FCC Ni, tetrahedral site at (1/4,1/4,1/4). Nearest host atoms (the tetrahedron vertices) are at distance a√3/4. For FCC, R = a√2/4. Thus r_tet = a(√3−√2)/4 and r_tet/R = (√3−√2)/√2 = 0.22474. Using the standard room-temperature lattice parameter of Ni, a_Ni = 0.3524 nm (Callister, Table of lattice parameters / Appendix; equivalent to R_Ni = 0.1246 nm): r_tet = 0.3524(√3−√2)/4 nm = 0.02800 nm = 0.280 Å.

(b) BCC Li, octahedral site at edge center (1/2,0,0). The two limiting host atoms are the adjacent corner atoms at distance a/2 (the four equatorial body-center neighbors lie farther, at a/√2). For BCC, R = a√3/4. Thus r_oct = a(2−√3)/4 and r_oct/R = (2−√3)/√3 = 0.15470. Using a_Li = 0.3509 nm (Callister; equivalent to R_Li = 0.152 nm): r_oct = 0.3509(2−√3)/4 nm = 0.02351 nm = 0.235 Å.

Python evaluation confirmed both the ratio forms and the direct lattice-parameter expressions: r_tet_Ni = 0.28001 Å, r_oct_Li = 0.23506 Å. Inputs are given to 3–4 significant figures, so the result is reported to 3 significant figures with standard rounding.

（执行证据）
Derived r_tet/R = (√3−√2)/√2 = 0.22474 for the FCC tetrahedral site and r_oct/R = (2−√3)/√3 = 0.15470 for the BCC octahedral site from unit-cell geometry. Using a_Ni = 0.3524 nm (FCC) and a_Li = 0.3509 nm (BCC), Python gave r_tet_Ni = 0.28001 Å and r_oct_Li = 0.23506 Å. Rounded to 3 significant figures: (0.280 Å, 0.235 Å).

## 最终答案
(0.280\ \text{Å},\ 0.235\ \text{Å})
