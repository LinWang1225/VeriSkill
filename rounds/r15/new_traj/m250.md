## 题目
Calculate the electrical conductivity of nickel at $-50^{\circ} \mathrm{C}$ and at $+500^{\circ} \mathrm{C}$. Give your answer as a tuple: (electrical_conductivity_at_minus_50C, electrical_conductivity_at_plus_500C).The units of each required answer are (ohm⁻¹·cm⁻¹, ohm⁻¹·cm⁻¹), respectively.

## 过程
The problem statement gives no numeric data, so the required inputs must be taken from standard property tables (source stated, not fabricated): nickel room-temperature resistivity rho_20 = 6.99e-8 Ohm.m <=> sigma_20 = 1.43e7 (Ohm.m)^-1 = 1.43e5 (Ohm.cm)^-1 (Callister, room-temp resistivity table), and temperature coefficient of resistivity alpha = 0.006 (degC)^-1 (Callister), reference T0 = 20 degC. Linear resistivity model: rho(T) = rho_20[1 + alpha*(T - T0)], so sigma(T) = sigma_20 / [1 + alpha*(T - T0)].

At T = -50 degC: factor = 1 + 0.006*(-50-20) = 1 - 0.42 = 0.58; sigma = 1.43e5 / 0.58 = 2.4655e5 (Ohm.cm)^-1.
At T = +500 degC: factor = 1 + 0.006*(500-20) = 1 + 2.88 = 3.88; sigma = 1.43e5 / 3.88 = 3.6856e4 (Ohm.cm)^-1.

Model-validity check (g-sci-model-validity-range): the linear resistivity approximation is the textbook-intended model here; both evaluated points give physical (positive, finite) resistivities (0.58*rho_20 and 3.88*rho_20), so no nonphysical value is produced. Caveat: -50 degC (223 K) lies below nickel's Debye temperature (~375 K) and 500 degC crosses the Curie point (~358 degC), so the linear model is an extrapolation in those regions; per the skill's textbook-use clause the linear result is reported with this annotation rather than discarded, since no nonlinear (Bloch-Grungeisen / magnetic) parameters are supplied. Sig figs: limited by alpha = 0.006 (and sigma_20 = 1.43, 3 sf); report 3 sf -> (2.47e5, 3.69e4) (Ohm.cm)^-1.

（执行证据）
Using rho(T)=rho_20[1+alpha(T-T0)] with nickel standard values sigma_20=1.43e5 (Ohm.cm)^-1 and alpha=0.006 /degC at T0=20 degC. At -50 degC the factor is 0.58 giving sigma=2.4655e5; at +500 degC the factor is 3.88 giving sigma=3.6856e4 (Ohm.cm)^-1. Rounded to 3 significant figures: (2.47e5, 3.69e4) Ohm^-1.cm^-1.

## 最终答案
(2.47\times10^{5},\ 3.69\times10^{4})\ \Omega^{-1}\cdot\mathrm{cm}^{-1}
