## 题目
The fatigue data for a steel alloy are given as follows:

| Stress Amplitude [MPa (ksi)] | Cycles to Failure |
| :--: | :--: |
| $470(68.0)$ | $10^{4}$ |
| $440(63.4)$ | $3 \times 10^{4}$ |
| $390(56.2)$ | $10^{5}$ |
| $350(51.0)$ | $3 \times 10^{5}$ |
| $310(45.3)$ | $10^{6}$ |
| $290(42.2)$ | $3 \times 10^{6}$ |
| $290(42.2)$ | $10^{7}$ |
| $290(42.2)$ | $10^{8}$ |

(a) What is the fatigue limit for this alloy?
(b) Determine fatigue lifetimes at stress amplitudes of 415 MPa (60,000 psi).
(c) Estimate fatigue strengths at $2 \times 10^{4}$ and $6 \times 10^{5}$ cycles.\

Give your answer as a tuple (fatigue limit, fatigue lifetimes of 415 MPa, fatigue strengths at $2 \times 10^{4}$ cycles, fatigue strengths at $6 \times 10^{5}$ cycles).The units of each required answer are (MPa, cycles, MPa, MPa), respectively.

## 激活技能
- g-matsci-sn-fatigue-loglog-interpolation
- g-matsci-sigfig-rounding

## 过程
This is a Callister-style discrete S-N fatigue problem for a steel alloy, so per g-matsci-sn-fatigue-loglog-interpolation I work on a semi-log S-log N plot (S linear, log N logarithmic), NOT a log-log Basquin fit.

(a) Fatigue limit: the low-stress end becomes horizontal — S = 290 MPa at N = 3e6, 1e7, 1e8. The plateau value is the fatigue/endurance limit: S_e = 290 MPa. These plateau points are excluded from the finite-life line.

(b,c) Finite-life region: fit a single best straight line S = a + b·log N through the five finite-life points (470,1e4),(440,3e4),(390,1e5),(350,3e5),(310,1e6). The 290 MPa point at 3e6 is the knee (plateau begins; the extrapolated line predicts ~271 MPa there, so it lies above the line, confirming it belongs to the fatigue-limit regime, not the finite-life line). Least-squares gives S = 801.421 - 82.034·log N. Residuals are all within ±6 MPa, confirming linearity.

(b) At S = 415 MPa (> S_e, so finite life): log N = (415-801.421)/(-82.034) = 4.7105 → N = 5.13e4 cycles.
(c) At N = 2e4: log N = 4.3010 → S = 801.421 - 82.034·4.3010 = 448.6 MPa → 449 MPa.
    At N = 6e5: log N = 5.7782 → S = 801.421 - 82.034·5.7782 = 327.4 MPa → 327 MPa.

All asked points lie in the finite-life range (S > 290 MPa and N below the knee), so the linear model is valid here (g-sci-model-validity-range satisfied). Input stresses are given to 3 sig figs (e.g., 68.0, 63.4 ksi), so per g-matsci-sigfig-rounding I report 3 sig figs.

（执行证据）
Fatigue limit read from the horizontal plateau at 290 MPa (3 points at N=3e6,1e7,1e8 all give 290 MPa). Least-squares S-log N line through the 5 finite-life points: S = 801.421 - 82.034·log N (residuals ≤6 MPa). Solving: N(415 MPa)=5.13e4 cycles; S(2e4)=448.6→449 MPa; S(6e5)=327.4→327 MPa.

## 最终答案
(290 MPa, 5.13×10^4 cycles, 449 MPa, 327 MPa)
