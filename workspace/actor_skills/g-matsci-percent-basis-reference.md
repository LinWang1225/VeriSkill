# 百分比/比率量的分母（参考基准）选择

## 触发情形

题目问一个百分比或比率量：凝固收缩率（percent shrinkage during solidification）、缩孔率、孔隙率（porosity）、冷加工率（percent cold work）、致密度（packing fraction / relative density）、体积变化率、质量分数…。这类量的数值 = (差量 / 参考) × 100，**分母取哪个量由该量的物理定义决定**，不是"手边刚好算出哪个体积就用哪个"。典型翻车：铸件凝固收缩率把名义模腔/外廓体积当分母，算出"占模腔的比例"，而定义要求的基准是实际已凝固出的固态金属体积——分母选错会系统低估（或高估）收缩率，且数值看起来"合理"难以自查发现。

## 硬约束

落笔算百分比前，必须先写一行"分母 = X，依据：该量的定义为 ……"，再代入。分母不得是"默认拿名义/外廓/初始体积"——必须能讲清为什么是它而不是另一个候选体积。

## 常见量的正确基准（按定义）

- **凝固收缩率 / percent shrinkage during solidification**：分母 = 已凝固固态金属体积 V_solid = m/ρ（m 为铸件室温实测质量，ρ 为该金属固态室温密度）。分子 = 缩孔体积 = V_nominal − V_solid（V_nominal 为名义外廓/模腔体积）。即 shrinkage = (V_nominal − V_solid) / V_solid × 100。**不是** /V_nominal——V_nominal 是模腔体积，含了将要成为缩孔的那部分空隙，拿它当基准把收缩率定义成了"占模腔比例"，与"凝固时固态金属体积收缩了多少"的物理含义不符。
- **孔隙率 porosity**：分母 = 含孔的总体积（名义外廓体积），分子 = 孔洞体积。注意孔隙率与凝固收缩率基准不同——孔隙率是"总体积里空了多少"，凝固收缩率是"固态金属体积比名义少了多少"。两者分母不同，不要混用。
- **冷加工率 percent cold work**：分母 = 原始截面积 A₀，分子 = A₀ − A_f（变形后截面积）。以原始为基准，不是变形后。
- **致密度 / relative density**：分母 = 理论致密固体密度（或理论晶格体积），分子 = 实测密度。以理论致密态为基准。
- **体积变化率（一般）**：明确题意是"相对于初态"还是"相对于终态"还是"相对于某参考态"，分母随之而定。

## 执行步骤

1. **识别所问量的定义**：题目问的是哪个百分比量？写出它的标准定义式（量 = 分子/分母），确认分母是哪个物理量。若题面用了术语（"percent shrinkage"、"porosity"、"percent cold work"），按该术语的标准定义定分母，不要凭字面猜。
2. **列出候选体积/面积/质量**：把题目里出现的所有体积（名义外廓、实测固态、模腔、缩孔…）列出来，逐个标注"这是 V_nominal / V_solid / V_cavity / …"。
3. **据定义选分母**：按上面"常见量的正确基准"或该量的标准定义，从候选里选出正确的分母，写一行"分母 = X，因为 <量名> 的定义为 ……"。
4. **算分子**：分子 = 与分母同参考的差量（收缩率分子 = V_nominal − V_solid；孔隙率分子 = V_cavity；冷加工率分子 = A₀ − A_f）。
5. **独立验证分母选择**：换一条路径确认分母——查教材/手册该术语的定义式，或取极限（若固态体积 → 名义体积，即无收缩，收缩率应 → 0；若分母选错，极限行为会不对）。分母选择本身是模型选择，不能用"数值代回原式"验证。
6. **自查（硬门控）**：报出百分数前问自己——
   - 我写的分母是哪个体积/面积/质量？它和该量的物理定义一致吗？
   - 我是不是因为"V_nominal 先算出来、方便"才拿它当分母？若是 → 回第 3 步按定义重选。
   - 同一组数据下，换另一个合理的分母会得到不同数值——我能讲清为什么选的不是那个吗？讲不清 → 回第 1 步查定义。

## 举例（通用占位，非任何具体题目）

铸件名义外廓体积 V_n、室温实测质量 m、固态密度 ρ。V_s = m/ρ 为已凝固固态金属体积，V_c = V_n − V_s 为缩孔体积。
- 问"凝固收缩率"→ (V_c / V_s) × 100，分母是 V_s（固态金属体积），不是 V_n。
- 问"孔隙率"→ (V_c / V_n) × 100，分母是 V_n（含孔总体积）。
两个百分比同一组数据但分母不同，先据术语定义定分母再算，不要默认用 V_n。
