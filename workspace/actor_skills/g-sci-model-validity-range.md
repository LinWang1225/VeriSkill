# 模型适用范围：外推前先确认落在有效区内

## 触发情形

解题用到一阶/线性化/经验近似公式（线性电阻率 ρ=ρ_ref[1+α(T−T_ref)]、Hooke 定律、理想气体、Sieverts 定律、Arrhenius 单段外推…），待求点远离该近似的参考点或落在近似失效的物理区间内。典型翻车：把室温附近成立的一阶线性关系外推到偏离参考点很远的温区（如低于 Debye 温度，此时电阻率按声子高次幂变化），得到非物理结果（如预测电阻率 = 0 或负值）却未察觉。

## 常见模型的有效区

- **线性电阻率** ρ=ρ_ref[1+α(T−T_ref)]：仅在 T_ref 附近且 T > Debye 温度 Θ_D 时成立；T < Θ_D 时电阻率 ∝ T⁵（Bloch–Grüneisen），线性近似失效。**磁相变（铁磁–顺磁转变，居里点 T_C）是另一条硬边界**：跨过 T_C 时 α 不连续变化（铁磁区与顺磁区 α 不同），单一 α 直线不能同时跨两区。铁磁金属（Fe、Ni、Co）的电阻率在 T_C 附近有反常贡献（s–d 散射、磁子散射），线性公式在 T_C 两侧须分别取该区的 α，或改用非线性/分区模型。判据：待求温区跨过 T_C（如一端在铁磁区、另一端在顺磁区）→ 不得用一条恒 α 直线贯穿，须分温区各取 α 或用实测 ρ–T 数据分段/非线性拟合。
- **Hooke 定律** σ=Eε：仅在弹性极限内（ε 远小于屈服应变）；大应变须用非线性弹性/塑性模型。
- **理想气体** pV=nRT：低压高温；高压低温须 virial 或状态方程修正。
- **Arrhenius 单段外推** ln D = ln D₀ − Q/RT：在拟合温区内可靠，跨相变或外推到远低于拟合区间的温度时须谨慎。
- **Dilute-solution / Henry / Sieverts**：仅溶质浓度→0 的极限；高浓度须用活度修正。**Regular-solution 特别注意**：判断是否超出稀溶液适用范围前，必须先检查交互参数 Ω 的符号——Ω<0（吸引交互）对应完全互溶、不存在 miscibility gap、无有限溶解度极限（x_B=1），稀溶公式 x_B=exp(−Ω/RT) 给出 >1 的非物理值正是"完全互溶"的信号，不得以"稀溶液近似不够精确"为由切换到 solvus 方程（详见 g-matsci-regular-solution-sign-convention）。只有 Ω>0 且 x_B 不小时才考虑改用 solvus 方程，且全程保留有符号 Ω，禁止取 |Ω|。

## 执行步骤

0. **硬门控（代入前必做，先于一切合理化判断）**：写下待求点 T_target（或对应压强/应变/浓度）与该材料的所有物理边界（Θ_D、T_C、T_m、弹性极限…）。逐条比对：
   - T_target < Θ_D（电阻率线性律）→ 线性电阻率公式**禁止使用**。**不得**再检查"结果是否为正/有限/量级合理"——一旦门控判定 T_target < Θ_D，"结果为正"检查即作废，它是已知翻车的合理化陷阱（线性律在 T<Θ_D 给出的正值只是公式数学延拓，不具物理意义）。直接走第 3 步 (a) 换模型或 (c) 声明无法严格求解。
   - 待求温区跨居里点 T_C（一端 < T_C < 另一端）→ 单一 α 直线**禁止使用**，须分温区各取 α 或用非线性模型。
   - 待求点超出弹性极限 / 跨相变 / 超出稀溶液极限 → 对应简化模型**禁止使用**。
   - 门控全过（待求点在有效区内、未跨任何边界）→ 进入第 1 步正常求解。
   - **门控失败时的禁令**：不得以"教科书预期模型 / intended model / textbook exercise / 全题在该模型框架内 / 无非线性参数 supplied / 结果仍为正且有限"等理由绕过门控——这些均不是有效辩护，与"承认但回避"翻车签名同罪。

1. **定模型与有效条件**：写下所用公式及其适用条件（温区、压强范围、应变范围、浓度区间…）。
2. **检查待求点**：把待求温度/压强/应变/浓度与有效条件比对。关键判据：
   - 偏离参考点的幅度是否在线性保持的尺度内（如 |T−T_ref|/T_ref 是否小）？
   - 是否跨过物理边界（低于 Θ_D、跨过居里点 T_C 等磁/结构相变、低于熔点进入液相、超出弹性极限、超出稀溶液极限）？
   - 模型在待求点是否给出非物理值（负电阻率、负浓度、超光速）？
3. **超出有效区时**：
   - (a) 换用该区有效的模型（低温电阻率用 Bloch–Grüneisen / Matthiessen 定则 ρ=ρ_residual+ρ_BG·T⁵；大应变用非线性弹性；高浓度用活度）。
   - (b) **仅当**题面明确要求用该简化模型（教科书题预期用法）**且**模型在待求点仍给出物理上合理的结果（正值、有限、量级合理）**且待求点未跨过任何已知物理边界**（未低于 Θ_D、未跨居里点 T_C、未超出弹性极限、未跨相变…）→ 按要求算，但在答案旁显式标注"该模型在待求点属外推，结果为近似，严格解须用 XXX 模型"。**跨过任一物理边界 → (b) 自动不可用，须走 (a) 或 (c)**，不得以"结果仍为正"为由启用 (b)。
   - (c) **硬禁止**：模型在待求点给出非物理值（负电阻率、零浓度、发散）或待求点远在有效区外（如 T < Θ_D 用线性电阻率、|T−T_ref| 与 T_ref 同量级）或待求点跨过已知物理边界（跨居里点 T_C、跨相变、跨弹性极限）时，**不得**以"已标注假设"为由沿用该模型——标注不等于改模型。必须按 (a) 换模型；若题面未给非线性参数则声明"线性模型在此温区失效，需 XXX 参数才能严格求解"，不要硬交一个已知失效的外推数值。**"教科书惯例/intended model/textbook exercise/教材题预期用法/全题在该模型框架内/textbook-use clause"均不是有效辩护**——这些只是说明题目用了简化模型，不改变模型在待求点物理上失效的事实；承认 T<Θ_D 却以"教材就是这么算的"继续用线性律，是"承认但回避"翻车签名，与"已标注假设"同罪。
4. **自查**：我是否把一阶/线性模型外推到远离参考点或跨过物理边界？模型在待求点是否给出非物理值（零、负、发散）？我是否"已承认假设不成立却仍沿用"——若是，这是已知翻车模式，必须回到第 3 步按 (a) 或 (c) 处理，不要静默提交外推结果。**特别确认**：若我写出了"教材/教科书/intended model/textbook-use clause/全题在线性框架内/无非线性参数 supplied"之类的理由来正当化一个已知失效的外推 → 这正是 (c) 所禁的"承认但回避"签名，删掉该理由、回到 (a) 换模型或声明无法严格求解。**跨边界检查**：代入前逐一列出该材料的所有物理边界（Θ_D、T_C、熔点 T_m、弹性极限…），待求点跨过任一条 → (b) 不可用，走 (a) 或 (c)；不要只看"结果为正"就启用 (b)。**边界选对了吗**：电阻率–温度律的有效边界是德拜温度 Θ_D（声子散射机制切换），不是居里温度 T_C（磁相变）；查 T_C 来判断电阻律适用区间是查错边界——T_C 只管 α 在磁相变处不连续，与线性律的高温/低温适用域无关。

## 同一题多问：全程同一模型/同一近似层次，不得逐问换近似

多部分题（(a)/(b)/(c)…）解同一物理体系时，**一旦在某一问选定了模型与近似层次，后续各问必须沿用同一模型同一近似层次**，不得在 (a) 用精确式定参数、(b) 却改用该精确式的低阶线性近似直接外推。典型翻车：Clausius–Mossotti 类关系 (εr−1)/(εr+2)=Nα/(3ε0)，(a) 用完整 CM（含 (εr+2) 局部场因子）由实测 εr 反解 α，(b) 加压后却改用稀释极限线性近似 κ=εr−1∝N 把 εr−1 直接翻倍——两步用了不同近似层次，(b) 丢掉了 (εr+2) 随密度变化项。正确：(b) 仍用完整 CM，令比值 (εr−1)/(εr+2) 按 N 比例缩放后解 εr。

**判据**：写完某一问的模型式后，回看上一问用的是完整式还是某阶近似——若两问处理同一物理量却用了不同近似层次（一问含高阶修正因子、另一问略去该因子） → 除非题面明确要求"用稀薄近似/线性近似重算"，否则回退到上一问的模型重做本问。

**执行**：
1. 在第一问落笔时记下所用模型与近似层次（完整式 / 一阶线性化 / 稀释极限 / …），标注"本题后续各问沿用此模型"。
2. 每个后续问代入前核对：本问所写公式与第 1 步记下的是否同一模型同一近似层次？若发现本问悄悄降阶（略去了上一问保留的修正因子/局部场因子/活度修正…） → 换回第 1 步的完整模型重算。
3. **仅当**题面在某问显式要求"用 X 近似估算"或"在稀薄极限下" → 该问可用更低阶近似，但仍须标注"本题其他问用完整模型，本问按题面要求用 X 近似"。
4. **自查**：逐问比对所用公式的近似阶数是否一致；发现某问的公式是上一问公式的低阶展开 → 回退用上一问的完整式重做该问。

## 举例（通用占位，非任何具体题目）

用线性电阻率 ρ=ρ_ref[1+α(T−T_ref)] 求 T=T₁ 处 ρ：先查该材料 Θ_D 与（若为铁磁金属）居里点 T_C，若 T₁ < Θ_D 或 |T₁−T_ref| 与 T_ref 同量级 → 线性近似失效，改用 Bloch–Grüneisen 或标注"外推至模型有效区外，结果近似"。若待求温区一端 < T_C < 另一端（跨居里点）→ 单一 α 不适用，须分温区各取 α 或用实测 ρ–T 分段/非线性模型。若模型在 T₁ 预测 ρ≤0 → 非物理信号，必改模型或标注。判定动作：代入前先比对待求点与模型有效区（含 Θ_D、T_C 等所有相变边界），不要算完才发现非物理仍硬交。
