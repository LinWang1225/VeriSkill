# 各向异性屈服函数中 R 的正确位置

## 触发情形

题面给法向各向异性参数 R（plastic strain ratio / Lankford coefficient），用 Hill 1948 二次或 Hosford 非二次屈服函数求平面应力下的应力比 α = σ_y/σ_x（通常由关联流动法则 ∂f/∂σ_y = 0 配合 ε_y = 0 导出）。典型翻车：把 R 放在 |σ_x|^a 和 |σ_y|^a 项上（写成 f ∝ |σ_x−σ_y|^a + R|σ_x|^a + R|σ_y|^a），而正确位置是乘在 |σ_x−σ_y|^a 项上（f ∝ |σ_x|^a + |σ_y|^a + R|σ_x−σ_y|^a）。R 放反后导出的 α 公式中 R 与 1/R 互换，数值错误。

## 硬约束

1. **Hosford 非二次（法向各向异性，平面应力 σ_z=0）**：
   - 正确形式：f^a = |σ_x|^a + |σ_y|^a + R|σ_x − σ_y|^a（可差整体常数因子如 1/(1+R)，不影响流动法则）。
   - R 在 |σ_x − σ_y|^a 项上，**不在** |σ_x|^a 或 |σ_y|^a 项上。
   - 由 ∂f/∂σ_y = 0（配合 ε_y = 0 的关联流动法则）得：a·σ_y^(a−1) − R·a·(σ_x−σ_y)^(a−1) = 0 → σ_y^(a−1) = R·(σ_x−σ_y)^(a−1) → α/(1−α) = R^(1/(a−1)) → **α = R^(1/(a−1)) / (1 + R^(1/(a−1)))**。

2. **Hill 1948 二次（法向各向异性，平面应力 σ_z=0）**：
   - 正确形式：f = σ_x² + σ_y² − (2R/(R+1))·σ_x·σ_y，或等价地 f ∝ σ_x² + σ_y² + R(σ_x−σ_y)²（展开后交叉项系数为 −2R，与上式只差整体因子 1/(1+R)）。
   - 由 ∂f/∂σ_y = 0 得：**α = R/(1+R)**。

3. **退化检验（必做）**：非二次形式在 a=2 时必须退化为 Hill 1948。把 a=2 代入你写的屈服函数，展开后交叉项系数应为 −2R/(R+1)（或等价地 R 出现在 (σ_x−σ_y)² 项上）。若 a=2 代入后交叉项系数变成 −2/(R+1)（R 跑到了 |σ_x|²、|σ_y|² 项上）→ R 位置反了，回第 1 步修正。

## 执行步骤

1. **写出屈服函数**：确认 R 乘在 |σ_x − σ_y|^a 项上（Hosford）或等价地在 (σ_x−σ_y)² 项上（Hill）。若发现 R 在 |σ_x|^a、|σ_y|^a 项上 → R 位置反了，调换。
2. **退化检验**：令 a=2，展开非二次形式，确认退化为 Hill 1948 的交叉项系数 −2R/(R+1)。不退化 → R 位置错，回第 1 步。
3. **由关联流动法则导出 α**：ε_y = 0 → ∂f/∂σ_y = 0，解出 α = σ_y/σ_x。
4. **自查（硬门控）**：
   - R 在哪个项上？在 |σ_x−σ_y|^a → 过；在 |σ_x|^a 或 |σ_y|^a → 回第 1 步调换。
   - a=2 退化到 Hill 的 α=R/(1+R) 吗？代入 a=2 看非二次 α 公式是否退化为 R/(1+R)。若退化为 1/(1+R) → R 反了，回第 1 步。
   - α 应在 0 与 1 之间（平面双轴拉伸、R>0 的物理情形）。若算出 α 超出 (0,1) → 回查 R 位置与公式。

## 举例（通用占位，非任何具体题目）

法向各向异性 R 值给定，Hosford 非二次 a 给定，平面应力 σ_z=0，ε_y=0，求 α。
- 错误：f ∝ |σ_x−σ_y|^a + R|σ_x|^a + R|σ_y|^a → ∂f/∂σ_y=0 给 (σ_x−σ_y)^(a−1) = R·σ_y^(a−1) → α = 1/(1+R^(1/(a−1)))。a=2 退化给 α=1/(1+R)≠R/(1+R)（除非 R=1），退化失败，R 位置反。
- 正确：f ∝ |σ_x|^a + |σ_y|^a + R|σ_x−σ_y|^a → ∂f/∂σ_y=0 给 σ_y^(a−1) = R·(σ_x−σ_y)^(a−1) → α = R^(1/(a−1))/(1+R^(1/(a−1)))。a=2 退化给 α=R/(1+R)，与 Hill 一致。

判定动作：写完屈服函数后立即做 a=2 退化检验；退化不出 Hill 的 α=R/(1+R) → R 位置反了，调换后重导 α。
