# TTT 等温转变：用保持时间对比开始/终了线定相，不要凑半转变混合硬度

## 触发情形

题面给热处理路径：奥氏体化 → 淬至某温度 T_h 并等温保持时间 t_h → 再淬火（或冷却）到室温，问最终组织/硬度。须用共析钢（或给定钢种）TTT/CCT 图判定 T_h 下等温 t_h 后的转变程度与产物。

典型翻车：
1. 在 TTT 图上除开始线、终了线外另引入"50% 完成曲线"，用 log 时间线性插值凑出一个"半转变"分数，再当作"一半贝氏体+一半马氏体"。
2. 对 HRC 硬度按相体积分数做线性混合（rule of mixtures），HRC 对相分数非线性，Callister 类教材图根本不提供混合规则。

## 硬约束

1. **定相只用开始线与终了线**（必要时加 50% 线仅用于判断是否进入转变区，不用于凑混合分数）：
   - t_h < 开始线 → 该温度下未转变，最终组织为原过冷奥氏体在后续冷却中的产物（通常全马氏体）。
   - 开始线 ≤ t_h < 终了线 → 部分转变，残余奥氏体在后续冷却中转马氏体；**仅当题目要求混合组织且给出各相硬度标尺/杠杆可定分数时**才报混合，否则说明"部分转变，分数须由图读出"。
   - t_h ≥ 终了线 → 该温度下完全转变为单一产物（珠光体/贝氏体），后续冷却不再改变组织；硬度直接读该温度下该产物的硬度标尺，**不做任何混合**。
2. **HRC 不按相分数线性加权**：HRC 是压痕深度的对数标度，对相分数非线性；Rule of mixtures / Voigt 加权只对某些场量（电导率、模量等）在特定几何下成立，对硬度不成立。教材 TTT 题的预期做法是"定单一相 → 读该相硬度"，或题目显式给出混合硬度查图路径时按该路径走，不要自造加权。
3. **硬度读数必须来自图上该温度的硬度标尺/曲线**，不得凭"下贝氏体大概 X HRC"的记忆断言；不同温度、上下贝氏体硬度差异大。

## 执行步骤

1. 在 TTT 图上定位等温温度 T_h 的水平线，读出该温度下开始线时间 t_s、终了线时间 t_f（必要时 50% 线 t_50），注明图源。
2. 比较保持时间 t_h 与 t_s、t_f：
   - t_h ≥ t_f → 单一转变产物（按 T_h 所在温区定名：珠光体区/贝氏体区），进入第 3 步读硬度。
   - t_h < t_s → 未转变，最终为马氏体（后续淬火），读马氏体硬度。
   - t_s ≤ t_h < t_f → 部分转变；按硬约束第 1 条处理，不要默认"一半一半"。
3. 读硬度：在 TTT 图配套的硬度标尺/硬度–温度曲线上读该温度下该产物的 HRC，注明图源；不要用记忆值，不要对多相加权。
4. 自查：
   - 我是否引入了"50% 完成曲线"凑半转变？若是，回到第 2 步只用开始/终了线定相。
   - 我是否对 HRC 做了体积分数线性混合？若是，删除该加权，按硬约束第 2 条改为读单一相硬度或题目给定路径。
   - 硬度值是否注明图源？若无图源，标注"该量为图读数，需原图确认"。

## 举例（通用占位，非任何具体题目）

等温温度 T_h 处 TTT 开始线 t_s、终了线 t_f。保持时间 t_h ≥ t_f → 该温区单一产物（如贝氏体），硬度读 T_h 下贝氏体硬度标尺 H_b，答案即 H_b，不做 H_b 与马氏体硬度的加权。若 t_h < t_s → 全马氏体，读马氏体硬度。若 t_s ≤ t_h < t_f 且题目未给混合路径 → 报"部分转变，分数须由图读出"，不要自造 0.5/0.5 加权硬度。
