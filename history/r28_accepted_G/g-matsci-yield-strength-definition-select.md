# 屈服强度定义选择：比例极限 ≠ 屈服强度

## 触发情形

题目要求计算回弹模量 U_r = σ_y²/(2E)、安全系数 n = σ_y/σ_applied、塑性失效载荷、或任何以屈服强度 σ_y 为输入的量，而材料无明显屈服点（应力–应变曲线从弹性区平滑过渡到塑性区，无锯齿屈服平台）。典型翻车：把比例极限（线性区终点、应力–应变开始偏离线性的点）当作屈服强度代入，低估 σ_y，进而低估 U_r 或高估安全系数。

## 关键概念辨析

三个不同的应力判据，不得混用：

1. **比例极限 σ_pl (proportional limit)**：应力–应变曲线上偏离线性的最大应力，即弹性区严格线性的终点。它是"线性范围的边界"，不是"塑性开始的标志"，不用于强度设计。
2. **弹性极限 σ_el (elastic limit)**：卸载后残余变形为零的最大应力。略高于比例极限，实验上难以测定，教材中很少单独使用。
3. **屈服强度 σ_y (yield strength)**：产生某规定塑性应变时的应力。对无明显屈服点材料，按 **0.002 (0.2%) 偏移法** 确定：在应力–应变图上从 ε=0.002 处作平行于弹性段（斜率 E）的直线，与应力–应变曲线的交点即为 σ_y。对有明显屈服点材料（低碳钢等出现锯齿屈服），取下屈服点（屈服平台对应的应力）。

**比例极限 < 弹性极限 < 屈服强度（0.002 偏移）**，三者数值不同，用错会系统性偏差。

## 硬约束

1. **先判材料类型**：题面或材料类别告知有无明显屈服点。
   - 有明显屈服点（低碳钢、中碳钢退火态等出现上下屈服点/屈服平台）→ σ_y 取下屈服点（应力–应变平台对应值）。
   - 无明显屈服点（不锈钢、铝合金、铜合金、退火高合金钢等曲线平滑过渡）→ σ_y 按 0.002 偏移法确定。
2. **0.002 偏移法执行步骤**：
   - 从应力–应变曲线弹性段求弹性模量 E（线性区最小二乘拟合或取弹性段斜率）。
   - 在应变轴上 ε = 0.002 处作斜率 E 的直线：σ_offset = E·(ε − 0.002)。
   - 该直线与实验应力–应变曲线的交点给出 σ_y 与对应应变 ε_y。
   - 若应力–应变曲线以表格形式给出（离散点），在塑性区段做分段线性插值与偏移线求交点。
3. **禁止用比例极限当 σ_y**：比例极限是线性区终点，不是屈服判据。即使题面给了比例极限值，也不得直接代入需要 σ_y 的公式。
4. **回弹模量** U_r = σ_y²/(2E) = ½·σ_y·ε_y，其中 σ_y 必须是按上述方法确定的屈服强度，不是比例极限。

## 执行步骤

1. 确认题目所求是哪个量（回弹模量、安全系数、失效载荷…），该量需要 σ_y。
2. 判定材料有无明显屈服点（查题面材料描述或教材分类）。
3. 按材料类型选 σ_y 定义（上节硬约束 1）。
4. 若用 0.002 偏移法：求 E → 画偏移线 → 求交点 → 读 σ_y。
5. 用正确的 σ_y 代入目标公式算结果。
6. **自查（硬门控）**：
   - 我代入的 σ_y 是比例极限还是屈服强度？若来自"线性区终点/偏离线性的点"→ 是比例极限，回第 3 步重选。
   - 材料无明显屈服点时我是否用了 0.002 偏移法？若直接取了某曲线上的点而无偏移构造 → 回第 4 步补偏移法。
   - σ_y > σ_pl 吗？若 σ_y ≤ σ_pl → 可能误取了比例极限，回查。

## 举例（通用占位，非任何具体题目）

材料 A 的应力–应变曲线由表格给出，无明显屈服点。求回弹模量。
- 错误：取线性区最后一个点（比例极限 σ_pl）当 σ_y，算 U_r = σ_pl²/(2E)——低估。
- 正确：弹性段拟合 E → 从 ε=0.002 作斜率 E 的偏移线 → 与曲线交点读 σ_y → U_r = σ_y²/(2E)。
- 判据：σ_y 应大于 σ_pl（偏移线在塑性区与曲线相交，交点应力高于线性区终点）。

判定动作：落笔前问"我用的 σ_y 是 0.002 偏移屈服强度还是比例极限？"前者→过；后者→回第 3 步重选。
