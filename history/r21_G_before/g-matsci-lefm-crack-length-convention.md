# LEFM 裂纹长度约定：a 是半裂纹长，检测限口径须对齐

## 触发情形

题面给 K_Ic、屈服强度、设计应力、Y 值，要求算临界裂纹/缺陷尺寸并判断是否可被 NDT 检出（或反之由检测限算最大允许应力/安全系数）。典型翻车：用 K_Ic = Y·σ·√(π·a_c) 解出 a_c 后，直接拿 a_c 与题面给的"缺陷检测分辨率极限"比较——但 a_c 是半裂纹长，而检测分辨率极限通常指**可检最小缺陷全长**（2a），两者差因子 2，导致"可检测"判定或报出的缺陷尺寸口径错误。

## 硬约束

1. **a 的定义**：在标准 LEFM 公式 K_I = Y·σ·√(π·a) 中，a 是**半裂纹长**（对内部穿透裂纹而言；对边缘/表面裂纹 a 是裂纹深度）。对内部穿透裂纹，**全长 = 2a**。
2. **NDT 分辨率极限的口径**：题面给的"flaw size resolution limit / detection limit / minimum detectable flaw size"通常指**可检缺陷的特征全长**（2a），即仪器能发现的最小总裂纹长度。读题时先确认该极限针对的是全长还是半长——若题面只说"flaw size"或"defect size"而无额外说明，默认全长口径。
3. **比较须同口径**：把临界值与检测限比较前，确认两者口径一致：
   - 若检测限是全长 → 比较 2a_c 与检测限。
   - 若检测限是半长 → 比较 a_c 与检测限。
   - 口径不一致时先换算，不要拿 a_c 直接与全长检测限比。
4. **答案口径**：题面问"critical flaw size"且答案单位为长度时，确认题面要的是半裂纹长 a_c 还是全长 2a_c。教材惯例（Callister 类）中"flaw size"对内部裂纹多指全长 2a；若题面明确用 a 符号则报 a_c。在答案旁注明所报口径（"2a_c = …（全长）"或"a_c = …（半长）"）。

## 执行步骤

1. 写下 K_Ic = Y·σ·√(π·a_c)，确认 a 是半裂纹长（内部穿透裂纹）或裂纹深度（边缘裂纹）。
2. 解出 a_c。
3. **定检测限口径**：读题面"flaw size resolution limit / detection limit"的措辞——若为"flaw size"/"defect size"默认全长 2a 口径；若题面显式说"half-crack length"/"a"则为半长口径。
4. **换算到同口径再比较**：
   - 检测限为全长 → 临界全长 = 2a_c，与检测限比较。
   - 检测限为半长 → a_c 与检测限比较。
5. **报答案**：按题面要求的口径报出（全长或半长），旁注口径。
6. **自查**：我是否拿 a_c（半长）直接与全长口径的检测限比较了？若是 → 因子 2 错，回第 4 步换算到同口径。我报的"flaw size"是半长还是全长？与题面要求一致吗？

## 举例（通用占位，非任何具体题目）

已知 K_Ic、σ、Y，检测分辨率极限 L_det（全长口径）。解 a_c = (1/π)(K_Ic/(Yσ))²。临界全长 = 2a_c。比较 2a_c 与 L_det：2a_c > L_det → 可检出；2a_c < L_det → 不可检出。答案报 2a_c（全长）并注明口径。

❌ 错误：解出 a_c 后直接比 a_c 与 L_det——a_c 是半长、L_det 是全长，口径不匹配，差因子 2。
