# S-N 疲劳离散数据：局部 log-log 插值，禁止全点回归

## 触发情形

题面给一张离散 S-N 数据表（若干个 (S_i, N_i) 实测点），所问的寿命 N（或应力 S）落在表中两个相邻点之间，要求读出对应的应力（或寿命）。典型翻车：对全部 n 个数据点做单一 log-log 幂律回归 S = C·N^b（即 log S = log C + b·log N 的最小二乘直线），再代入所问 N 读 S。这条整体回归线**不经过各实测点**（除非点恰好共线），在高周端、中间端会系统偏离实测值，把所有插值结果一起拉偏。

## 硬约束

- **局部插值**：所问 N 落在表中两个相邻点 (N_j, S_j) 与 (N_{j+1}, S_{j+1}) 之间（N_j ≤ N ≤ N_{j+1}）时，只取这两个点在 log-log 空间做线性插值：
  ```
  log S = log S_j + (log S_{j+1} − log S_j) · (log N − log N_j) / (log N_{j+1} − log N_j)
  ```
  再取 S = 10^(log S)。等价地，在区间 [N_j, N_{j+1}] 内假定 Basquin 律 S = C_j·N^b_j，用两端点定 C_j、b_j。
- **禁止全点回归**：不得对全部 n 个 (log N_i, log S_i) 做最小二乘拟合再代入。整体回归最小化的是全点残差和，不保证过任一实测点，区间内插值会偏离实测。
- **外推警告**：所问 N 落在表的范围之外（N < N_min 或 N > N_max）时是外推而非插值——即使局部外推也须标注"外推，无实测包围点，结果可靠性降低"。
- **多段不同斜率**：若 S-N 数据在 log-log 图上明显分段（低周/高周 fatigue transition、耐久极限附近趋于水平），各段斜率不同，更不能用一条直线拟合全段——按所问 N 落在哪段，取该段相邻点插值。

## 执行步骤

1. **确认数据是离散表**：题面给的是有限个 (S_i, N_i) 点还是一条连续曲线/已知 Basquin 参数？离散表 → 本技能适用；已给 Basquin 参数 (C, b) → 直接 S = C·N^b，不需插值。
2. **定位所问 N 落在哪两个相邻点之间**：将表中 N_i 按升序排列，找到 N_j ≤ N ≤ N_{j+1}。若 N 恰好等于某 N_j → 直接读 S_j，无需插值。
3. **局部 log-log 线性插值**：取 (N_j, S_j) 和 (N_{j+1}, S_{j+1}) 两点，按上面公式在 log-log 空间插值。只这两点，不牵涉其他点。
4. **多个所问值**：若题面问多个寿命对应的应力，每个独立定位其包围区间、独立插值，不要用一个回归方程统一代入。
5. **自查（硬门控）**：
   - 我是否用了全部数据点做回归？若是 → 回第 3 步改为局部两点插值。
   - 插值结果是否落在两个包围点的 S 值之间（log-log 单调时）？若插值结果超出 [S_j, S_{j+1}] 范围 → 算错，回第 3 步重算。
   - 所问 N 是否在表范围内？若在范围外 → 标注外推警告。
6. **独立验证**：换一条路径确认——如用相邻两点的斜率 b_j = (log S_{j+1} − log S_j)/(log N_{j+1} − log N_j) 手算，与插值公式结果比对；或取所问 N = N_j 看插值是否退化为 S_j（边界一致性检查）。

## 举例（通用占位，非任何具体题目）

表给 n 个点 (S_i, N_i)，所问 N 落在 N_j 与 N_{j+1} 之间：
- 正确：只取 (N_j, S_j)、(N_{j+1}, S_{j+1}) 两点，log-log 线性插值得 S。
- ❌ 错误：对全部 n 个点做 log S = a + b·log N 最小二乘回归，再代入 log N 读 S——回归线不经过各实测点，插值偏离。

判定动作：写下插值式后，确认式中只含两个包围点的坐标、不含其他点；若式中出现全部点的拟合参数 a、b → 用错方法，回第 3 步改为局部两点插值。
