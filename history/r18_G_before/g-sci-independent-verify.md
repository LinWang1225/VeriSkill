# 独立验证：第二路径复算，禁止循环论证

## 硬约束

任何"验证/检查"步骤都必须是**独立**的——用一条不复用原推导的第二路径重新得到同一结果，两条独立结果一致才算过。**禁止**把数值代回自己导出的式子、或用同一套推导/同一份代码再算一遍当验证：那是循环论证，只查得出誊写错，查不出符号/系数/模型错。

## 什么算"独立第二路径"

满足任一条即视为独立：
- **换公式/换模型**：原推导用解析式，验证用数值积分/有限差分/量纲分析粗估；原用 A 公式，验证用等价的 B 公式（B 不是 A 的代数重排）。
- **换工具**：原推导手算，验证用独立写的代码（不复制原推导的表达式，从头按物理定义实现）。
- **换符号约定/坐标系**：原用一种约定，验证换另一种等价约定看是否落到同一数值。
- **量级/极限检查**：取极端参数（某相体积分数→0 或→1）看结果是否退化为单相值；量级粗估与精确值差不超过合理倍数。

**不算独立的**：把原导出的闭式结果代入原式两边看相等；把原代码的输出再跑一遍；只改变量名不改表达式。

**同一物理量的标度/单位换算不是独立路径**：把一个量从一种标度换算到另一种标度（硬度 HB ↔ HV、长度 nm ↔ Å、温度 °C ↔ K、压力 atm ↔ Pa…）仍是**同一个测量值**，共享同一物理测量，只查得出换算系数对不对，查不出该量本身是否取对、模型是否选对。用"700 HB 与 697 HV 交叉核对"这类同量异标度当独立验证，是伪独立，等同循环论证。独立第二路径必须换**公式/模型/工具/数据来源**，不能只换同一量的计量单位。

## 常见伪独立模式（逐条排查）

以下模式看似独立、实为循环，提交前逐条对照：

1. **单位换算重跑同一公式**：原推导用 SI 算出 v，"验证"改用 cgs/原子质量单位/其他单位制重跑同一公式得 v'。公式没换、物理路径没换，只换了计量单位 → 伪独立。判据：验证段若只出现单位换算因子和原公式的重排 → 不算独立，须换公式或换模型。
2. **变量代回自身定义式**：原推导由 θ 算出 λ（λ = f(θ)），"验证"把 θ 代回 λ = f(θ) 复算得同一 λ。这是恒等式，验不出 f 是否选对。判据：验证段若把原推导的输入量代回原推导的输出公式 → 循环，须换一条不经过 f 的路径（如换一个独立测得的 λ 对照、或用不同物理关系导出 λ）。
3. **同组锚点拟合再回代**：用从同一张图/同一组数据读得的若干点拟合模型参数（Avrami n/k、幂律 a/b…）再外推或回代该组点。拟合必过锚点，回代必相等，验不出锚点是否偏离真实图线。判据：验证段若拟合用的数据点与原推导同源 → 循环，须换不同来源的数据或不同物理关系的量级粗估。
4. **牌号/规格派生比值当独立核对**：用牌号规格里两个属性的比值（如屈服/抗拉下限比）去核对算出的两个强度的比值。比值源自同一组规格数字，任何同类型线性律都会自动满足 → 伪独立（详见 g-matsci-grade-designation-not-source）。

## 执行步骤

1. 完成原推导得到候选答案后，**另起一段**标注"独立验证"。
2. 选一条上列独立路径，**从头**重算（不是引用原步骤）。
3. 比较两条路径的结果：
   - 一致（在题目容差内）→ 通过，可提交。
   - 不一致 → 回到原推导排查，不要硬交。优先查符号约定、系数、单位换算、模型选择这四类。
4. 验证段要写清**用了哪条独立路径、与原推导有何不同**，不要只写"Verified numerically"——这种无来源声明不算验证，会被判过程可追溯性弱。
5. 提交前对照"常见伪独立模式"逐条自查：我的验证是否只是单位换算重跑同一公式 / 变量代回自身定义式 / 同组锚点拟合再回代 / 牌号派生比值核对？命中任一条 → 不是独立验证，删掉重选路径。

## 中间量—最终量一致性检查

除独立第二路径外，若解答中同时报了中间量 x 和最终量 y，且两者之间存在**已知的物理/定义关系** y = g(x)（g 不是你自己为求 y 而导出的式子，而是独立的已知约束，如晶格 c/a 比、化学计量比、几何关系），须检查 g(x_reported) ≈ y_reported。不通过 → 中间量或最终量至少一个有误，回原推导排查。这不是循环论证（g 是外部已知约束，非原推导路径），能查出中间量算错而最终量碰巧从另一路径算对的情形。

## 举例（通用占位）

原推导用闭式 P = f(a,b,c) 算得数值 v。独立验证：用独立代码从物理定义（不调用 f）数值重算得 v'；或取极限 a→0 看 v 是否退化为已知单相解 v_0。|v−v'|/|v| 在容差内 → 过；否则回原推导查。禁止：把 v 代回 f(a,b,c) 两边看相等。中间量—最终量检查示例：报了晶格参数 a 和 c，已知该结构 c/a = r（常数），检查 c_reported ≈ r·a_reported；不通过 → a 或 c 有误。
