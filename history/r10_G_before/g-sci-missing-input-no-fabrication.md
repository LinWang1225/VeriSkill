# 缺关键输入时不得捏造：保留为函数或声明不可定解

## 触发情形

题面给了一组参数，要求算某个量，但该量本质上还依赖一个题面未给的变量（速率依赖时间、通量依赖位置、浓度依赖时刻…）。典型翻车：为了让式子"算完"，自行选一个使中间量取整洁值的输入点（如令某指数 = 某整数反推时间），把凭空凑出的单一数值当最终答案提交。该数值不由题面数据决定，换一个取点就差若干量级。

## 硬约束

- **禁止**引入题面未给、非公认物理常数、且非由题面约束关系导出的数值输入。凡引入的数值须可追溯到题面原文、公认常数表、或题面约束的代数推导。
- 若目标量 = f(x) 而题面未给 x，则答案须保留为 f(x)（显式写出 x 的函数式），或声明"该量取决于 x，题面未指定 x 故无单一数值解"。

## 执行步骤

1. **列依赖**：写出目标量所依赖的全部变量，逐个标注"题面给了 / 题面没给"。
2. **对没给的变量**：
   - (a) 能否用题面给的约束/关系消去它（如题面给了转化分数 y 而非时间 t，可由 Avrami 式反解 t 再代入速率式）→ 消去后继续。
   - (b) 消不去 → 将答案写成该变量的显式函数，注明"需指定该变量才能给数值"。
   - (c) 题面暗示要单一数值但确无足够信息 → 声明问题不可定解，指出缺哪个参数，不要凑数。
3. **自查**：扫一遍解答里每个代入的数值——它来自题面、公认常数、还是题面约束的推导？若有任何一个数值来源是"我选了一个整洁值"→ 删掉，回第 2 步按 (b) 或 (c) 处理。

## 举例（通用占位，非任何具体题目）

目标量 r = f(t; a, b)，题面给了参数 a、b 但没给时间 t。禁止：令某中间量 = 整数 c 反推 t=t₀ 再算出 r(t₀) 当答案——t₀ 不由题面决定。正确：报 r(t) = f(t; a, b) 的显式式，注明"题面未指定 t，r 为 t 的函数，需给定 t 才有数值"。若题面另给转化分数 y₀：由 y₀ = 1−e^{−…} 反解 t 代入 f → 得单一数值，此路径合法（t 由题面给的 y₀ 导出，非凭空选取）。
