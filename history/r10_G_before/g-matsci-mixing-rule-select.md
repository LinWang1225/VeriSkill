# 混合法则选择：先判物理机制，再选对什么量做体积加权

## 触发情形

题面求两相（或多相）复合/合金的有效性质：电导率 σ、热导率 k、弹性模量 E、电阻率 ρ 等，给了各相体积分数 V_i 和各相该性质的值。常见陷阱是把"规则混合"(rule of mixtures, Voigt 算术平均)直接套到题目问的那个量上，而不先判断该量在假定的场几何下是串联叠加还是并联叠加。

## 判别流程（按此顺序走，不要跳）

1. **定场几何**：题面是否说明相排列方向相对外场（电流/热流/应力）？
   - 相平行于场方向 → 等应变/等场（Voigt，并联）→ 对**性质本身**做体积加权：P_eff = Σ V_i·P_i。
   - 相垂直于场方向 → 等应力/等流（Reuss，串联）→ 对**性质的倒数**做体积加权：1/P_eff = Σ V_i / P_i，再取倒数。
   - 题面未明示几何、属教材标准题 → 用该教材该类问题的约定（Callister 类教材对横向电导/热导默认 Reuss 串联），并在解答中一句话注明所取模型。

2. **对电导率 σ 特别注意**：电流"易走低阻相"对应并联（Voigt 上界），"被迫串穿高阻相"对应串联（Reuss 下界）。
   - 串联模型（常见默认）：先算有效**电阻率** ρ_eff = Σ V_i·ρ_i（其中 ρ_i = 1/σ_i），再 σ_eff = 1/ρ_eff。
   - 并联模型：σ_eff = Σ V_i·σ_i。
   - 易错点：把 σ_eff = Σ V_i·σ_i（并联）当成默认，会**高估高阻相的贡献**——这是典型翻车点。若题面说"两相串联/电流依次穿过两相"或教材该题用串联约定，必须走电阻率加权再取倒数。

3. **对弹性模量 E**：纵向（纤维方向）用 Voigt：E = Σ V_i·E_i；横向用 Reuss：1/E = Σ V_i/E_i。先看题面"纵向/横向/等应变/等应力"关键词再落笔。

4. **算完自查**：把两相体积分数代入，检查
   - Voigt 结果是否 ≥ 各相中最大值之加权（上界性质）；
   - Reuss 结果是否 ≤ 各相中最小值之加权（下界性质）；
   - 串反并同：串联结果应偏向**高阻/低导/低模**相，并联结果应偏向**低阻/高导/高模**相。方向反了说明把串并联搞反，回到第 1 步重判几何。

## 上下界只用于合理性核对，不得反推选定输入参数

**硬约束**：Voigt 上界（P_eff ≤ Σ V_i·P_i）与 Reuss 下界（1/P_eff ≥ Σ V_i/P_i）是**模型一致性检验**，只用于算完之后核对结果是否落在物理允许的上下界之间、方向是否合理。**禁止**把上下界不等式当"判据"去反推、筛选或选定各相的输入参数（如纤维模量 E_f、基体模量 E_m）。

典型翻车：题面给了实验复合模量与体积分数，但组分模量须查材料性能表取得；解答不查表，反而把 Voigt 上界不等式当方程反解 E_f，以"某候选值会预测偏低/偏高"为由排除候选值、选定一个"使预测自洽"的 E_f。这是把**模型的一致性检验误用作输入参数的选择标准**——上下界只约束"算出的 P_eff 不能超过并联/低于串联"，不约束"该取哪个 E_f"；用它反推 E_f 等于让模型自己给自己定输入，结果由循环逻辑决定而非由实验/查表值决定。

**输入参数的正确来源**（按优先级）：
1. 题面显式给定 → 直接用。
2. 题面所附材料性能表/图 → 查表/读图取值，注明表号/图号（参见 g-matsci-chart-lookup-read、g-sci-explicit-assumptions）。
3. 题面未给且无表可查 → 声明缺该参数，保留为符号或声明不可定解（参见 g-sci-missing-input-no-fabrication）。

**上下界的正确用法**：算出 P_eff 后，检查 P_lower(Reuss) ≤ P_eff ≤ P_upper(Voigt)；若结果落在界外 → 模型/算术有错，回去排查；若落在界内 → 合理性通过，仅此而已。不得反过来用"要落在界内"去筛 E_f 的候选值。

## 不适用混合法则的量

- **HRC / HB / HV 等硬度标度**：硬度是压痕深度的对数型标度，对相体积分数**非线性**，Rule of mixtures（Voigt 加权）对硬度不成立。多相合金硬度不能由各相硬度按体积分数加权平均得到；教材 TTT/淬火题的预期做法是"定单一相 → 读该相硬度标尺"，或题目显式给出混合硬度查图路径时按该路径走。见到"两相各占某分数 + 各相硬度 → 求合金硬度"时，先确认题目是否显式给定混合规则；没有则不要自造加权，改为按相分数定单一主导相读硬度或声明需图读。
- **其他对数/指数标度量**（如 pH、声压 dB、Richter 震级）同理不可线性加权；先确认量是否为线性可加的广延/强度量再决定是否用混合法则。

## 举例（通用占位，非任何具体题目）

两相体积分数 V_1、V_2（V_1+V_2=1），电导率 σ_1、σ_2，电阻率 ρ_i=1/σ_i：
- 串联（电流依次穿过）：ρ_eff = V_1·ρ_1 + V_2·ρ_2，σ_eff = 1/ρ_eff。
- 并联（电流可分流）：σ_eff = V_1·σ_1 + V_2·σ_2。

判定动作：在题面找"parallel to / perpendicular to / series / 依次穿过 / 沿纤维方向 / 横向"等关键词；找不到时按教材该类题约定取模型并在答案旁注明，不要默认并联。
