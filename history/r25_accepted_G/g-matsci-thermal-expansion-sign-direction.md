# 热膨胀尺寸换算：统一带符号因子，禁止 (1−αΔT) 收缩除项

## 触发情形

题目涉及温度变化引起的长度/体积尺寸换算：铸造型腔尺寸（模具温度与室温不同）、热装配过盈配合、双金属温敏挠曲、热胀冷缩补偿长度等。典型翻车：把"从高温回到低温"理解成乘以 (1−αΔT)，或把某一段升温膨胀错放到分母写成 1/(1−αΔT)，与正确做法 1/(1+αΔT) 或 (1+αΔT) 方向相反——αΔT 小时数值几乎一致（1/(1−x)≈1+x），难以自洽查出，但物理模型已反。

## 硬约束

1. **只用一个因子形式**：L(T₂) = L(T₁)·(1 + α·ΔT)，其中 ΔT = T₂ − T₁（带符号，升温为正、降温为负）。无论升温还是降温，都是**乘以** (1+αΔT)；降温时 ΔT<0 自然给出收缩。**禁止**另写 (1−αΔT) 当作"收缩因子"——那是把 ΔT 符号吞进括号又漏了一个 O((αΔT)²) 项，且极易放错位置。
2. **多段串联一律乘因子**：跨多个温度区间或多种材料时，沿"参考态 → 逐段目标态"链依次乘 (1+α_i·ΔT_i)，每个 ΔT 用该段目标温度减该段起点温度。要把某段换回参考态，乘以 (1+α·ΔT) 的倒数 1/(1+αΔT)，**不要**改成 (1−αΔT)。
3. **先列温度链再代数**：动笔前写出"哪个尺寸在哪个温度已知、要求哪个温度的哪个尺寸、中间经过哪些材料/温度"，确认每一段是升温还是降温、因子该乘在分子还是分母，再落公式。典型铸造型腔：型腔在模具温度下尺寸 = 铸件在模具温度下尺寸 = 铸件室温尺寸·(1+α_铸件·ΔT_升温)；机加工型腔室温尺寸 = 型腔高温尺寸/(1+α_模具·ΔT_升温)。铸件膨胀因子在**分子**（放大高温尺寸），模具膨胀因子在**分母**（把高温尺寸折回室温）。

## 执行步骤

1. **画温度–尺寸链**：列出已知尺寸及其所在温度、所求尺寸及其所在温度、中间衔接的材料与温度。标出每一段 ΔT = T_目标 − T_起点。
2. **逐段写因子**：每段写 (1 + α_材料·ΔT)，ΔT 带符号。升温段 ΔT>0、因子>1；降温段 ΔT<0、因子<1。要反向折回时用倒数 1/(1+αΔT)，不用 (1−αΔT)。
3. **组装表达式**：把各段因子按链顺序相乘/相除，写出最终 L = L_0·(因子积)。确认每个因子位置（分子/分母）与该段物理方向一致——升温放大放分子，把高温尺寸折回室温放分母。
4. **方向自查**：对每个因子问"这一段是从低温到高温还是反向？因子该 >1 还是 <1？它在分子还是分母？"——三者方向须一致；任一不一致即方向反了，回到第 2 步重写。再作独立量级复核：αΔT 通常远小于 1，最终尺寸应与 L_0·(1 ± 几个 αΔT) 同量级；若结果与 L_0 差倍数级，方向/位置必有错。

## 举例（通用占位，非任何具体题目）

室温长 L₀ 的工件，其线胀系数 α_w，模具材料线胀系数 α_m，模具温度 T_h 高于室温 T_c。求模具在室温下须机加工出的型腔长，使工件冷到室温后长 L₀。温度链：工件室温 L₀ → 工件高温 = L₀·(1+α_w·(T_h−T_c))（升温，因子>1，在分子）→ 型腔高温与之相等 → 型腔室温 = 型腔高温/(1+α_m·(T_h−T_c))（折回室温，因子>1 放分母）。错误写法：型腔室温 = L₀·(1−α_w·(T_h−T_c))/(1+α_m·(T_h−T_c))——把工件升温膨胀误写成收缩除项 (1−αΔT)，方向反；因 1/(1−x)≈1+x 数值可能接近，但模型已反。判定动作：逐段核对因子是 (1+αΔT) 还是 (1−αΔT)、在分子还是分母，与该段升温/降温方向是否一致；发现 (1−αΔT) → 改成 (1+αΔT) 并据方向定分子/分母。
