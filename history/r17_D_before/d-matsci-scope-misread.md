## 方法库

### 子情形：区熔精炼逐 pass 递推——"previous pass"类
- 【正确方法】区熔精炼中分凝系数 k0 将界面处固体浓度 C_s 与液体浓度 C_l 联系：C_s = k0·C_l（单步界面平衡）。当题目给出当前固体浓度、问"previous pass"的液体浓度时，须用**多道次区熔分布方程**（如 Pfann 单道次分布 C_s(x)=C_0[1-(1-k)e^{-kx/l}] 的多道次迭代，或经多道次精炼后的浓度分布公式）按道次数回退到指定 pass 再求该 pass 的液体浓度。关键：单步界面平衡 C_s=k0·C_l 只给出**当前 pass 界面处**的固液关系，不能直接用于跨 pass 回退——"previous pass"的液体浓度须经多道次分布方程递推，而非简单的一次或两次除以 k0。须显式递推到题目指定的那一 pass。
- 【错误签名】轨迹用单步界面平衡 C_s=k0·C_l 直接算 C_l=C_s/k0 并当作"previous pass"的答案——这其实是当前 pass 的界面液体浓度，未做任何跨 pass 递推。特征：轨迹出现将"产生当前浓度的 pass"等同于"previous pass"的表述（如"the liquid on the pass that produced it"）；或轨迹只做了一次除以 k0 就给出答案，而题目问的是 previous pass（须经多道次分布方程回退）；或轨迹虽提及"previous pass"但计算中无任何道次数依赖、无分布方程，仅用单步平衡关系。

### 子情形：多段/多步过程——"before/after/initial/final"类
- 【正确方法】当题目问某物量在"before""after""initial""final"等指定阶段的状态时，须先确定该阶段在过程序列中的位置，从该位置起算，而非从当前或最方便的阶段起算。若过程有 N 步、题目问第 M 步（M≠当前步），须显式回退或前进到第 M 步再计算。
- 【错误签名】轨迹把题目指定的非当前阶段当成当前阶段直接计算，或跳过了从当前阶段到指定阶段的过渡步骤；特征：轨迹未提及阶段切换、直接在当前阶段上算出答案。

### 子情形：实测物性——牌号规格下限 vs 硬度/经验关联实测值
- 【正确方法】当题目要求通过非破坏性/实验手段（如硬度压痕）实测某构件的真实屈服/抗拉强度时，须先用实测数据（如压痕直径+载荷→布氏/洛氏硬度）经经验关联（教材中硬度–强度标定曲线/经验公式）读出该具体构件的实测强度。材料牌号（如某铸铁级别）所标的数值是该牌号的**最低保证性能下限**（minimum specified properties），不是该具体构件的实测值——牌号仅用于确认材料类别/选择合适的经验关联曲线，不能直接当作答案。关键判据：题目含 measure/determine nondestructively/test 等实测措辞时，答案须来自实测数据经经验关联换算，而非牌号规格下限；若轨迹所报强度值恰等于牌号规格下限（数值与牌号标识一致），即疑似把规格下限当实测值。
- 【错误签名】轨迹算出硬度后，未从经验关联曲线读出实测强度，而是直接取材料牌号所标的最低屈服/抗拉强度保证值作为答案；或轨迹声称"从教材强度–硬度曲线读出"但所报数值恰与牌号规格下限一致（因牌号下限本就是该材料类的典型下限），说明实际数据来源是牌号而非经验关联。核对特征：轨迹所报屈服/抗拉强度数值与牌号标识中的最小保证值一致（或仅差单位换算）；或轨迹虽有"从曲线读出"的叙述但未给出与硬度值对应的、不同于规格下限的实测读数；或轨迹将牌号数值用作"sanity check"后实际答案仍等于该数值。结果：所报强度系统性偏低（取了下限而非典型/实测值），与正确经验关联读数有显著偏差。

## R 判据

- R-d-matsci-scope-misread-001 [hard] 若本题含时间/位置/过程步骤限定词（previous/next/initial/final pass、before/after 等）指定一个非当前阶段、或题目要求实测某物性（measure/determine nondestructively 等）而轨迹代入材料牌号/规格下限保证值：在正文"方法库"里找与本题最匹配的子情形，按其【正确方法】核对轨迹是否递推/回退到题目指定的阶段/是否从实测数据经经验关联换算、并查是否犯了其【错误签名】（停在当前阶段、把当前阶段当指定阶段、回退步数不足、把牌号规格下限当实测值、所报数值恰等于牌号标识下限）；方法库无恰配子情形时用家族通用检查（核对轨迹计算所用的阶段是否与题目限定词一致、或轨迹所报物性值是否来自实测/经验关联而非规格下限，不一致即命中）。命中任一错误签名、或计算阶段与题目指定阶段不符、或把规格下限当实测值，即命中。 依据:r2#qe055,r14#m029,r15#e055

### 子情形：稳态渗透/传质——给定通量比与总通量（产率）须联用，勿丢弃总量条件
- 【正确方法】稳态渗透/传质问题中，当题目同时给定（a）渗透物通量之比（或渗透侧分压比，由此推出通量比）和（b）总渗透通量/产率（如"permeate must be produced at a flux of J_total"）时，这两个条件是关于未知量的**两个独立方程**，须联立求解。通量比条件消去膜厚 L 后给出一个含目标变量（如温度 T）的方程，总通量条件给出另一个含 T 和 L 的方程——但总通量条件中经 Arrhenius/Sieverts 项含 T，并非"只固定 L"。此外，当渗透物为双原子分子（A₂、B₂）而溶解/扩散以原子计（Sieverts 定律 C∝√p）时，原子通量到分子通量的换算因子（1/2 per diatomic molecule）须带入**总通量求和式**（J_total = J_A2 + J_B2 = (1/2)(J_A_atom + J_B_atom)），该因子在通量比中可能约去但在总通量求和中不约去、改变 T 的解。正确做法：列出通量比方程和总通量方程（含原子/分子换算因子），联立解出 T（和 L）。关键判据：题目给定通量比 + 总通量 → 两个条件都须用于求 T；总通量条件含 T（经 Arrhenius 项），不是"只固定 L"。
- 【错误签名】轨迹仅用通量比条件解出目标变量（如 T），随后将总通量条件判为"只固定 L、与 T 无关"而丢弃——实际上总通量条件经 Arrhenius/Sieverts 项含 T，是与通量比独立的约束。或轨迹在总通量求和中漏掉原子/分子换算因子（1/2），声称该因子"对两物种相同、在比值中约去"便也不带入总通量式——但该因子在总通量求和中不约去（它乘的是各物种原子通量之和，不是比值的分子分母）。核对特征：轨迹出现"total-flux condition only fixes L""the flux condition then only fixes L, not T"等将总量条件判为与目标变量无关的表述；或轨迹仅用一个条件便给出目标变量数值、对题目其余给定条件未代入检验；或轨迹在通量比中消去换算因子后声称该因子"common to both species and cancels"，却未在总通量求和式中重新引入该因子。结果：仅由通量比解出的 T 与联立两条件解出的 T 显著不同。

- R-d-matsci-scope-misread-002 [soft] 若本题给定多个约束条件（含通量比/分压比 + 总通量/产率/守恒条件，或类似的多条件对）而轨迹仅使用其中部分条件便求出目标变量：在正文"方法库"里找与本题最匹配的子情形，按其【正确方法】核对轨迹是否将所有给定约束条件联立使用、并查是否犯了其【错误签名】（将总通量/产率条件判为"只固定其他变量、与目标变量无关"而丢弃、仅用通量比便解出目标变量、在总通量求和中漏掉原子/分子换算因子、声称换算因子"约去"而未带入求和式）；方法库无恰配子情形时用家族通用检查（核对轨迹是否使用了题目给定的每个约束条件——若有条件未被代入计算且该条件经物理公式含目标变量，即命中）。命中任一错误签名、或题目给定约束条件被丢弃而该条件实际约束目标变量，即命中。 依据:r16#m102
