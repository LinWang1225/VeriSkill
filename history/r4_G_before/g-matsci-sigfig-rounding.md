# 有效数字与舍入约定

## 触发情形

题目给定的输入参数有效数字位数不一（如有的给 2 位、有的给 3 位），最终要报一个数值答案。常见被指问题：报出位数多于最弱输入、舍入方向系统性偏大、中间量过早截断。

## 执行步骤

1. **清点每个输入的有效数字位数**，记下最少位数 n_min。
2. **中间计算全程保留守卫位**（至少比 n_min 多 2–3 位），不要在中间步骤就四舍五入到 n_min——过早截断会累积偏差。只在**最终报出**时收尾。
3. **最终答案位数 ≤ n_min**。若 n_min=2，报 2 位有效数字（如 a.b×10^k 形式），不要报 3 位。
4. **舍入用标准四舍五入**（half-up 或 half-even 均可，但要一致）：
   - 待舍入位后一位 ≥5 进一，<5 舍去；
   - 不要系统性只向上或只向下。自查：若连续多题舍入都偏向同一方向，说明有偏置，回去核对舍入规则。
5. **查表/文献常数**（密度、原子量、扩散系数等）：取与题目输入精度匹配的位数；题目用 2 位输入时，不必把密度取到 5 位再算出 5 位答案——精度受限于最弱输入。

## 自查动作

报出答案前问自己：
- 这个答案有几位有效数字？是否 ≤ 最弱输入的位数？是→过；否→收到 n_min 位。
- 舍入是标准四舍五入还是单向偏置？拿待舍入位后一位确认进/舍方向。
- 中间量是否被过早截断？若中间步骤就四舍五入到最终位数，回到第 2 步保留守卫位重算。

## 举例（通用占位）

输入 X=a.b（2 位）、Y=c.de（3 位）：n_min=2，最终答案报 2 位有效数字。中间算用 a.b、c.de 原值或更高精度，不在中间截断到 2 位。若尾数算得 a.bc…，按标准四舍五入到 a.b 或 a.(b+1)，不要总是进位。
