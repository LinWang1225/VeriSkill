# 显式声明外部标准值与近似，量化误差，对齐单位

## 触发情形

解题时用到题面未给出的外部标准值（材料密度、原子量、扩散系数、晶格参数标准值…），或做了简化近似（忽略某小项、稀释假设、理想接触假设…）。反复被指的三类问题：默默代入标准值不注来源、做近似不量化误差、答案单位标注与题面声明不一致。

## 执行步骤

1. **外部标准值**：每次引入题面未给的数值，在该值旁注明"取 v（来源：手册/教材第几版）"。若该量有常见取值区间，注明所取值与区间端点对结果的相对影响量级。
2. **近似**：每次做近似（忽略某项、线性化、稀释假设…），写明被忽略项量级与保留项量级之比，给出近似引入的相对误差量级（如"忽略项 ≈ X，保留项 ≈ Y，X/Y ≈ Z%，误差在 Z% 量级"）。比值不小（>约 5%）时说明为何仍可近似，或改用精确式。
3. **单位对齐**：答案单位与题面声明的单位对齐——题面说答案单位为 % 就报百分数（如 88.75 而非 0.8875），说 weight fraction 就报分数，说 diffraction angle 就报 2θ 而非 θ。两者口径不同时在答案旁注明所取口径。
4. **自查**：报出前扫一遍解答——每个外部数值是否有来源注记、每个近似是否有误差量级、答案单位是否与题面对齐。任一缺失 → 补上再提交。

## 举例（通用占位，非任何具体题目）

题面未给材料密度，需查手册取 ρ = v₀：在代入处写"ρ = v₀（手册第几版，该材料室温标准值）"。做近似忽略小项 ε：写"ε/主项 ≈ p%，误差在 p% 量级"。题面声明答案单位为 % 而推导得分数 f：报 f×100 并注明"按题面 % 口径"。题面问衍射角而 Bragg 解得 θ：报 2θ 并注明"衍射角 = 2θ"。
