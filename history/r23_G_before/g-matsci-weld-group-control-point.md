# 焊缝/螺栓群偏心载荷：控制点取剪力叠加的保守端

## 触发情形

焊缝群或螺栓群承受外载荷。须先判断载荷线是否通过群形心：
- **通过形心（轴向/无偏心）**：载荷对群无扭矩，各焊缝/螺栓只受均匀直接剪，按面积（焊缝长度×喉厚）分摊载荷，由许用剪切定尺寸——**不产生弯曲、不适用本技能的偏心/扭转模型**。
- **不通过形心（偏心）**：群上各点同时受直接剪（均匀分布）与偏心扭矩引起的扭转剪（随位置线性变化、方向沿周向），须求群中最大喉部/承载应力并据此定尺寸——本技能的主情形。

典型翻车（偏心情形）：把扭转剪与直接剪**相消**的那一端（被扭矩"减轻"的非保守点）当成控制点，令该端合力等于许用值来求尺寸——所得尺寸偏小、方向错误，设计不安全。
典型翻车（轴向被误当偏心）：载荷线明明过形心（如沿构件长度方向过形心的轴向拉/压），解题者却套用偏心+弯剪叠加模型反求焊脚或焊缝长度——引入本不存在的扭矩，所得尺寸与长度均错。

## 硬约束

- **控制点 = 合力最大点**：在群各端点中逐一算合力（直接剪 + 扭转剪的矢量叠加），取合力最大的那个端点作为控制点，令其应力等于许用值来求解未知尺寸。
- **保守端 = 两剪同向叠加端**：直接剪方向与扭转剪方向相同（或夹角为锐角、代数同号）的端点，合力最大，是控制点。
- **非保守端 = 两剪相消端**：直接剪与扭转剪反向（代数异号）的端点，合力被扭矩减轻，**不是**控制点；用它当判据会低估所需尺寸。
- 不得只看"离形心最远的点"就当控制点——还要看扭转剪在该点的方向是否与直接剪同向；离形心远但方向相反的点仍可能是非保守端。

## 执行步骤

0a. **焊缝长度边界门控（判可行/不可行前必做）**：当你要把算出的焊缝长度 l 与某尺寸比较以判"是否超限不可行"时，先确认该尺寸是**构件纵向长度**还是**截面肢宽/腿宽/厚度**：
   - 焊缝沿**构件长度方向**布置，其可用长度上限是构件纵向尺寸，**不是**截面的肢宽/腿宽/厚度。
   - 截面肢宽（如角钢的 leg width）是横截面几何维度，与焊缝长度是**两个不同方向**的量，**不得**用作焊缝长度上限。
   - **门控判据**：若 l > 肢宽但 ≤ 构件可用纵向长度 → 仍可行，不得以"l > 肢宽"判其不可行。只有 l > 构件可用纵向长度才真不可行。误判"不可行"会错误切换到偏心弯剪叠加模型，引入本不存在的弯曲/扭矩。
0b. **所问量门控（落笔前必做）**：把题面"Give your answer as the value of X"里的 X 与你打算报出的量名逐字比对。weld_length（焊缝长度 l，沿构件纵向）≠ weld leg size / 焊脚尺寸 h ≠ throat thickness / 喉厚 t ≠ bolt diameter / 螺栓直径 d——数值与单位均不同。算完后报**题面所问的 X**；若求解过程中顺带得到的是另一个量（如走了定焊脚路径得到 h）→ 必须回到题目所问的量换算或重解，不得直接报顺带量。

0. **先判载荷是否过形心**：算焊缝群/螺栓群形心位置，看外载荷作用线是否通过形心。
   - **过形心（e=0）**：轴向加载，无扭矩、无弯曲。按各焊缝/螺栓的面积（焊缝长度×喉厚）分摊载荷，令最大剪应力 = 许用剪切定尺寸。**到此为止，不进入下面的偏心步骤**。常见误判：把角钢截面的**肢宽（leg width / 截面维度）**当成焊缝可用长度上限，据此判平衡设计焊缝长度"超限不可行"而改走偏心弯剪叠加模型——焊缝沿**构件长度方向**布置，其可用长度由构件纵向尺寸与强度条件决定，**不受截面肢宽约束**；截面肢宽是横截面几何维度，与焊缝长度是两个不同方向的量，不可混用。若算出的平衡设计焊缝长度 > 肢宽但 ≤ 构件可用纵向长度 → 仍可行，不得以肢宽判其不可行。
   - **不过形心（e≠0）**：进入下面的偏心/扭转流程。
1. **定群形心**：算焊缝群/螺栓群的形心位置（对焊缝群按喉部面积加权；对螺栓群按各螺栓截面积加权，等径时按位置算术平均）。
2. **定偏心与扭矩**：外载荷作用线到群形心的垂直距离即偏心 e，扭矩 T = F·e（F 为外载荷合力）。
3. **定直接剪**：假设均匀分摊到群上，方向沿外载荷方向。
4. **定扭转剪**：群上某点的扭转剪 ∝ 该点到形心的距离，方向垂直于该点到形心的连线（沿扭矩旋转方向）。在群各**端点**（角点、最远点）处逐一算出扭转剪矢量。
5. **逐端叠加求合力**：在每个端点把直接剪与扭转剪矢量相加，算合力大小。**取合力最大的端点为控制点**——该点就是两剪同向叠加的保守端。
6. **令控制点应力 = 许用值**，解未知尺寸（焊缝长度 l、螺栓直径 d…）。
7. **自查**：先回查第 0 步——载荷线确实不过形心吗？若实际过形心却走了偏心流程 → 回第 0 步按轴向重做。再确认所选控制点的扭转剪与直接剪同向（或锐角、代数同号）。若发现控制点的两剪反向相消 → 选反了，回到第 5 步取合力最大的端点。再核验：用所选控制点求出的尺寸是否 ≥ 用非保守端求出的尺寸（保守端应给出更大/更安全的尺寸）。
8. **确认所问量并据此作答（答非所问门控）**：落笔前明确题面要的是哪个量——"weld length / 焊缝长度"（沿构件长度方向的焊缝段长度 l）、"weld leg size / 焊脚尺寸 h"、"throat thickness / 喉厚 t"、"bolt diameter / 螺栓直径 d"是不同量，数值与单位均不同。算完后报**题面所问的那个量**，不要报求解过程中顺带得到的另一个量。典型翻车：题面问 weld length，解题者因走了"定焊脚"路径而报焊脚尺寸 h——h 与 l 数值差若干倍，即使 h 算对也答非所问。判定动作：把题面"Give your answer as the value of X"里的 X 与最终报出的量名逐字比对；不一致 → 改报 X。

## 举例（通用占位，非任何具体题目）

焊缝群形心在 G，外载荷 F 过群上方某点、偏心 e，扭矩 T=F·e 使群绕 G 转动。群两端点 A、B 到 G 等距，A 端扭转剪方向与直接剪同向（叠加，合力大），B 端反向（相消，合力小）。控制点取 A（保守端），令 τ_A = τ_all·h·(throat factor) 解焊缝长度 l。禁止取 B 端令 τ_B = τ_all·… 求 l——B 是被扭矩减轻的非保守端，所得 l 偏小、不安全。判定动作：在每个端点画直接剪与扭转剪方向箭头，同向叠加端即控制点。
