# S-N 疲劳离散数据：S–log N 半对数图解，禁止 log–log Basquin 回归

## 触发情形

题面给一张离散 S-N 数据表（若干个 (S_i, N_i) 实测点），常含低应力端趋于水平的疲劳极限平台，要求由给定寿命反解应力、或由应力反解寿命，且常有多个子问。教材标准方法（Callister 等）是在 **S–log N 半对数图**（S 线性轴、log N 对数轴）上沿有限寿命区数据点作最佳直线后图解读数。典型翻车：把全部有限寿命点做 log–log 最小二乘拟合成单一 Basquin 幂律 S=A·N^b 再反解——该模型与教材方法不一致，会平滑疲劳极限膝点、使插值偏离教材读数。

## 硬约束

- **用 S–log N 半对数图，不用 log–log 图**：横轴 log N（对数），纵轴 S（线性，非对数）。在有限寿命区沿数据点作最佳直线（目视/线性回归 S = a + b·log N 均可），由该直线读数或反解。**禁止**用 log S–log N 双对数图拟合成 Basquin 幂律 S=A·N^b——那是不同的模型，不是教材该题型的预期方法。
- **疲劳极限平台单独处理**：低应力端趋于水平的段是疲劳极限/耐久极限 S_e，不属有限寿命直线区——取平台值，不并入直线拟合/绘制。
- **同一有限寿命直线贯穿多问**：多个子问代入同一条 S–log N 直线（同一组 a、b），不得逐问换相邻两点局部插值得折线。
- **已给解析参数时直接代入**：题面已给 S–log N 直线方程或 (a, b) → 直接代入，不需拟合。题面已给 Basquin (A, b) 并明确要求用 Basquin → 按题面要求用 Basquin，本技能其余步骤跳过。

## 执行步骤

1. **确认数据性质与题面要求**：题面给的是离散表还是已知解析参数？是否明确要求用 Basquin/幂律？已给 S–log N 参数 → 直接代入；明确要求 Basquin → 按题面走，本技能跳过。离散表且未指定模型 → 用 S–log N 半对数图解，继续。
2. **分区**：把点按 N 升序排列，区分有限寿命直线区（S–log N 上近似共线的点）与疲劳极限水平段（低应力趋于平台的点）。直线区点用于拟合/绘制；平台段单独处理取 S_e。
3. **S–log N 直线**：对直线区全部点 (log N_i, S_i) 作最佳直线 S = a + b·log N（线性回归或目视最佳直线）。记录 a、b 及所用点数。注意纵轴是 S（线性），不是 log S。
4. **统一反解各问**：每个子问代入同一条 S = a + b·log N（或反解 N = 10^((S−a)/b)）。所有子问共用第 3 步的同一组 a、b。
5. **自查（硬门控）**：
   - 我是否在 S–log N 半对数图上工作（纵轴 S 线性）？若发现自己在 log S–log N 双对数图上拟合 → 模型选错，回第 3 步改为 S–log N。
   - 我是否用了 Basquin 幂律 S=A·N^b 做 log–log 最小二乘？若是且题面未明确要求 Basquin → 回第 3 步改为 S–log N 直线。
   - 多个子问是否用了同一组 a、b？逐个检查反解式，若各问 a、b 不同 → 回第 4 步统一。
   - 疲劳极限平台段是否被误并入直线区？若把平台段点也塞进直线拟合 → 直线被拉平，回第 2 步剔除平台段。
6. **独立验证**：换一条路径确认——如用直线残差检查各点偏离直线的程度是否合理；或取所问 N 等于某实测点 N_i 看直线是否给出接近 S_i 的值（边界一致性）。多问时另查各问结果是否落在同一条 S–log N 直线上。

## 举例（通用占位，非任何具体题目）

表给有限寿命区 m 个点 (S_i, N_i) 及低应力平台 S_e，题面分多问求不同 N 对应的 S。
- 正确：在 S–log N 图上对 m 个有限寿命点作最佳直线 S=a+b·log N；各问代入同一直线反解；疲劳极限取平台 S_e。
- ❌ 错误（模型选错）：对 m 个点做 log–log 最小二乘拟合成 Basquin 幂律 S=A·N^b 再反解——模型与教材方法不一致，平滑膝点，插值偏离教材读数。
- ❌ 错误（折线）：逐问取相邻两点局部插值得折线段，各问 a、b 不同，结果彼此不自洽。

判定动作：写下拟合式后检查——纵轴是 S（线性）还是 log S？若是 log S 且题面未要求 Basquin → 回第 3 步改为 S–log N 半对数直线。
