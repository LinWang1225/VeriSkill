# 区熔：单步平衡偏析 vs 多道次分布方程

## 触发情形

题面涉及区熔(zone refining)、分凝系数 k (= C_s/C_l 界面平衡比)、液区(zone)浓度、固相浓度分布，问"上一遍/前一遍 pass 后液区浓度""经过 n 道后某位置浓度""区熔达到某纯度需几遍"等。须先判清问的是**单步界面平衡**还是**跨道次分布**——两者用不同公式，混用必错。

## 两条公式的适用边界（核心辨析）

- **单步平衡偏析** C_s = k·C_l（或 C_l = C_s/k）：只描述**同一瞬间**固–液界面处共存的固相浓度 C_s 与液相浓度 C_l 之间的平衡。适用：题面给某点固相浓度问"与之平衡的液相浓度"，或单次凝固界面平衡。**不适用**：问"上一遍 pass 的液区浓度"——那是**不同时刻/不同道次**的量，界面平衡式联系的是同一时刻的两侧，跨道次须用分布方程。
- **区熔一次通过分布方程** C_s(x) = C₀[1 − (1−k)·e^{−kx/l}]（l 为液区长度，C₀ 为初始均匀浓度，x 为距起始端距离）：描述液区从左到右扫一遍后**固相沉积的浓度分布**。多道时用递推：第 n 道的浓度分布由第 n−1 道的分布经一次通过方程卷积/积分得到，或用 Pfann 多道递推关系联系相邻两遍。
- **极端纯化极限**（液区远长于特征距离、多道后）：C_l ≈ C_s/k 退化形式有时可用，但前提是题面明确说"已达稳态纯化极限"；题面说"上一遍 pass"≠ 稳态极限，须走分布方程或递推。

## 执行步骤

1. **判道次结构**：从题面圈出"single pass / one pass / 上一遍 / previous pass / n passes / after N passes / 最终纯度"等关键词。
   - 问"与某固相平衡的液相浓度"（同一瞬间）→ 单步平衡偏析 C_s = k·C_l。
   - 问"上一遍/前一遍/n 道后的浓度"（不同道次）→ 分布方程或递推，**不得**用 C_s = k·C_l 联系跨道量。
2. **定分布方程参数**：若属多道，确认 C₀（初始浓度）、k（分凝系数）、l（液区长度）、x（位置）。注意 k 的来源——题面给定则用题面值；题面未给须查表并注明来源（参见 g-sci-explicit-assumptions），不同来源 k 值差异会使结果波动，须声明所取值。
3. **多道递推**：第 n 道浓度 = 一次通过方程作用于第 n−1 道分布。若题面给"已达某纯度"反问"上一遍浓度"，按递推关系反解，不要用单步平衡式反解。
4. **单位**：ppb/ppm/wt%/at% 间换算按 g-matsci-percent-basis-reference；浓度量级独立粗估（如纯化方向应使杂质浓度递减）。
5. **自查**：我用的公式联系的是同一时刻的量还是跨道次的量？若跨道次却用了 C_s = k·C_l → 错模型，回到第 1 步改用分布方程/递推。

## 举例（通用占位，非任何具体题目）

题面问"区熔已使某处固相浓度达 C_target，求上一遍 pass 时该处液区浓度"：这是跨道次问题，须用一次通过分布方程（或递推关系）联系上一遍与当前遍的浓度，**不得**用 C_l = C_s/k（该式只给同一瞬间界面两侧，不给"上一遍"的液区）。判定动作：题面出现"previous pass / 上一遍 / after N passes"→ 走分布方程；只出现"与之平衡的液相浓度"→ 走单步平衡偏析。
