# 缺关键输入时不得捏造：保留为函数或声明不可定解

## 触发情形

题面给了一组参数，要求算某个量，但该量本质上还依赖一个题面未给的变量（速率依赖时间、通量依赖位置、浓度依赖时刻…）。典型翻车：为了让式子"算完"，自行选一个使中间量取整洁值的输入点（如令某指数 = 某整数反推时间），把凭空凑出的单一数值当最终答案提交。该数值不由题面数据决定，换一个取点就差若干量级。

## 硬约束

- **禁止**引入题面未给、非公认物理常数、且非由题面约束关系导出的数值输入。凡引入的数值须可追溯到题面原文、公认常数表、或题面约束的代数推导。
- 若目标量 = f(x) 而题面未给 x，则答案须保留为 f(x)（显式写出 x 的函数式），或声明"该量取决于 x，题面未指定 x 故无单一数值解"。

## 执行步骤

1. **列依赖**：写出目标量所依赖的全部变量，逐个标注"题面给了 / 题面没给"。
2. **对没给的变量，先穷尽推导再判欠定**（关键：勿一见"目标量依赖某变量"就宣布欠定停手）：
   - (a) **能否用题面给的约束/关系消去它**——逐条扫题面给的等式/约束，看能否解出该变量。典型：题面给了转化分数 y 而非时间 t，可由 Avrami 式 y=1−e^{−ktⁿ} 反解 t=(−ln(1−y)/k)^(1/n) 再代入速率式 ṗ=nkt^{n−1}e^{−ktⁿ}；题面给了某时刻的浓度/转化率/位置，可反解出该时刻再代入。**这一步必须做尽**，不得跳过直接判欠定。
   - (a′) **题面是否显式或隐式指定了评估点**——"计算反应速率""求 t 时刻的 X"等措辞常指一个题面已给（或由给定数据反解出）的特定时刻/位置，而非"速率作为 t 的函数"。若题面要的是**一个数值**（带单位如 s⁻¹），则必须代入第 (a) 步解出的（或题面给的）时刻算出单一数值，**不得**只给含 t 的符号式。
   - (b) 第 (a)(a′) 都走不通、变量确消不去 → 将答案写成该变量的显式函数，注明"需指定该变量才能给数值"。
   - (c) 题面暗示要单一数值但确无足够信息 → 声明问题不可定解，指出缺哪个参数，不要凑数。
3. **自查**：扫一遍解答里每个代入的数值——它来自题面、公认常数、还是题面约束的推导？若有任何一个数值来源是"我选了一个整洁值"→ 删掉，回第 2 步按 (b) 或 (c) 处理。另查：我是否因"目标量依赖某变量"就停在符号式而未尝试第 (a) 步反解？若题面给了可反解该变量的约束（如转化率、某时刻浓度）而我没用来消元 → 回第 2 步(a) 补做反解再代入。

## 欠定误判（反向翻车）

本技能的常见**反向**误用：题面其实给了足够信息（直接给了评估时刻，或给了可反解时刻的转化率/浓度），解题者却把"速率随 t 变化"当成"题目欠定"，停在符号函数不代入，把本可确定的数值答成"无单一值"。判定：题面所问带单位且要单一数值时，符号式不算完成——必须回到第 2 步(a)(a′) 找到代入值算出数值；只有第 (a)(a′) 确实无路可走才可按 (b)(c) 保留符号式或声明欠定。

## 举例（通用占位，非任何具体题目）

目标量 r = f(t; a, b)，题面给了参数 a、b 但没给时间 t。禁止：令某中间量 = 整数 c 反推 t=t₀ 再算出 r(t₀) 当答案——t₀ 不由题面决定。正确：报 r(t) = f(t; a, b) 的显式式，注明"题面未指定 t，r 为 t 的函数，需给定 t 才有数值"。若题面另给转化分数 y₀：由 y₀ = 1−e^{−…} 反解 t 代入 f → 得单一数值，此路径合法（t 由题面给的 y₀ 导出，非凭空选取）。反向例：题面问"计算反应速率（s⁻¹）"并给了可反解 t 的转化率 y₀，解题者却只给 ṗ(t) 符号式并称"欠定"→ 误判，须由 y₀ 反解 t 代入算出单一 s⁻¹ 数值。
