# 缺关键输入时不得捏造：保留为函数或声明不可定解

## 触发情形

题面给了一组参数，要求算某个量，但该量本质上还依赖一个题面未给的变量（速率依赖时间、通量依赖位置、浓度依赖时刻…）。典型翻车：为了让式子"算完"，自行选一个使中间量取整洁值的输入点（如令某指数 = 某整数反推时间），把凭空凑出的单一数值当最终答案提交。该数值不由题面数据决定，换一个取点就差若干量级。

## 硬约束

- **禁止**引入题面未给、非公认物理常数、且非由题面约束关系导出的数值输入。凡引入的数值须可追溯到题面原文、公认常数表、或题面约束的代数推导。
- 若目标量 = f(x) 而题面未给 x，则答案须保留为 f(x)（显式写出 x 的函数式），或声明"该量取决于 x，题面未指定 x 故无单一数值解"。

## 执行步骤

1. **列依赖**：写出目标量所依赖的全部变量，逐个标注"题面给了 / 题面没给"。
2. **对没给的变量，先穷尽推导再判欠定**（关键：勿一见"目标量依赖某变量"就宣布欠定停手）：
   - (a) **能否用题面给的约束/关系消去它**——逐条扫题面给的等式/约束，看能否解出该变量。典型：题面给了转化分数 y 而非时间 t，可由 Avrami 式 y=1−e^{−ktⁿ} 反解 t=(−ln(1−y)/k)^(1/n) 再代入速率式 ṗ=nkt^{n−1}e^{−ktⁿ}；题面给了某时刻的浓度/转化率/位置，可反解出该时刻再代入。**这一步必须做尽**，不得跳过直接判欠定。
   - (a′) **题面是否显式或隐式指定了评估点**——"计算反应速率""求 t 时刻的 X"等措辞常指一个题面已给（或由给定数据反解出）的特定时刻/位置，而非"速率作为 t 的函数"。若题面要的是**一个数值**（带单位如 s⁻¹），则必须代入第 (a) 步解出的（或题面给的）时刻算出单一数值，**不得**只给含 t 的符号式。
   - (a″) **题面是否要的是表达式本身**——"导出/写出/求…的速率表达式""derive the rate equation""express ṗ as a function of t""compute the rate"（速率/通量/浓度等本质随自变量变化的量，题面只给参数不给评估点）等措辞表明所求就是一个含自变量的符号式，而非单一数值。此时**含 t 的表达式即为完整答案**，不得以"未给 t 故不可解"拒答。关键辨析：表达式带单位（如 s⁻¹）不等于题面要单一数值——一个函数 r(t) 同样有单位 s⁻¹；判据是题面措辞"导出/写出/express/compute…的式子/速率"vs"计算/求…在…时的（单一）值"，不是看单位。若措辞属前者且第 (a) 步无法从题面约束消去 t → 按 (b) 报出含 t 的显式函数式，这算完成，不算欠定。
   - (b) 第 (a″) 命中（题面要表达式）或第 (a)(a′) 都走不通（题面要数值但变量消不去）→ 将答案写成该变量的显式函数。**关键：当 (a″) 命中（题面要的就是表达式/速率函数）时，该函数式即终答，直接报出，不得附加"欠定 / no single numerical value / 不可定解 / 需指定该变量才能给数值"等拒答标注**——该标注会把一个正确表达式误标为欠定，触发 underdetermined 判据把对的答案判错。仅当题面明确要单一数值（"计算…在…时的值"）且第 (a)(a′) 确实消不去变量时，才按 (c) 声明不可定解。
   - (c) 题面暗示要单一数值但确无足够信息 → 声明问题不可定解，指出缺哪个参数，不要凑数。
3. **自查**：扫一遍解答里每个代入的数值——它来自题面、公认常数、还是题面约束的推导？若有任何一个数值来源是"我选了一个整洁值"→ 删掉，回第 2 步按 (b) 或 (c) 处理。另查：我是否因"目标量依赖某变量"就停在符号式而未尝试第 (a) 步反解？若题面给了可反解该变量的约束（如转化率、某时刻浓度）而我没用来消元 → 回第 2 步(a) 补做反解再代入。再查：我是否把"题面要表达式"误当"题面要数值"而拒答？若题面措辞为"导出/写出/express/compute…的式子/速率"且第 (a) 步确无消元路径 → 含变量的符号式即为终答，不拒答。**末查（关键）**：我的最终答案里是否含"欠定 / no single numerical value / 不可定解 / 需指定该变量才能给数值"等拒答标注？若题面要的是表达式/速率函数且我已写出正确表达式 → **删掉该标注**，只留表达式本身；拒答标注仅用于题面明确要单一数值却确无足够信息的情形。

## 欠定误判（反向翻车）

本技能的常见**反向**误用：题面其实给了足够信息（直接给了评估时刻，或给了可反解时刻的转化率/浓度），解题者却把"速率随 t 变化"当成"题目欠定"，停在符号函数不代入，把本可确定的数值答成"无单一值"。判定：题面所问带单位且要单一数值时，符号式不算完成——必须回到第 2 步(a)(a′) 找到代入值算出数值；只有第 (a)(a′) 确实无路可走才可按 (b)(c) 保留符号式或声明欠定。

## 举例（通用占位，非任何具体题目）

目标量 r = f(t; a, b)，题面给了参数 a、b 但没给时间 t。禁止：令某中间量 = 整数 c 反推 t=t₀ 再算出 r(t₀) 当答案——t₀ 不由题面决定。正确：报 r(t) = f(t; a, b) 的显式式作为终答；若题面措辞为"compute/derive the rate"（要表达式）则**只报表达式，不加任何"欠定/no single numerical value"标注**。若题面措辞为"计算…在…时的值"（要单一数值）且确无约束可消去 t → 此时才声明"该量取决于 t，题面未指定 t 故无单一数值解"。若题面另给转化分数 y₀：由 y₀ = 1−e^{−…} 反解 t 代入 f → 得单一数值，此路径合法（t 由题面给的 y₀ 导出，非凭空选取）。反向例：题面问"计算反应速率（s⁻¹）"并给了可反解 t 的转化率 y₀，解题者却只给 ṗ(t) 符号式并称"欠定"→ 误判，须由 y₀ 反解 t 代入算出单一 s⁻¹ 数值。又一反向例：题面问"compute the rate"只给 n、k 不给 t，解题者写出正确 ṗ(t) 式却附注"no single numerical value——t not specified"→ 表达式本是对的终答，拒答标注把它误标为欠定而判错；正确做法是只报 ṗ(t) 式，不加标注。
