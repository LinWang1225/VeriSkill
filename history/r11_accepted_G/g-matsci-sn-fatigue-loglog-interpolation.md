# S-N 疲劳离散数据：统一 Basquin log-log 拟合，禁止逐问局部插值

## 触发情形

题面给一张离散 S-N 数据表（若干个 (S_i, N_i) 实测点），有限寿命区有多个点共处于同一条 Basquin 关系 S = A·N^b（即 log S = log A + b·log N 线性），要求由给定寿命反解应力、或由应力反解寿命，且常有多个子问。典型翻车：每个子问取包围该问 N 的两个相邻点做局部 log-log 插值，每次换一对点、得到一条折线而非同一条 S–N 曲线，三个子问结果彼此不自洽且偏离整体趋势。

## 硬约束

- **统一拟合**：有限寿命区全部点共处于一条 Basquin 律时，先用**全部**有限寿命点做一次 log-log 最小二乘拟合：
  ```
  log S = log A + b·log N   （对全部有限寿命点 (log N_i, log S_i) 最小二乘）
  ```
  定出统一的 A、b，再由这一条曲线统一反解所有子问。
- **同一曲线贯穿多问**：多个子问（求不同 N 对应的 S、或不同 S 对应的 N）必须代入同一条拟合曲线（同一组 A、b），不得每问换一对点。判定：写下每个子问的反解式，里面出现的 A、b 应是同一组数；若各问的 A、b 不同 → 用错方法。
- **耐久极限单独处理**：若数据在低应力端趋于水平（疲劳极限/耐久极限 S_e），该段不属 Basquin 幂律区——疲劳极限取水平段值或单独判定，不并入幂律拟合。拟合只用有限寿命区（幂律区）的点。
- **外推警告**：所问 N 落在拟合点范围之外是外推，须标注"外推，可靠性降低"。
- **已给 Basquin 参数时直接代入**：题面已给 (A, b) → 直接 S = A·N^b，不需拟合。

## 执行步骤

1. **确认数据性质**：题面给的是离散表还是已知 Basquin 参数 (A, b)？已给参数 → 直接代入，本技能其余步骤跳过。离散表 → 继续。
2. **分区**：把点按 N 升序排列，区分有限寿命幂律区（log-log 上近似共线的点）与耐久极限水平段（低应力趋于平台的点）。幂律区点用于拟合；平台段单独处理。
3. **统一 log-log 最小二乘拟合**：对幂律区全部点 (log N_i, log S_i) 做一次线性最小二乘，定出 log A 与 b（即斜率 b、截距 log A）。记录 A、b 及所用点数。
4. **统一反解各问**：每个子问代入同一条 S = A·N^b（或反解 N = (S/A)^(1/b)）。所有子问共用第 3 步的同一组 A、b。
5. **自查（硬门控）**：
   - 我是否对幂律区全部点做了一次统一拟合？若只取两个相邻点定 A、b → 退化为局部插值，回第 3 步改为全点最小二乘。
   - 多个子问是否用了同一组 A、b？逐个检查反解式，若各问 A、b 不同 → 回第 4 步统一。
   - 耐久极限段是否被误并入幂律拟合？若把平台段点也塞进 log-log 拟合 → 拟合线被拉平，回第 2 步剔除平台段。
   - 所问 N 是否在拟合范围内？范围外 → 标注外推。
6. **独立验证**：换一条路径确认——如用拟合残差检查各点偏离拟合线的程度是否合理（残差应小且无系统偏置）；或取所问 N 等于某实测点 N_i 看拟合曲线是否给出接近 S_i 的值（边界一致性）。多问时另查三问结果是否落在同一条拟合曲线上（任取两问反解 (N,S) 对，看是否满足 S = A·N^b）。

## 举例（通用占位，非任何具体题目）

表给幂律区 m 个点 (S_i, N_i)，共处一条 Basquin 律，题面分三问求不同 N 对应的 S。
- 正确：对 m 个点做一次 log-log 最小二乘得统一 A、b；三问分别代入同一 S = A·N^b 反解，结果共曲线、彼此自洽。
- ❌ 错误：第 1 问取相邻两点 (N_j, S_j)、(N_{j+1}, S_{j+1}) 定 A_1、b_1；第 2 问换另一对相邻点定 A_2、b_2；第 3 问再换一对——三问各得一条折线段，A、b 各不相同，结果彼此不自洽且偏离整体趋势。

判定动作：写下各问反解式后，检查式中 A、b 是否为同一组数；若各问 A、b 不同 → 回第 3 步改为幂律区全点统一最小二乘，再统一代入。
