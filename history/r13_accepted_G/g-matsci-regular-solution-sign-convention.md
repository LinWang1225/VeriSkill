# Regular-solution 符号约定：Ω 符号决定物理情形，禁止 |Ω| 替换

## 触发情形

题面给 regular-solution 参数 Ω（交互能）并要求算溶解度、活度系数、solvus 组成等。典型翻车：不先据 Ω 符号判定物理情形，机械套用 solvus 方程，并把带符号的 Ω 换成 |Ω| 去强行求根——这在 Ω<0（完全互溶、本无 miscibility gap）时伪造出一个不存在的 solvus 根，得到错误溶解度。

## Ω 符号与物理情形

- **Ω > 0**（A-B 交互排斥）：同种原子偏好聚集，低温下存在 miscibility gap，solvus 方程 ln x_B + Ω(1−x_B)²/(RT) = 0 在 0<x_B<1 内有物理根。可用 solvus 方程求溶解度。
- **Ω < 0**（A-B 交互吸引）：异种原子偏好混合，**完全互溶，不存在 miscibility gap**。solvus 方程 ln x_B + Ω(1−x_B)²/(RT) = 0 在 0<x_B<1 内**无物理根**（代入有符号 Ω 后无解）。此时不得套用 solvus 方程求根。
- **稀溶液溶解度公式** x_B = exp(Ω/RT)：用**有符号** Ω 直接代入。Ω<0 时给出 x_B<1（有限溶解度），Ω>0 时给出 x_B>1（提示稀溶液近似已不适用，须用 solvus 方程）。

## 硬约束

1. **禁止以 |Ω| 替换有符号 Ω**：在任何 regular-solution 方程（solvus 方程、活度系数 ln γ_B = Ω(1−x_B)²/(RT)、稀溶液公式）中，Ω 必须保留题面给定的符号。把 Ω 换成 |Ω| 翻转了交互项的物理意义：Ω<0（吸引、完全互溶）被伪装成 Ω>0（排斥、有 gap），从而给一个本无解的方程伪造出根。这是已坐实的翻车模式。
2. **Ω<0 时不得套用 solvus 方程**：solvus 方程仅对 Ω>0 有物理根。题面给 Ω<0 又要求算溶解度时，用稀溶液公式 x_B=exp(Ω/RT) 直接求解，不要以"稀溶液近似不够精确""模型适用范围"为由另起 solvus 方程——该方程在此物理情形下根本不适用，所得"精确解"是符号翻转伪造的假根。
3. **不得以"模型适用范围"为由从稀溶液公式切换到 solvus 方程**：稀溶液近似确实有适用范围（x_B→0），但超出范围时的正确做法是检查 Ω 符号——若 Ω<0 则不存在 miscibility gap、无 solvus 可言，稀溶液公式就是该题型的预期解法；若 Ω>0 且 x_B 不小才改用 solvus 方程（仍用有符号 Ω）。

## 执行步骤

1. **读 Ω 符号**：从题面取 Ω 的符号（正/负/零），在解答开头写一行"Ω = …（正/负），对应物理情形：排斥有 gap / 吸引完全互溶 / 理想混合"。
2. **据符号选公式**：
   - Ω > 0：先用稀溶液公式 x_B=exp(Ω/RT) 估算；若结果 x_B 不小（如 >0.1–0.2，视题目精度要求），改用 solvus 方程 ln x_B + Ω(1−x_B)²/(RT) = 0（**有符号 Ω**）数值求解。
   - Ω < 0：直接用稀溶液公式 x_B=exp(Ω/RT)。**不套 solvus 方程**。若题面要求"精确解"，声明"Ω<0 对应完全互溶，无 miscibility gap，稀溶液公式为该题型预期解法"。
   - Ω = 0：理想溶液，完全互溶，x_B 无限制。
3. **全程保留符号**：代入计算时 Ω 带符号直接进指数/方程，不得取绝对值。
4. **自查（硬门控）**：
   - 我是否在任何一步把 Ω 换成了 |Ω|？是 → 立即改回有符号 Ω 重算。
   - Ω<0 时我是否套用了 solvus 方程？是 → 删除该路径，回第 2 步用稀溶液公式。
   - 我是否以"模型适用范围"为由从稀溶液公式切换到了 solvus 方程，却没先检查 Ω 符号？是 → 回第 1 步先定符号再选公式。

## 举例（通用占位，非任何具体题目）

题面给 Ω=Ω₀（Ω₀<0），求 B 在 A 中溶解度。第 1 步：Ω₀<0，吸引交互，完全互溶，无 miscibility gap。第 2 步：用 x_B=exp(Ω₀/RT) 直接算（Ω₀ 带负号进指数），得 x_B<1。不套 solvus 方程。判定动作：若发现自己在写 ln x_B + |Ω₀|(1−x_B)²/(RT) = 0 → 停下，这是符号翻转伪造的假根路径，回第 2 步。

题面给 Ω=Ω₁（Ω₁>0），求溶解度。先用 x_B=exp(Ω₁/RT) 估算；若 x_B 偏大不满足稀溶液近似，改用 solvus 方程 ln x_B + Ω₁(1−x_B)²/(RT) = 0（Ω₁ 保持正号）数值求解。
