# Regular-solution 符号约定：Ω 符号决定物理情形，稀溶公式 x_B=exp(−Ω/RT)

## 触发情形

题面给 regular-solution 参数 Ω（交互能）并要求算溶解度、活度系数、solvus 组成等。典型翻车：(1) 把活度系数写成 ln γ_B=−Ω(1−x_B)²/(RT)（Ω 前多挂负号），导致稀溶公式变成 x_B=exp(Ω/RT)（指数符号取反）；(2) 不先据 Ω 符号判定物理情形，机械套用 solvus 方程或稀溶公式；(3) 把带符号的 Ω 换成 |Ω| 去强行求根——这在 Ω<0（完全互溶、本无 miscibility gap）时伪造出一个不存在的 solvus 根，得到错误溶解度。

## 标准约定与公式

- **活度系数**：ln γ_B = Ω(1−x_B)²/(RT) = Ω·x_A²/(RT)。Ω 前面**没有额外负号**——这是 regular-solution 模型的标准教材约定。若你写出 ln γ_B = −Ω(1−x_B)²/(RT)，说明在 Ω 前多挂了一个负号，后续全部结果符号翻转。
- **稀溶液溶解度公式**：由 a_B = γ_B·x_B = 1（solvus 条件，纯 B 参考）及无限稀释 γ_B^∞ = exp(Ω/RT) 得
  ```
  x_B = exp(−Ω/RT)
  ```
  注意指数里是 **−Ω**，不是 +Ω。若你写出 exp(Ω/RT)，符号取反了。
- **solvus 方程**：ln x_B + Ω(1−x_B)²/(RT) = 0，Ω 带符号直接代入。

## Ω 符号与物理情形

- **Ω > 0**（A-B 交互排斥）：同种原子偏好聚集，低温下存在 miscibility gap。稀溶公式 x_B=exp(−Ω/RT) < 1 → 有限溶解度。若 x_B 不小（如 >0.1–0.2），改用 solvus 方程数值求解（仍用有符号 Ω）。
- **Ω < 0**（A-B 交互吸引）：异种原子偏好混合，**完全互溶，不存在 miscibility gap，无溶解度极限**。稀溶公式 x_B=exp(−Ω/RT) = exp(|Ω|/RT) > 1 → x_B>1 是非物理信号，意为"B 在 A 中完全可溶，无有限溶解度"。此时不得套用 solvus 方程求根（该方程在 Ω<0 时于 (0,1) 内无物理根），也不得报一个有限的 x_B 值——正确答案是"完全互溶"或 x_B=1。
- **Ω = 0**：理想溶液，完全互溶，x_B 无限制。

## 硬约束

1. **活度系数 Ω 前无额外负号**：ln γ_B = Ω(1−x_B)²/(RT)，不是 −Ω(1−x_B)²/(RT)。若你在 Ω 前写了负号 → 后续稀溶公式变成 exp(Ω/RT)（符号取反），Ω<0 时把本应 >1 的值翻成 <1，凭空造出有限溶解度。这是已坐实的翻车模式。
2. **稀溶公式指数是 −Ω**：x_B = exp(−Ω/RT)，不是 exp(Ω/RT)。写下公式后先检查指数里 Ω 的符号——应是负号。
3. **禁止以 |Ω| 替换有符号 Ω**：在任何 regular-solution 方程中，Ω 必须保留题面给定的符号。把 Ω 换成 |Ω| 翻转了交互项的物理意义：Ω<0（吸引、完全互溶）被伪装成 Ω>0（排斥、有 gap），从而给一个本无解的方程伪造出根。
4. **Ω<0 时不得套用 solvus 方程、不得报有限 x_B**：solvus 方程仅对 Ω>0 有物理根。题面给 Ω<0 又要求算溶解度时，正确答案是"完全互溶，无 miscibility gap，无有限溶解度极限（x_B=1）"。不要以"稀溶液近似不够精确""模型适用范围"为由另起 solvus 方程——该方程在此物理情形下根本不适用，所得"精确解"是符号翻转伪造的假根。
5. **不得以"模型适用范围"为由从稀溶液公式切换到 solvus 方程**：稀溶液近似确实有适用范围（x_B→0），但超出范围时的正确做法是检查 Ω 符号——若 Ω<0 则完全互溶、无 solvus 可言；若 Ω>0 且 x_B 不小才改用 solvus 方程（仍用有符号 Ω）。

## 执行步骤

1. **读 Ω 符号**：从题面取 Ω 的值与符号，在解答开头写一行"Ω = …（正/负），对应物理情形：排斥有 gap / 吸引完全互溶 / 理想混合"。
2. **写活度系数**：ln γ_B = Ω(1−x_B)²/(RT)。检查 Ω 前是否有额外负号——若有，删掉。
3. **据符号选公式**：
   - Ω > 0：先用稀溶公式 x_B=exp(−Ω/RT) 估算；若结果 x_B 不小（视题目精度要求），改用 solvus 方程 ln x_B + Ω(1−x_B)²/(RT) = 0（**有符号 Ω**）数值求解。
   - Ω < 0：**完全互溶，无 miscibility gap，无有限溶解度极限**。报 x_B=1 或"完全互溶"。不套 solvus 方程，不报有限 x_B。若题面要求"精确解"，声明"Ω<0 对应完全互溶，无 miscibility gap，溶解度极限 x_B=1"。
   - Ω = 0：理想溶液，完全互溶，x_B 无限制。
4. **全程保留符号**：代入计算时 Ω 带符号直接进指数/方程，不得取绝对值。
5. **自查（硬门控）**：
   - 我写的活度系数是否在 Ω 前多挂了负号（写成 −Ω）？是 → 删掉负号重算，稀溶公式随之从 exp(Ω/RT) 修正为 exp(−Ω/RT)。
   - 我写的稀溶公式指数里是 −Ω 还是 +Ω？若是 +Ω → 符号取反，改为 −Ω。
   - 我是否在任何一步把 Ω 换成了 |Ω|？是 → 立即改回有符号 Ω 重算。
   - Ω<0 时我是否套用了 solvus 方程或报了一个有限 x_B？是 → 删除该路径，回第 3 步报"完全互溶"。
   - 我是否以"模型适用范围"为由从稀溶液公式切换到了 solvus 方程，却没先检查 Ω 符号？是 → 回第 1 步先定符号再选公式。

## 举例（通用占位，非任何具体题目）

题面给 Ω=Ω₀（Ω₀<0），求 B 在 A 中溶解度。第 1 步：Ω₀<0，吸引交互，完全互溶，无 miscibility gap。第 3 步：报"完全互溶，无有限溶解度极限（x_B=1）"。不套 solvus 方程，不报有限 x_B。判定动作：若发现自己在写 ln x_B + |Ω₀|(1−x_B)²/(RT) = 0 或 x_B=exp(Ω₀/RT)<1 → 停下，符号翻转伪造了假根/假溶解度，回第 3 步报完全互溶。

题面给 Ω=Ω₁（Ω₁>0），求溶解度。先用 x_B=exp(−Ω₁/RT) 估算（注意指数是 −Ω₁）；若 x_B 偏大不满足稀溶液近似，改用 solvus 方程 ln x_B + Ω₁(1−x_B)²/(RT) = 0（Ω₁ 保持正号）数值求解。
