# 材料牌号不是答案来源：经验系数只从教材查，不从牌号反推

## 触发情形

题面给一个材料牌号（如 "65-45-12 cast iron"、"AISI 1045"、"ASTM A36"）和一项实测量（布氏硬度 HB、洛氏硬度 HRC、压痕参数…），要求由实测量推算强度（屈服、抗拉）或其他力学性能。典型翻车：解题者注意到牌号的数字恰好等于规格标称强度（如 65-45-12 的 65 ksi 抗拉 / 45 ksi 屈服下限），于是从"硬度 × 系数 = 牌号标称强度"反推出系数，再代回算出恰好复现牌号标称值的强度。这等于用待求量自己证明自己——循环论证，系数不是来自独立经验关系而是来自答案本身。

## 硬约束

- **牌号只是标识**：牌号里的数字（无论它们是否恰好等于规格强度下限、成分百分数、或热处理代号）**不得**作为求解目标量的数值来源。牌号唯一允许的用途是：确认材料类别（ductile iron / 灰铸铁 / 钢 / 铝合金…）以选择对应的那一组教材经验系数。
- **规格下限不是实测值**：牌号规格给出的强度（如最低屈服/抗拉下限）是**批次验收下限**，不是该构件的实测强度。题面要求"用压痕硬度实测/推算该构件的真实强度"时，须由实测硬度经教材经验关系算出，**禁止**把规格下限值直接当作实测强度提交。规格下限与实测值的区别：下限是"该牌号所有合格件都必须超过的门槛"，实测值是"这一个具体构件的实际强度"，后者经硬度换算得到、通常高于下限。把下限当实测值等于忽略题面给的硬度测量信息、用规格代替测量。
- **经验系数只从教材/标准查**：硬度—强度换算系数（如 σ_UTS ≈ k·HB 中的 k）须来自教材或标准给出的、针对该材料类别的通用经验关系，并注明出处。**禁止**由"牌号标称强度 ÷ 实测硬度"反算 k 再使用。
- **自洽性不等于正确性**：算出的强度落在牌号规格区间内，只能作为合理性旁证，不能作为验证通过的依据——更不能反过来调整系数去凑规格下限。独立验证须用一条不经过该系数的第二路径（见 g-sci-independent-verify）。
- **牌号属性比值不是独立验证**：用牌号规格里两个属性的比值（如屈服/抗拉 = Y_min/U_min）去"交叉验证"算出的两个强度，是循环论证——该比值本身就从同一组牌号规格数字导出，任何用同一硬度经同一类线性律算出的两个强度都会自动满足这个比值，验不出系数是否独立。独立验证须换公式或换数据来源，不能换一个"从牌号派生的比值"。
- **逐位吻合牌号下限是红线**：由实测硬度经独立经验关系算出的强度，在正常情形下不会逐位等于牌号规格下限的换算值（经验关系带不确定度，实测件强度通常高于下限）。若最终强度逐位等于牌号下限换算值 → 极可能经验系数是从牌号反推的、或图读数被牌号数字锚定，回第 3 步重查系数出处与图读数独立性。
- **只对教材显式给出的关联式代入**：教材经验关系并非对每个力学性能都存在。若教材/标准只给"硬度→抗拉"关联而不给"硬度→屈服"关联，不得自造一个硬度→屈服线性律填补空缺——屈服须由题面指定的其他权威途径（如等级规定、题面给出应力–应变曲线）取得。自造经验律的系数无独立来源，等于把待求量偷换成来源不明的常数。

## 执行步骤

1. **圈出牌号并解读其含义**：确认牌号标识的是哪类材料（用于选对经验关系组），同时明确牌号里的数字代表什么（规格下限 / 成分 / 热处理代号）。把"这些数字不是答案来源"写明。
2. **从实测量出发**：用题面给的压痕/硬度测量值算出硬度数（如 HB），这是推导的唯一起点。
3. **查教材经验关系**：针对第 1 步确认的材料类别，从教材/标准查取硬度—强度经验换算式及其系数，注明出处（教材名、章节/表号）。系数是预先给定的常数，不是本题待定。
4. **代入计算**：用查得的系数和实测硬度算出强度。不得在过程中出现"由牌号标称值 ÷ HB 定系数"这一步。
5. **自查（硬门控）**：
   - 我是否把牌号规格下限/标称值直接当作答案提交？若最终强度值等于牌号规格下限且未经过硬度换算 → 用规格代替了实测，回第 2 步从实测硬度重新推算。
   - 我用的系数是从教材查的，还是从牌号数字算出来的？若系数来源是"牌号标称强度 / 实测硬度"→ 循环论证，回第 3 步改用教材系数。
   - 我的"验证"是不是把算出的强度拿去和牌号标称值比对就完事？若是 → 这只查方向不查正误，须补一条独立第二路径（换公式/换数据来源重算），见 g-sci-independent-verify。
   - 解答里是否出现"为使结果等于牌号标称值故取系数 = …"这类倒推语句？若有 → 删除，回第 3 步。
   - 我的"独立验证"是不是用了牌号两个属性的比值（如 Y_min/U_min）去核对两个算出强度的比值？若是 → 该比值源自牌号规格，不是独立路径，删掉，改用 g-sci-independent-verify 的换公式/换数据来源路径。
   - 最终强度值是否逐位等于牌号规格下限的换算值？若是 → 系数极可能从牌号反推，回第 3 步重查每个系数的具体教材出处。
   - 我是否对一个教材未给关联式的性能（如硬度→屈服）自造了线性律？若是 → 删掉自造律，改用题面指定的权威途径（等级规定/应力–应变曲线）取得该性能。

## 举例（通用占位，非任何具体题目）

题面给牌号 G（其数字恰等于规格抗拉下限 U_min 与屈服下限 Y_min）和实测硬度 H，要求推抗拉与屈服强度。
- 正确：由牌号 G 确认材料类别 → 查教材得该类别通用关系 σ_UTS ≈ k_1·H、σ_y ≈ k_2·H（k_1、k_2 为教材常数）→ 代入 H 算出两个强度。算得值落在 [U_min, …] 区间内仅作旁证。
- ❌ 错误：取 k_1 = U_min / H、k_2 = Y_min / H（从牌号标称值反推系数）→ 代回得 σ_UTS = U_min、σ_y = Y_min，恰好复现牌号——这是用答案自己证明自己，系数无独立来源，任何硬度都会算出同一标称值，实测硬度信息被浪费。

判定动作：写下系数后追问"这个系数是从哪本书/哪张表查的？"——若答不上具体出处、或出处是"由牌号数字算得"→ 循环论证，回第 3 步改用教材系数并注明出处。
