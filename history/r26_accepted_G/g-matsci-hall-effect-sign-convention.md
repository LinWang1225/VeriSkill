# Hall 效应符号约定：载流子符号只计入一次

## 触发情形

题面涉及 Hall 效应：给电导率/迁移率/载流子浓度，求 Hall 电压或所需磁场；或给 Hall 电压求载流子浓度/类型；或问 Hall 系数符号。典型翻车：在 Hall 电压公式前手写一个负号"因为电子带负电"，同时又把 q=-e（带符号）代入分母——负号被计入两次，等价于把电子当成空穴，所得 Hall 系数符号反转，解出的磁场（或电压）符号与正确值相反。

## 硬约束

Hall 系数的定义是 **R_H = 1/(n·q)**，其中 q 是**带符号**的载流子电荷：
- 电子：q = −e → R_H = −1/(n·e) < 0
- 空穴：q = +e → R_H = +1/(n·e) > 0

Hall 电压：**V_H = R_H · I · B / d**（d 为厚度，I、B 取沿各自正方向的代数值）。

**符号只允许从一条路径进入**，不得重复：

| 约定 | 公式形式 | q 的取法 | 前置负号 |
|------|----------|----------|----------|
| A（带符号 q） | V_H = I·B / (n·q·d) | q = −e（电子）/ +e（空穴），带符号 | **无**，不写前置负号 |
| B（显式载流子型） | V_H = ∓ I·B / (n·e·d) | e = \|q\| > 0，恒正 | 电子取 −、空穴取 + |

两种约定等价，择一使用。**禁止**把 A 的带符号 q 与 B 的前置负号叠加——那会把电子的 R_H 从 −1/(ne) 变成 +1/(ne)，符号反转。

## 执行步骤

1. **定载流子类型**：从题面或材料性质判断载流子是电子还是空穴。金属、n 型半导体 → 电子（R_H < 0）；p 型半导体 → 空穴（R_H > 0）。若题面给电导率 σ 和电子迁移率 μ_e，载流子为电子。
2. **选一种符号约定（A 或 B），贯穿全题**：
   - 约定 A：在公式中**不写**前置负号，让 q 带符号承载载流子类型。V_H = I·B/(n·q·d)，电子 q=−e。
   - 约定 B：在公式前写载流子型符号（电子 −、空穴 +），q 取正常数 e=|q|。V_H = −I·B/(n·e·d)（电子）。
3. **代入求解**：按选定约定代入数值，符号自然落到结果上。
4. **符号自查（硬门控）**：报出前检查——
   - 我是否在公式前写了负号**同时** q 取了负值？若是 → 重复计入，删掉其一，回第 2 步重算。
   - 电子的 Hall 系数 R_H 是否为负？若算出 R_H > 0 却载流子是电子 → 符号反了，回第 2 步查约定。
   - 题面给 V_H < 0 且载流子为电子（R_H < 0）：由 V_H = R_H·I·B/d，R_H<0、I>0、d>0 → B 须为正才能得 V_H<0。若解出 B<0 → 符号反了，回第 2 步查是否重复计入负号。
5. **独立验证符号**：换另一条路径确认符号——如用 Lorentz 力方向手判（电子 v×B 受力方向 → 电荷积累面 → Hall 电压极性），与公式算出的符号比对。两者不一致 → 符号约定有误，回第 2 步。

## 举例（通用占位，非任何具体题目）

载流子为电子，已知 σ、μ_e、I、d、V_H，求 B。
- 由 σ = n·e·μ_e 定 n（n 为正数，e 为正常数）。
- 约定 A：V_H = I·B/(n·q·d)，q=−e → B = V_H·n·q·d/I = V_H·n·(−e)·d/I。V_H<0、q<0 → B>0。
- 约定 B：V_H = −I·B/(n·e·d)，e>0 → B = −V_H·n·e·d/I。V_H<0 → B>0。
- ❌ 错误：V_H = −I·B/(n·q·d) 且 q=−e → 负号计入两次 → B 符号反转。

判定动作：写下 Hall 公式后，数一遍负号来源——前置负号和带符号 q 各算一条，只能有一条。两条同时出现 → 删一条重算。
