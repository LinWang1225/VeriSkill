# 两体 Archard 磨损：表面分担因子，别把单表面公式直接套

## 触发情形

题面描述两个固体表面相互滑动磨损（轴对套筒、销对盘、块对环…），问体积磨损或磨损率。Archard 磨损定律单表面形式为 V = K·F·s / H（K 无量纲磨损系数、F 法向力、s 滑移距离、H 表面硬度）。典型翻车：把单表面 V = K·F·s/H 直接当成两体总磨损，丢掉两表面分担的因子。

## 硬约束

- **两体对磨时总磨损由两个表面分担**：每个表面各贡献 V_i = K·F·s / H_i，总磨损 V_total = V_1 + V_2 = K·F·s·(1/H_1 + 1/H_2)。
- **等硬度对（H_1 = H_2 = H）**：V_total = 2·K·F·s / H，相对单表面公式多一个**因子 2**。丢掉这个因子会把总磨损算小一半。
- **异硬度对**：V_total = K·F·s·(1/H_1 + 1/H_2)，不能只用一个表面的硬度。
- 若题面问的是"某一个表面的磨损量"而非总磨损 → 只取该表面的 V_i，不乘 2、不叠加。先看清题面问的是单面还是总磨损。
- **比较两场景的磨损率/体积损失比时，先判两场景何者变化**：题面给"same shaft + sleeve 材质分别为 (a) 钢、(b) 铜，比较 sleeve 磨损率"之类——两场景里 shaft 材质不变，只有 sleeve 材质变。比较的是**变化那个表面（sleeve）的单面磨损** V_sleeve = K·F·s / H_sleeve，比值 = H_sleeve(a) / H_sleeve(b)；不变的 shaft 项在两场景相同、相消，**不进入比值**。典型翻车：把每个场景都按两体总磨损 V_total = K·F·s·(1/H_shaft + 1/H_sleeve) 算再相比，对同材场景 (a) 引入因子 2 而对异材场景 (b) 不引入，致比值被压成正确值的一半。判据：若两场景仅 sleeve 材质不同、shaft 材质相同 → 比的是 sleeve 单面磨损，shaft 项相消，不套两体总磨损。

## 执行步骤

1. **判一两体**：题面是否描述两个表面相互滑动？是 → 两体处理；只有一个表面被磨损（另一表面视为刚性无磨损）→ 单表面。
2. **判"单场景求磨损"还是"多场景比磨损"**：
   - 单场景（题面给一对配对、问该配对的磨损量/率）→ 走第 3–4 步。
   - 多场景比较（题面给两个或多个配对、问磨损率/体积损失之比）→ 先逐场景标出哪个表面材质变了、哪个不变；比值分子分母都只取**变化那个表面**的单面磨损 V_i = K·F·s / H_i，不变表面的项在两场景相同、相消。不得对某场景套两体总磨损再相比——同材场景的因子 2 与异材场景不对称，会把比值压偏。走第 4 步报比值。
3. **定各表面硬度**：两体时分别确认 H_1、H_2。同种材料（题面说"同种钢""both steel"等）→ H_1 = H_2，因子 2 出现；异种材料 → 各取各的硬度。
4. **算总磨损**：V_total = K·F·s·(1/H_1 + 1/H_2)；等硬度时化简为 2·K·F·s/H。
5. **确认题面所问**：题面问"total wear / 总磨损"→ 报 V_total；问"wear on surface X / 某表面磨损"→ 报该面 V_i；问"两场景磨损率之比"→ 报变化表面的单面磨损之比。
6. **自查**：两体等硬度对的总磨损里是否含因子 2？若答案等于 K·F·s/H 而题面是等硬度两体总磨损 → 丢了因子 2，回第 4 步修正。若两体异硬度而答案只用了一个 H → 回第 3 步补齐两个硬度。若题面是两场景比较而我给某场景套了两体总磨损（含因子 2 或 1/H_shaft 项）→ 回第 2 步改取变化表面的单面磨损再相比。

## 举例（通用占位，非任何具体题目）

两体对磨，法向力 F、滑移距离 s、磨损系数 K，表面 1 硬度 H_1、表面 2 硬度 H_2：
- 总磨损 V_total = K·F·s·(1/H_1 + 1/H_2)。
- 若 H_1 = H_2 = H（同种材料）→ V_total = 2·K·F·s / H。
- 若题面只问"surface 1 的磨损"→ V_1 = K·F·s / H_1，不乘 2。

判定动作：在题面找"two surfaces / 轴对套筒 / 销对盘 / 同种材料 / both of steel"等关键词；两体 + 等硬度 + 问总磨损 → 因子 2 必出现，漏掉即错。
