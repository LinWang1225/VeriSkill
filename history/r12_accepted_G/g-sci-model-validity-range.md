# 模型适用范围：外推前先确认落在有效区内

## 触发情形

解题用到一阶/线性化/经验近似公式（线性电阻率 ρ=ρ_ref[1+α(T−T_ref)]、Hooke 定律、理想气体、Sieverts 定律、Arrhenius 单段外推…），待求点远离该近似的参考点或落在近似失效的物理区间内。典型翻车：把室温附近成立的一阶线性关系外推到偏离参考点很远的温区（如低于 Debye 温度，此时电阻率按声子高次幂变化），得到非物理结果（如预测电阻率 = 0 或负值）却未察觉。

## 常见模型的有效区

- **线性电阻率** ρ=ρ_ref[1+α(T−T_ref)]：仅在 T_ref 附近且 T > Debye 温度 Θ_D 时成立；T < Θ_D 时电阻率 ∝ T⁵（Bloch–Grüneisen），线性近似失效。
- **Hooke 定律** σ=Eε：仅在弹性极限内（ε 远小于屈服应变）；大应变须用非线性弹性/塑性模型。
- **理想气体** pV=nRT：低压高温；高压低温须 virial 或状态方程修正。
- **Arrhenius 单段外推** ln D = ln D₀ − Q/RT：在拟合温区内可靠，跨相变或外推到远低于拟合区间的温度时须谨慎。
- **Dilute-solution / Henry / Sieverts**：仅溶质浓度→0 的极限；高浓度须用活度修正。

## 执行步骤

1. **定模型与有效条件**：写下所用公式及其适用条件（温区、压强范围、应变范围、浓度区间…）。
2. **检查待求点**：把待求温度/压强/应变/浓度与有效条件比对。关键判据：
   - 偏离参考点的幅度是否在线性保持的尺度内（如 |T−T_ref|/T_ref 是否小）？
   - 是否跨过物理边界（低于 Θ_D、低于熔点进入液相、超出弹性极限、超出稀溶液极限）？
   - 模型在待求点是否给出非物理值（负电阻率、负浓度、超光速）？
3. **超出有效区时**：
   - (a) 换用该区有效的模型（低温电阻率用 Bloch–Grüneisen / Matthiessen 定则 ρ=ρ_residual+ρ_BG·T⁵；大应变用非线性弹性；高浓度用活度）。
   - (b) **仅当**题面明确要求用该简化模型（教科书题预期用法）**且**模型在待求点仍给出物理上合理的结果（正值、有限、量级合理）→ 按要求算，但在答案旁显式标注"该模型在待求点属外推，结果为近似，严格解须用 XXX 模型"。
   - (c) **硬禁止**：模型在待求点给出非物理值（负电阻率、零浓度、发散）或待求点远在有效区外（如 T < Θ_D 用线性电阻率、|T−T_ref| 与 T_ref 同量级）时，**不得**以"已标注假设"为由沿用该模型——标注不等于改模型。必须按 (a) 换模型；若题面未给非线性参数则声明"线性模型在此温区失效，需 XXX 参数才能严格求解"，不要硬交一个已知失效的外推数值。
4. **自查**：我是否把一阶/线性模型外推到远离参考点或跨过物理边界？模型在待求点是否给出非物理值（零、负、发散）？我是否"已承认假设不成立却仍沿用"——若是，这是已知翻车模式，必须回到第 3 步按 (a) 或 (c) 处理，不要静默提交外推结果。

## 举例（通用占位，非任何具体题目）

用线性电阻率 ρ=ρ_ref[1+α(T−T_ref)] 求 T=T₁ 处 ρ：先查该材料 Θ_D，若 T₁ < Θ_D 或 |T₁−T_ref| 与 T_ref 同量级 → 线性近似失效，改用 Bloch–Grüneisen 或标注"外推至模型有效区外，结果近似"。若模型在 T₁ 预测 ρ≤0 → 非物理信号，必改模型或标注。判定动作：代入前先比对待求点与模型有效区，不要算完才发现非物理仍硬交。
