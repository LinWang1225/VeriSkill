## 方法库

### 子情形：Arrhenius 扩散参数 D₀/Q 成套配套——按相结构查取
- 【正确方法】Fick 第二定律求解扩散问题需 Arrhenius 参数 D = D₀·exp(−Q/RT)。D₀ 与 Q 必须是同一参考表条目中、针对题目指定的溶质–溶剂–相结构（如"C in FCC iron""C in BCC iron"）的成套数值。不同相结构（FCC vs BCC）、不同溶质的参数不可混用；同一 D₀ 配不同 Q（或反之）会系统性偏移预测温度/扩散速率。须在轨迹中显式标注参数来源与适用体系，并核对所引数值与题目指定相结构一致。关键判据：D₀ 与 Q 须出自同一表行、对应同一溶质–溶剂–相；题目指定某相时只能用该相的参数。
- 【错误签名】轨迹代入的 D₀ 与 Q 不成套——D₀ 取自某一表条目、Q 取自另一条目（或不同相/不同溶质的条目），或参数对应的是与题目指定不同的相结构（如题目指定 FCC 却用了 BCC 的 Q，或 D₀ 来自 FCC 而 Q 来自 BCC）。核对特征：轨迹引用了 D₀ 和 Q 但未标注二者来自同一表条目；或所引参数对应的相结构与题目指定不一致；或与该体系公认成套参数相比，Q 偏高/偏低使预测温度系统性偏离。结果：所得温度/时间/浓度与正确成套参数给出的结果有显著偏差。

### 子情形：纤维/基体模量查表取值——勿用物理不等式反推选定
- 【正确方法】复合材料混合律问题（如 E_c = V_m·E_m + V_f·E_f）中纤维模量 E_f 和基体模量 E_m 须从参考表按题目指定的纤维类型/基体材料查取。若题目指定纤维体系（如碳纤维/环氧），应查该体系的标准 E_f、E_m 值代入。Voigt 上界（isostrain）给出的是 E_c 的理论上界，它是一个一致性检验：若算出的 E_c 低于实验值，说明所用参数或模型有误，但该不等式不能用来反推选定 E_f——上界只约束"算出的预测值不应低于实验值"，不唯一确定 E_f。正确做法：按题目指定的纤维类型查表取 E_f，若存在多种候选值应按题目上下文（纤维牌号/品种）确定，而非用上界不等式筛选。关键判据：参数须来自查表，而非由物理不等式/模型一致性条件反推。
- 【错误签名】轨迹列出多个候选纤维模量值后，用 Voigt 上界不等式（E_calc ≥ E_exp）作筛选标准——凡使预测低于实验值的候选被以"违反上界/不物理"为由排除，使预测高于实验值的候选被"确认"选用。这把一致性检验误用作参数选择标准。核对特征：轨迹出现"upper bound sanity check""prediction must be ≥ experimental""using E_f = X would give Y < E_exp, unphysical, confirming E_f = Z"等表述——即用模型不等式在候选参数间做选择；或轨迹以"违反上界"为由排除某查表值。结果：选定的 E_f 被物理不等式而非材料实际属性决定，所得误差值与正确查表值给出的结果不符；且可能漏算题目要求的多值答案（如题目要求多种纤维模量各自的误差，轨迹只报单值）。

## R 判据

- R-d-matsci-param-lookup-001 [soft] 若本题指定材料/相结构/纤维体系且需查表取参数（扩散 D₀/Q、激活能、固溶度、纤维/基体模量 E_f/E_m 等）：在正文"方法库"里找与本题最匹配的子情形，按其【正确方法】核对轨迹所引参数是否与题目指定材料/相/纤维类型匹配且成套配套、并查是否犯了其【错误签名】（D₀ 与 Q 不成套、相结构不匹配、未标注参数来源、用物理不等式/模型一致性检验反推选定参数值而非查表取值）；方法库无恰配子情形时用家族通用检查（核对轨迹所引每个参数的来源/适用体系是否与题目指定一致、参数间是否成套、参数是否由查表而非不等式反推获得，不一致即命中）。命中任一错误签名、或参数与指定体系不匹配、或参数由物理不等式反推选定，即命中。 依据:r5#m219,r9#m041
