# 有效数字与舍入约定

## 触发情形

题目给定的输入参数有效数字位数不一（如有的给 2 位、有的给 3 位），最终要报一个数值答案。常见被指问题：报出位数多于最弱输入、舍入方向系统性偏大、中间量过早截断。

## 执行步骤

1. **清点每个输入的有效数字位数**，记下最少位数 n_min。计数规则（常见误数根源）：
   - 非零数字间的 0 都算有效：如 `a.bc` 有 3 位，`a.bcd` 有 4 位。
   - 小数点后的尾 0 **算有效**：`a.b` 有 2 位，`a.b0` 也有 3 位，`a.0` 有 2 位——尾 0 表示测量精度到了该位，不得忽略。
   - 整数末尾的 0 无小数点时**歧义**：`ab00` 可能 2/3/4 位，按题面书写惯例取保守（2 位）；若题面写成科学记数 `a.b×10^k` 则按系数位数计。
   - 前导 0 **不算有效**：`0.ab` 与 `a.b` 同位数。
   - **自查误数**：把"小数点后位数"或"总字符数"当成有效数字位数是常见错——有效数字位数 = 从左起第一个非零位到末尾保留位（含尾 0）的位数。如 `a.b`（一位小数）是 2 位不是 3 位，`a.0` 是 2 位不是 1 位——尾 0 计入位数，小数点后位数 ≠ 有效数字位数。
2. **中间计算全程保留守卫位**（至少比 n_min 多 2–3 位），不要在中间步骤就四舍五入到 n_min——过早截断会累积偏差。只在**最终报出**时收尾。
3. **最终答案位数 ≤ n_min**。若 n_min=2，报 2 位有效数字（如 a.b×10^k 形式），不要报 3 位。
4. **舍入用标准四舍五入**（half-up 或 half-even 均可，但要一致）：
   - 待舍入位后一位 ≥5 进一，<5 舍去；
   - 不要系统性只向上或只向下。自查：若连续多题舍入都偏向同一方向，说明有偏置，回去核对舍入规则。
5. **查表/文献常数**（密度、原子量、扩散系数等）：取与题目输入精度匹配的位数；题目用 2 位输入时，不必把密度取到 5 位再算出 5 位答案——精度受限于最弱输入。

## 中间舍入链一致性

写中间步骤时，**写出的舍入值与下一步实际代入的值必须是同一个数**。常见问题：先写"x ≈ x̃（舍入到 k 位）"，下一步却用未舍入的 x 去平方/开方/乘除，再写"x̃² = …"——但 x̃² ≠ x²，等号不成立，审计链断裂。规则：
- 要么中间步骤写全精度值（x² = …），要么舍入后**用舍入值**继续算（x̃² = …），二者择一，不得"写舍入值、用未舍入值"。
- 每个等号的左右两边必须用同一精度的数算出；若左边写的是舍入值，右边必须由该舍入值算得，不得由更高精度值算得再贴个舍入标签。
- 自查：沿推导链逐个等号检查"等号右边是用等号左边写的那个数算的吗"——若右边实际用了更高精度值 → 要么把左边改成全精度，要么把右边重算成舍入值的结果。

## 自查动作

报出答案前问自己：
- 这个答案有几位有效数字？是否 ≤ 最弱输入的位数？是→过；否→收到 n_min 位。
- 舍入是标准四舍五入还是单向偏置？拿待舍入位后一位确认进/舍方向。
- 中间量是否被过早截断？若中间步骤就四舍五入到最终位数，回到第 2 步保留守卫位重算。
- 舍入链是否自洽？逐个等号确认左右用了同一精度的数；发现"写舍入值、用未舍入值"→ 统一到一种精度再重写该步。
- **位数是否多报**：若输入最少 2 位有效数字而答案报了 4 位以上 → 回收到 n_min 位。教材惯例偶尔容忍多报 1 位，但多报 2 位以上属精度虚高，须收。
- **整数末尾 0 歧义**：若答案落在整数（如 a×10ⁿ 的整数倍），裸写"a00"无法区分几位有效数字 → 须用尾小数点（"a00."）或科学记数（"a.bc×10ⁿ"）显式标明位数。判据：答案写成无小数点无指数的整数且末尾含 0 → 改写为带尾小数点或科学记数形式，使有效数字位数可从书写形式唯一确定。

## 举例（通用占位）

输入 X=a.b（2 位）、Y=c.de（3 位）：n_min=2，最终答案报 2 位有效数字。中间算用 a.b、c.de 原值或更高精度，不在中间截断到 2 位。若尾数算得 a.bc…，按标准四舍五入到 a.b 或 a.(b+1)，不要总是进位。

## 相近大数相减（catastrophic cancellation）：相减前必须保留全精度

当最终量（或某中间量）是**两个量级相近的大数之差**的小残差时——典型形如 r = (ρ·N_A·a³ − n·M)/M_H，其中被减数与减数近对消、残差比任一被减数小若干数量级——**相减前所有参与运算的量必须保留到全可用精度，不得提前舍入任一被减数/减数**。提前把某个被减数（如原子量、摩尔质量、Avogadro 常数）舍入到比残差还粗的位数，会注入与残差同量级甚至更大的误差，经后续除以小残差（如 r = Δ/M_H 中 M_H≈1）放大后偏差可达数成乃至翻倍。

**判据（触发本子情形）**：写出求解表达式后扫一眼——最外层或某层是否有"大数 − 大数"结构，且两数差远小于两数本身（比值差/被减数 < 约几个 %）？是 → 进入下面的精度保留流程。

**执行**：
1. 识别相减结构 Δ = A − B 中 A、B 及所有 feeding 量（密度、原子量、晶格参数、N_A…）。
2. **相减前**：每个 feeding 量取到其来源给出的全精度（手册/教材标准值的全部有效位），不得为"简洁"先舍入到 2–3 位。即使题目输入只有 2–3 位有效数字，相减前的常数/标准值仍取全精度——有效数字位数限制只作用于**最终报出**，不作用于 catastrophic cancellation 的中间相减。
3. 算完残差 Δ 及其下游量后，只在**最终答案**按 n_min 收尾。
4. **自查**：若发现自己在相减前把某个原子量/常数写成了少位数形式（如把 A_X = a.bcd 写成 a.bc 再参与相减）→ 回第 2 步换回全精度重算该步。判据：相减的两数各自有几位有效数字参与运算？若任一被减数/减数参与相减时的精度位数 ≤ 残差的有效位数 → 必然丢精度，回去提精度。

**举例（通用占位）**：r = (A − B)/C，A ≈ B（比值差/A ≈ 1%），A 由常数 ρ·N_A·a³ 算得。正确：ρ、N_A、a 各取全精度算 A，与全精度 B 相减得 Δ，再除以 C，最终按 n_min 舍入。错误：先把 B 中的原子量舍入到 2 位再相减——舍入注入的误差与 Δ 同量级，r 偏差可达数成。

## 加法/减法 vs 乘法/除法：精度规则不同

最终答案的舍入位数取决于**运算结构**，不是一律取最少有效数字位数：

- **乘除为主的表达式**（如 ρ = A·x·(1−x)·C）：结果有效数字位数 ≤ 输入最少有效数字位数（上记 n_min 规则）。
- **含加法/减法的表达式**（如 ρ = ρ₀ + C·x·(1−x)、y = a + b·T）：加法/减法的精度由**小数位**决定，不是有效数字位数。一个 3 位有效数字的加数（如 ρ₀ = a.bc×10^k，小数点后 2 位）与一个乘积项相加时，和的小数位受限于 ρ₀ 的小数位，最终结果应保留到与 ρ₀ 相同的小数位（即仍 3 位有效数字），而不是按乘积项的有效数字位数截断。
- **判据**：先看最终表达式最外层是加法还是乘法。是加法 → 按加数中最少小数位定结果精度；是乘法 → 按因子中最少有效数字位数定结果精度。混合式（加法里嵌乘积）→ 先定每个乘积项的精度，再按加法规则定和的精度。
- **常见错误**：把加法结构 ρ = ρ₀ + Δρ（ρ₀ 以 3 位有效数字给出）的结果按乘积项 Δρ 的有效数字位数舍入，多丢精度。正确做法：ρ₀ 的小数位决定和的小数位，保留到该位。
