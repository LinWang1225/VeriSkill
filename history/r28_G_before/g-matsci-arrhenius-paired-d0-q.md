# Arrhenius 参数配对与相匹配：D₀ 与 Q 同表同相

## 触发情形

题面给出 Arrhenius 型关系 D = D₀·exp(−Q/RT)（扩散系数、反应速率、蠕变、电导…），指定某相/结构/体系（如"FCC iron""austenite""α-Fe""carbon in FCC iron"），要求算某温度下的 D 或由目标 D 反解温度/时间。须从扩散数据表查取 (D₀, Q)。典型翻车：代入的激活能 Q 并非题面所指定相的标准值——或从不同来源分别取 D₀ 和 Q（跨表混配），或用了另一相（如 BCC α-Fe）的 Q 配 FCC 的 D₀。D₀ 与 Q 不配套时 ln(D₀/D) = Q/RT 中的 Q 偏移直接传递到解出的 T，使温度系统性偏高或偏低。

## 硬约束

- **同表同相**：D₀ 与 Q 必须来自**同一张扩散数据表**中**同一行**（同一体系、同一相、同一扩散物种）的配套值。不得从 A 表取 D₀、从 B 表取 Q 拼合。
- **相/结构匹配题面**：题面说"FCC""austenite""γ-Fe" → 取该物种在 FCC 相的 (D₀, Q)；题面说"BCC""α-Fe""ferrite" → 取 BCC 相的值。不同相的 Q 可差倍数，用错相直接出错。
- **扩散物种匹配**：碳在铁、氮在铁、镍在铜…各体系 (D₀, Q) 不同；确认题面所问的是哪个物种在哪个基体中扩散，取对应行。
- **注明来源**：在代入处写明"(D₀, Q) 取自 [表/教材名]，[物种] in [相/结构]"，让配对可审计。
- **D₀ 量级拦截（代入前必做）**：从表抄出 D₀ 后，先用典型量级粗核——间隙扩散（H/C/N/O 在金属基体中）D₀ 通常在 10⁻⁷–10⁻³ m²/s 区间（多数集中在 10⁻⁵–10⁻³）；置换扩散（金属原子在金属基体中）D₀ 通常在 10⁻⁵–10⁻⁴ m²/s 区间。若抄出的 D₀ 偏离该物种该类扩散的典型区间**两个数量级以上**（如间隙扩散抄到 10⁻⁷ 而该物种典型为 10⁻³，差四个数量级）→ 大概率抄错指数/读错列，回表重读该单元格的指数部分。注意区分 D₀ 的单位（m²/s vs cm²/s 差 10⁴ 倍）——先统一到同一单位再比量级。

## 执行步骤

1. **定相/结构/物种**：从题面圈出相（FCC/BCC/γ/α…）、基体（Fe/Cu/Ni…）、扩散物种（C/N/H…）。题面只说"iron is FCC" → 相 = FCC（奥氏体），须取该相数据。
2. **定位数据表**：确认所用扩散数据表覆盖该物种在该基体该相的 (D₀, Q) 行。若手上的表没有该相该物种行 → 先找到正确的表再取数，不要用相近相/物种的值替代。
3. **取配套 (D₀, Q)**：从同一行同时取出 D₀ 和 Q，不要分两次查、不要跨表拼。记录取值与来源。**抄 D₀ 时逐位核对指数**：表中 D₀ 常以科学记数 a×10ⁿ 给出，n 的正负号与数值是最高频抄错点——先把 n 单独读出写下（"指数 n = …"），再拼回 a×10ⁿ，不要一眼扫过整个科学记数。
4. **D₀ 量级拦截**：按硬约束"D₀ 量级拦截"做典型量级粗核。不通过 → 回第 3 步重读 D₀ 单元格（重点核对指数 n 的符号与数值）。通过才继续。
5. **代入求解**：D = D₀·exp(−Q/RT) 或反解 T = Q/[R·ln(D₀/D)]。注意 D₀ 与 D 同单位（通常 m²/s 或 cm²/s），Q 与 R 同能量单位（Q 用 J/mol 配 R=8.314 J/(mol·K)；Q 用 cal/mol 配 R=1.987 cal/(mol·K)）。
6. **相稳定区核验**：解出温度 T 后，核验 T 是否落在题面所指定相的稳定温区内（如 FCC 奥氏体铁约 912–1394°C）；落在区外 → 说明参数或模型可能有误，回到第 3 步重查 (D₀, Q) 配对。
7. **自查**：D₀ 与 Q 是否来自同一表同一行同一相？Q 是否对应题面指定的相（而非另一相）？D₀ 量级是否落在该物种该类扩散的典型区间内？解出的 T 是否在该相稳定温区内？任一不满足 → 回到对应步骤修正。特别警惕：凭记忆取 Q 而不核对相/物种 → 高概率取到错相值；凭记忆或一眼扫取 D₀ 指数 → 高概率抄错量级。

## 举例（通用占位，非任何具体题目）

题面指定物种 S 在基体 M 的相 P（如"carbon in FCC iron"），Arrhenius 式 D=D₀·exp(−Q/RT)。从扩散数据表找到"S in M, phase P"行，同时取该行的 (D₀, Q)，注明来源。禁止：从表 A 取 D₀、从表 B 取 Q；或取 S in M 但相 P'（≠P）的 Q 配相 P 的 D₀。反解 T 后核验 T 落在相 P 的稳定温区；若 T 远在该区外 → 参数配对可疑，重查。判定动作：代入前先在题面确认相/物种，在数据表找对应行，D₀ 与 Q 同行同取，不跨表不跨相。
