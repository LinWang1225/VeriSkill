# 多材料参数取自同一数据源

## 触发情形

同一道题涉及两种或以上材料（如比较 BCC 与 FCC 的间隙半径、两种合金的密度比、双组分扩散偶），需要查表/查手册获取各材料的晶格常数、原子半径、密度、扩散系数等参数。典型翻车：材料 A 的参数取自教材标准表，材料 B 的参数却取自另一来源的非标准值（或凭记忆取了近似值），两参数不自洽使最终数值偏移——即使公式与算术全对，参数源不一致导致结果与用统一数据源算出的参考值不符。

## 硬约束

- 同一题中所有查表参数须取自**同一数据源**（同一教材附录表、同一手册、同一数据库）。若题面给了某材料的参数，以题面值为准并据其精度推断应使用的数据源层级。
- **不得**对一种材料用标准表值、对另一种材料用非标准/记忆值。若题面未指定数据源，统一选用该领域教材最常用的标准表（如 Callister 附录、CRC、Pearson's Crystal Data）。
- 代入前在解答中列出每个参数及其来源（"a_A = … nm（Callister Table X）"），逐个核对来源是否同一。

## 执行步骤

1. **列出所需参数**：写出本题涉及的所有材料及其所需参数（晶格常数 a、原子半径 R、密度 ρ、扩散系数 D…）。
2. **统一数据源**：选定一个数据源（教材附录表 / 手册 / 数据库），所有材料的参数都从该源取。若某参数在该源中查不到 → 换一个能覆盖全部所需参数的源，不要对缺的那个另找零散来源凑数。
3. **逐个标注来源**：在解答中写明每个参数值及其来源。若题面已给某参数 → 以题面值为准，其余参数尽量取与题面值同源/同精度的表值。
4. **一致性自查**：扫一遍所有代入的参数——它们是否都来自同一数据源？若有任一个来自不同来源或凭记忆取近似值 → 换成统一源的值重算。另查：某材料的晶格常数是否取了非标准/非常用值（与同源其他材料参数精度不匹配）→ 若是，换成该源的标准值。

## 禁止用模型一致性不等式选参数

当某材料参数有多个候选值（如纤维模量有标准模量/高模量两个牌号值），须按**题面指定的材料牌号/规格**或**配套表的指定行**取值，不得用模型一致性不等式（如 Voigt 上界 E_calc ≥ E_exp、Reuss 下界等）在候选值间筛选——一致性检验是**验算**，不是**参数选定**。典型翻车：题面给"C fibers"未指定等级，解题者用 Voigt 上界不等式排除低模量候选值并"确认"高模量值，把模型验算当成了查表选参。正确做法：题面未指定牌号时，从配套表中与题面其他信息（体积分数、实验模量行等）匹配的指定行取值；若仍无法消歧，在解答中显式声明所选牌号及依据，不得用不等式消歧。

## 举例（通用占位，非任何具体题目）

题面涉及材料 A（结构甲）与材料 B（结构乙），须查两者的晶格常数 a_A、a_B。错误：a_A 取自教材表（标准值），a_B 取自另一手册的非标准值，两者精度/来源不匹配，使比较结果偏移。正确：从同一教材附录表取 a_A 与 a_B，在解答中标注两者来源相同。判定动作：代入前把所有参数及其来源列一张表，逐行核对来源列是否全同；发现任一行来源不同 → 统一到同一源重取该行参数。

参数有多个候选值时，错误：用模型上界/下界不等式排除某候选值并"确认"另一候选值——一致性检验不是参数选定标准。正确：按题面材料牌号/规格或配套表指定行取值；无法消歧时显式声明所选值及依据。
