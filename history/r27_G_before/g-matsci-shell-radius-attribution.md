# 球壳/柱壳半径归属：标称直径=外径，壁厚向内扣

## 触发情形

题面描述一个"直径 D、壁厚 t 的球形容器/管道/压力容器"，要求算穿过壁的稳态扩散通量、传热或渗漏速率。球壳稳态扩散用

```
ṁ = 4π D Δc / (1/r_i − 1/r_o)
```

柱壳用 2πL·DΔc/ln(r_o/r_i)。典型翻车：把题面的"直径 D"当作**内**径（r_i = D/2），再向外加壁厚得 r_o = D/2 + t。这使分母 (1/r_i − 1/r_o) 比正确值偏小（两半径都偏大且更接近），通量系统性偏大。正确归属：容器的标称直径是**外**径，r_o = D/2，壁厚向内扣除得 r_i = D/2 − t。

## 硬约束

- **标称直径/半径 = 外径/外半径**：除非题面显式标注"内径 (inner diameter / ID)"，否则"直径 D""半径 R"指外径。r_o = D/2。
- **壁厚向内扣**：r_i = r_o − t（t 为壁厚）。不得把壁厚向外加（r_o = r_i + t 配 r_i = D/2）。
- **代入前标注归属**：在写 r_i、r_o 数值的那一步，显式标注"r_o = 标称直径/2（外）、r_i = r_o − t（内）"，让归属可审计。
- **量纲一致**：r_i、r_o 须同单位（扩散系数用 m²/s 时半径用 m；Δc 用 g/m³）。壁厚常以 mm 给、直径以 cm 给——先统一单位再相减。

## 执行步骤

1. **圈出题面几何描述**：记下"直径/半径"数值与单位、"壁厚/厚度"数值与单位，以及是否标注了"内/外"。
2. **定归属**：
   - 题面说"内径"→ r_i = 该值/2，r_o = r_i + t。
   - 题面说"外径"或只说"直径/半径"未标注 → 按外径处理：r_o = 该值/2，r_i = r_o − t。
   - 压力容器/球形容器/管道的标称尺寸惯例是外径（或公称外径），不要默认内径。
3. **统一单位**：把 r_o、r_i、t 换到同一单位（与扩散系数和浓度单位配套），再算 r_i = r_o − t。
4. **代入壳公式**：球壳 ṁ = 4πDΔc/(1/r_i − 1/r_o)；柱壳 ṁ = 2πL·DΔc/ln(r_o/r_i)。确认分母 (1/r_i − 1/r_o) > 0（r_o > r_i）。
5. **自查（硬门控）**：
   - 我把标称直径当内径还是外径？若当内径（r_i = D/2，r_o = D/2 + t）→ 错归属，回第 2 步改为外径、壁厚向内扣。
   - r_o 是否大于 r_i？若 r_i ≥ r_o → 几何矛盾，回第 2 步。
   - 单位是否统一？壁厚 mm、直径 cm 直接相减会差 10 倍 → 回第 3 步。
6. **独立验证**：换一条路径确认归属——如用壁厚很薄时的薄壁近似 ṁ ≈ 4π r² D Δc / t（r ≈ r_o ≈ r_i）粗估量级，与精确壳公式结果比对；两者应同量级。若精确值比薄壁近似大很多 → 可能半径归属反了（分母被算小），回第 2 步。

## 举例（通用占位，非任何具体题目）

题面给"直径 D、壁厚 t 的球形容器"（未标注内/外），稳态扩散 ṁ = 4πDΔc/(1/r_i − 1/r_o)。
- 正确：r_o = D/2（外径），r_i = D/2 − t（壁厚向内扣），代入。
- ❌ 错误：r_i = D/2（把标称直径当内径），r_o = D/2 + t（壁厚向外加）→ 两半径都偏大、(1/r_i − 1/r_o) 偏小、ṁ 偏大。

判定动作：写下 r_i、r_o 后追问"标称直径我当的是内径还是外径？"——若当内径且题面未标注"内径"→ 改为外径、r_i = r_o − t 重算。薄壁近似粗估量级与精确值比对，差得离谱 → 归属可疑。
