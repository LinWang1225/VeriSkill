# 查表取参数：先核行标签、列标签、单位，再读单元格

## 触发情形

题目要用 Q=mcΔT、热膨胀、电阻、扩散等公式，需从教材/手册附录表查某材料的比热容 c_p、线胀系数 α、密度 ρ、电阻率 ρ、扩散系数 D 等。典型翻车：表里多种材料按行排列、多个参数/单位按列排列时，凭"大概在这一行"取数，行错位取到相邻材料的值，或列错位取到相邻单位（如 J/(g·K) vs J/(kg·K) vs cal/(g·°C)），代入后公式与算术全对、数值却整体偏移。

## 硬约束

1. **三核对再读数**：读单元格前依次确认——(a) 行标签 = 目标材料（含同素异形体/合金牌号，如灰铸铁 vs 纯铁、Si₃N₄ vs Si）；(b) 列标签 = 目标参数（c_p vs c_v、α 线胀 vs β 体胀）；(c) 列头单位 = 你公式要代入的单位。任一不符 → 重新定位行/列，不要将就。
2. **单位不符先换算再代入**：若表列单位与公式单位不一致（如表给 J/(kg·K) 而公式用 J/(g·°C)），先显式换算并写出换算式，再代入；不要默默把数值当另一单位用。温度差 ΔT 用 °C 还是 K 须与 c_p 单位匹配（ΔT 数值在 °C 与 K 间相等，但 c_p 单位标注要一致）。
3. **量级自洽拦截**：代入前用已知物理量级粗核该参数——常见金属 c_p 在约 0.1–0.9 J/(g·K) 量级、线胀系数在约 10⁻⁶–10⁻⁵ /°C、室温电阻率金属约 10⁻⁸–10⁻⁶ Ω·m、扩散预因子 D₀ 间隙扩散约 10⁻⁷–10⁻³ m²/s（多数 10⁻⁵–10⁻³）、置换扩散约 10⁻⁵–10⁻⁴ m²/s。取值偏离该材料该参数的典型量级一个数量级以上 → 大概率取错行/列或单位或抄错指数，回表重定位。对科学记数 a×10ⁿ 形式的表列值（尤其 D₀），先单独读出指数 n 核对正负号与数值，再拼回完整值——指数是最高频抄错部位，一眼扫过整个科学记数常导致量级偏移若干个 10 的幂。
4. **标注来源与取值**：解答中写出"c_p(材料) = 数值 单位（表 X.Y，第 N 行第 M 列）"，便于复核行/列是否对位。

## 执行步骤

1. **定位表**：确认题目指向哪张表（教材附录表号/手册章节）；若题面未指定，选用该领域常用标准表并注明。
2. **三核对**：在表中先沿行找到目标材料行（逐字符比对材料名/牌号），再沿列找到目标参数列且核对单位，确认行列交点单元格。
3. **读数 + 量级核**：读出单元格数值，按第 3 条硬约束做量级自洽粗核；不通过 → 回第 2 步重定位。
4. **单位换算（如需）**：若表单位与公式单位不同，显式换算后代入。
5. **标注**：在解答中写明参数值、单位、来源表号与行列。
6. **独立复核**：换一条不依赖该表读数的路径粗估（如用该材料另一已知热学关系、或不同来源的同参数量级），两者一致才可信；不一致 → 优先怀疑行/列错位，回第 2 步重定位。

## 举例（通用占位，非任何具体题目）

要用 Q=mc_pΔT 算材料 A 升温 ΔT 的吸热，从教材表查 c_p(A)。表按行列材料、按列列 c_p（单位 J/(kg·K)）。错误：扫到"材料 A 那一行附近"取一个数，实际取到相邻材料 B 的 c_p，或取到 c_p 列旁另一单位列的值，代入后 Q 整体偏移。正确：先沿行逐字符比对找到材料 A 行，再沿列确认列头为 c_p 且单位 J/(kg·K)，读交点值；若公式用 J/(g·°C)，先除以 1000 换算并写出换算式；代入前粗核 c_p(A) 是否在该材料典型量级内。判定动作：读数前在解答里先写"行=材料 A、列=c_p [J/(kg·K)]"，再写取值；量级不符或单位不符 → 回表重定位，不将就代入。
