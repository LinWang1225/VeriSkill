# 跨材料比较：受控变量须统一，不得各取极值

## 触发情形

题目要求比较两个或多个材料/体系在某物理机制下的某量增量或百分增量——典型如"比较各材料 by strain hardening 的屈服强度百分增量""比较各合金的时效硬化峰值""比较各材料的冷加工强化率"。该量是某受控变量 x（%CW、冷加工度、温度、应变、时效时间…）的函数 f_i(x)，每个材料 i 有自己的曲线 f_i。**正确比较**是在**同一个 x** 上读各 f_i(x) 再算增量；**典型翻车**是给每个材料各取一个不同的 x_i（如各自的极限强度对应的最大 %CW、各自曲线的终点）当终点，于是比的是"各自能硬化到多高"而非"等条件下的硬化能力"，基准不一致致排序与数值都失真。

## 硬约束

1. **受控变量统一**：比较 f_i 在某机制下的增量/百分增量时，须对所有材料取**同一个 x 值**。题面若指定了该 x（如"在 %CW = 某值时"）→ 用题面值；题面若只说"by strain hardening"未给具体 x → 须在解答中显式选定一个公共 x（如取各材料曲线覆盖区间内的公共 %CW），并注明"取同一 x = … 进行比较"，不要让每个材料各走各的 x。
2. **禁止各取极值**：不得用每个材料自己的最大冷加工/极限强度/曲线终点当该材料的终点 x_i——各 x_i 不同，增量算出来不在同一基准上，排序比的是"谁的天花板高"而非"同等条件下谁硬化得多"，是不同命题。
3. **禁止自行截断**：不得以"某晶体结构冷加工受限/该材料不能冷加工到那么高"等题面未给的限制自行截断某材料的 x 或 f——若题面未声明该限制，须按题面数据走；若某材料在选定公共 x 下确无数据点，注明"该材料在 x = … 处无可用数据"并说明对比较结论的影响，不要凭物理直觉删数据点。

## 执行步骤

0. **核验各条目同基准**：在选数据点之前，先逐条核验拟用的每个材料数据条目是否满足"同一比较基准"——
   - **牌号纯度一致**：题面限定"commercially pure / 纯金属/某牌号族"时，每个条目都须是该纯度等级；不得混入合金化牌号、不同纯度等级、或名义同族但实际成分不同的条目。逐条标"纯度等级 = …"，任一条与题面限定不符 → 换到符合的条目，无符合条目则标注该材料缺数据。
   - **参考态（temper）一致**：百分增量的分母（退火态/初始态）对所有材料须取**同一 temper**（如全用 fully annealed）；不得给某材料用退火态、另一材料用半硬态当参考。逐条标"参考态 = …"。
   - **终态受控变量一致**：见第 2 步，所有材料的终态 x 须取同一值。
   此步先做，避免"选完数据才发现基准不一致却已算到底"。典型翻车：跨材料比较"commercially pure 退火态经应变硬化的屈服强度百分增量"时，某材料条目混入了非纯牌号或非退火参考态，致该材料的增量基准与他人不同，排序与数值失真。
1. **识别所问比较的量与受控变量**：题面问的是哪个量（屈服强度百分增量、强度增量、导率变化…）？该量是哪个变量 x 的函数？写出 f_i(x) 的形式。
2. **定公共 x**：题面是否指定了 x 的值？
   - 指定 → 所有材料用该 x。
   - 未指定 → 选一个落在所有材料曲线共同覆盖区间内的 x，显式注明"取同一 x = …"。若各材料曲线覆盖区间无交集，说明该比较在单一 x 下不可行，须分 x 报告或声明需题面指定 x。
3. **逐材料在同一 x 下读数**：对每个材料 i，在其应变硬化曲线/数据表上读 f_i(公共 x) 与参考态 f_i(annealed/初始)，算增量 Δ_i = f_i(x) − f_i(ref) 或百分增量 Δ_i% = (f_i(x) − f_i(ref)) / f_i(ref) × 100。
4. **比较与排序**：在同一 x 下比较各 Δ_i / Δ_i%，排序才有意义。
5. **自查（硬门控）**：报出前逐材料检查——
   - 每个材料的终点 x_i 是否都等于第 2 步选定的公共 x？若有任何 x_i ≠ 公共 x → 回第 2 步统一。
   - 我是否用了某材料的极限强度/最大冷加工/曲线终点当它的终点？若是 → 回第 3 步改用公共 x 下的读数。
   - 我是否以题面未给的晶体结构/加工限制自行截断了某材料？若是 → 删掉该截断，按数据走。
   - 各材料的参考态（退火态/初始态）是否一致？参考态不同同样使基准不一致。
   - 各条目的牌号纯度是否都符合题面限定（commercially pure / 指定牌号族）？是否混入了非纯牌号或不同纯度等级？若有 → 回第 0 步换到符合的条目。

## 举例（通用占位，非任何具体题目）

比较材料 A、B、C "by strain hardening" 的屈服强度百分增量，各有一条 σ_y–%CW 曲线：
- 正确：选公共 %CW = x₀（落在三条曲线共同覆盖区间内），对 A、B、C 各读 σ_y(x₀) 与 σ_y(annealed)，算 (σ_y(x₀)−σ_y,annealed)/σ_y,annealed × 100，三者比较。
- 错误：给 A 用 A 的最大 %CW、给 B 用 B 的最大 %CW、给 C 用 C 的最大 %CW——各 %CW 不同，比的是"各自天花板"而非"等应变下硬化能力"，排序失真。
- 错误：以"材料 B 是 HCP，冷加工受限"为由自行截断 B 的 %CW 或 σ_y——题面未给该限制时不得自行截断。

判定动作：落笔前先问"我给每个材料取的 x 是同一个值吗？"不是 → 回第 2 步定公共 x。
