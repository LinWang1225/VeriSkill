# 稳态渗透/扩散：联立通量比与总通量守恒

## 触发情形

题面涉及膜/壁两侧多物种稳态渗透或扩散，同时给出两类条件：
1. **通量比/分压比**条件（如 J_A/J_B = p_A/p_B，或某两物种通量成定比）；
2. **总通量/总产率**条件（如单位时间透过总量 = 给定值，或总渗透通量 = 给定值）。

要求温度、膜厚、浓度等未知量时，须**联立**这两类条件。典型翻车：只保留通量比、声称膜厚与换算因子"在比中消去"，把总通量条件整步丢弃，导致丢失一个独立方程、未知量无法唯一确定或换算因子被错误消去。

## 硬约束

1. **题面给的每个独立条件都要用上**：通量比是一个方程，总通量守恒是另一个方程。两个方程联立才能定解。只用了比值方程而未用总通量方程 → 缺一个约束，答案不可复现。
2. **原子/分子换算因子带入求和式**：若渗透物种是双原子分子（如 H₂→2H），分子通量与原子通量间有化学计量因子（如 1 分子 → 2 原子）。该因子在**通量比**中可能恰好消去（若两物种有相同因子），但在**总通量求和式**中不一定消去——求和式 J_total = J_A + J_B（或含计量因子的加权和）中每个物种的换算因子须各自带入，不得因"比值中消去了"就在求和式中也省略。
3. **消去变量前确认两边是同一变量同一因子**：只在确认两处出现的是完全相同的因子（同物种、同计量关系）时才可消去；比值中消去不等于求和式中消去。

## 执行步骤

1. **清点题面条件**：列出所有给定条件（通量比、总通量/产率、分压、膜厚、温度关系…），标注每个条件给出的是哪物种、哪侧。确认条件数 ≥ 未知量数；若只用了一个条件就想解出所有未知量 → 回头找漏用的条件。
2. **写出每物种的稳态通量表达式**：J_i = D_i·(C_i,high − C_i,low)/L（Fick 第一定律）或 Sieverts/Arrhenius 形式，逐物种写出。若有原子/分子换算，在通量表达式中显式写出计量因子。
3. **联立**：
   - 通量比方程：J_A/J_B = 给定比（或由分压比导出的比）。
   - 总通量方程：Σ(计量因子_i · J_i) = 给定总通量。
   - 两方程联立求解未知量。
4. **自查**：
   - 题面给的总通量/产率条件用上了吗？若没出现在最终求解步骤 → 回到第 3 步联立。
   - 原子/分子换算因子在求和式中带了吗？若因"比值中消去"而全局丢弃 → 回到第 2 步在求和式中补回。
   - 未知量数 = 独立方程数吗？少一个方程 → 一定漏了某个条件。

## 举例（通用占位，非任何具体题目）

膜两侧物种 A、B 稳态渗透，题面给 J_A/J_B = r（通量比）与 J_A + J_B = J_tot（总通量）。物种 A 为双原子分子，渗透时 1 分子→2 原子，原子通量 J_A,atom = 2·J_A,mol。联立：由比值得 J_A = r·J_B；代入求和式 2·J_A,mol + J_B = J_tot（注意 A 的计量因子 2 在求和式中保留，不因比值中两物种因子相同而省略）；解出 J_A、J_B 后再求温度/膜厚。错误做法：只在比值 J_A/J_B 中消去因子 2 和膜厚 L，声称"L 和因子都消了"，把 J_tot 条件丢弃 → 缺一个方程，无法定解。
