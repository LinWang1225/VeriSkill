## 方法库

### 子情形：电阻率→电导率（两相合金/复合材料）
- 【正确方法】题目给各相电阻率 ρ_i 和体积分数 V_i、求整体电导率时，应按串联（等应力 / 等电流）模型先混合电阻率：ρ_mix = Σ V_i·ρ_i，再取 σ = 1/ρ_mix。物理依据：电流穿过相界，电阻串联叠加，电阻率按体积分数线性加权。
- 【错误签名】把 rule of mixtures 直接套到电导率上：σ = Σ V_i·σ_i = Σ V_i/ρ_i（并联 / 等电场模型），高估高阻相（低电导相）的贡献，结果系统性偏大。核对特征：轨迹先把各相电阻率取倒数得各相电导率，再按体积分数线性叠加电导率；或出现"conductivity rule of mixtures""σ = V·σ₁ + V·σ₂"等表述而题目原始数据给的是 resistivity。

### 子情形：热导率 / 弹性模量等其它方向相关物性
- 【正确方法】须根据载荷 / 场方向判断串联还是并联：沿层方向（等场 / 等应力）用并联 Σ V_i·k_i；垂直层方向（等流 / 等应变）用串联 1/Σ(V_i/k_i)。选错方向即错。
- 【错误签名】不分方向一律套同一 mixing rule，或把应串联的量按并联叠加（反之亦然）。

### 子情形：一般复合物性——串联/并联判据
- 【正确方法】对任一复合有效物性，先判定该物性在给定物理场景下是"场量串联"还是"流量并联"：场量（电阻率、磁阻率、垂直层热阻）串联叠加；流量（电导率、磁导率、沿层热导）并联叠加。混合的对象必须是"串联叠加的那一个量"。
- 【错误签名】对题目给的原始量先取倒数再混合，等价于把串联量按并联处理（或反之）。

### 子情形：两体对磨磨损——单表面 vs 两表面
- 【正确方法】Archard 磨损定律 dV/dL = K·W/H 描述单表面磨损率。当两体对磨且两表面同材料时，磨损由两表面分担，总磨损率含因子 2（两表面各贡献 1/H）。比较两体对磨与单表面情形时，须按对磨情形计入两表面因子。独立验证须用真正不同的物理路径（如不同磨损定律、不同材料参数来源），而非同一材料的两种硬度标度（如 HB 与 HV）间的换算——那只是同一硬度值的单位转换，不是独立路径。
- 【错误签名】轨迹把单表面 1/H 直接套用到两体对磨情形，丢掉因子 2；或所谓"独立验证"两条路径的数值来源实可互相换算（同一材料、同一热处理状态的硬度在不同标度间转换），并非独立物理路径。核对特征：轨迹涉及两体对磨/相同材料对磨场景但磨损率表达式中无因子 2；或"独立验证"两路径仅差一个硬度标度转换因子。

### 子情形：比较不同轴瓦/套筒材料磨损率（同一钢轴）——钢轴项相消，只比轴瓦单面磨损
- 【正确方法】当题目要求比较同一钢轴配不同轴瓦/套筒（sleeve/bearing）材料的磨损率时，磨损率按 Archard 单表面公式 dV/dL = K·W/H 分别计算各轴瓦表面的磨损。钢轴在两工况中材料相同、磨损率相同，在比值中相消——比较的只是轴瓦表面磨损率之比 = H_轴瓦1/H_轴瓦2（硬度反比）。关键：比较对象是轴瓦（被比较变量）的单面磨损，不是钢轴+轴瓦的总磨损；钢轴项是控制变量、在两工况中恒定而相消。题目若问"compare the rate of wear when the sleeve is (a) material-1 and (b) material-2"，被比较的是 sleeve 的磨损，shaft 不进入比较。
- 【错误签名】轨迹把比较对象偷换成两体总磨损（钢轴+轴瓦之和），对同材钢-钢工况引入"两表面分担"因子 2 使总磨损翻倍，而钢-铜工况不含此因子，导致比值被压成 (1 + H_s/H_c)/2 而非正确的 H_s/H_c。核对特征：轨迹出现"two-body total wear""surface sharing factor 2""V_total = KFs(1/H_1 + 1/H_2)"等把总磨损当比较对象的表述；或轨迹对同材工况含因子 2、对不同材工况不含，使比值被因子 2 压低；或轨迹自述"naive single-surface gives H_s/H_c, two-body correction halves it"之类把正确值当 naive 错误来"修正"的叙述。结果：比值约为正确值的一半（当硬度比远大于 1 时）。

### 子情形：Orowan 绕过强化——滑移面内 2D vs 体占比 3D 几何
- 【正确方法】Orowan 绕过强化 Δσ = Gb/(λ−d) 中，λ 是滑移面上粒子间距，体积分数 f 与间距 λ 的几何关系须按滑移面内二维（平方）关系建立：f ∝ (d/λ)²（滑移面上单位面积内粒子截面积占比）。三维立方关系 f ∝ (d/λ)³ 描述体占比，但 Orowan 间距是滑移面内的二维量，应用平方律。
- 【错误签名】轨迹用三维立方关系 f = (πd³/6)/λ³ 把滑移面间距与体积分数联系起来，得到偏大的 f。核对特征：轨迹出现 f = π/[6(λ/d)³] 或等价的 d³/λ³ 形式用于 Orowan 绕过强化问题。

### 子情形：偏心焊缝群扭转——控制点/极值点选取
- 【正确方法】偏心载荷焊缝群（载荷作用线不通过焊缝群形心）产生扭转，焊缝各端部应力为直接剪切与扭转剪切的矢量和。控制点（governing point）是扭转剪切与直接剪切同向相加的端部（保守端/趾端），该端应力最大、决定所需焊缝长度。须对焊缝群两端分别计算合成应力并比较大小，取较大端为控制点；哪端"相加"取决于扭矩方向与焊缝群几何的相对关系，不能凭直觉假定。关键判据：控制点应是扭转使应力增大的端，而非扭转使应力减小的端（非保守端/跟端）；若轨迹选中的端实际是相减端，则控制点选反，所得焊缝长度偏短、不满足强度要求。
- 【错误签名】轨迹只选定一端便声称其"扭转相加"为控制点，但实际选中的是扭转使应力减小的非保守端——即把跟端当趾端、把相减端当相加端；或轨迹未对两端分别计算合成应力比较大小，直接假定某端控制。典型特征：轨迹提到另一端"扭转相减"且应力更低，却未意识到自己选中的端其实才是相减端（几何方向判反）；或轨迹的扭矩方向与偏心矢量的叉乘结果不一致。结果：所得焊缝长度偏短（非保守），真正控制端被漏判。

### 子情形：S-N 疲劳单问插值——逐段局部 log-log 插值 vs 全局幂律回归（单问情形）
- 【正确方法】S-N 疲劳数据以离散表格给出（若干 (σ_a, N) 数据点）、要求某单一指定寿命 N_f 对应的最大应力幅时，标准做法是在 log σ–log N 空间对**包围 N_f 的两个相邻数据点**做**逐段局部线性插值**（log σ_a = log σ_1 + (log N_f − log N_1)·(log σ_2 − log σ_1)/(log N_2 − log N_1)），而非对全部数据点做一条全局幂律回归 σ_a = a·N^b。理由：S-N 曲线通常呈非线性（不同寿命段斜率不同），全局回归平滑掉局部曲率，在个别寿命处系统性偏移；逐段局部插值保留各数据点处的局部斜率，与实验行为更吻合。关键判据：每个所求 N_f 应使用其紧邻的两点插值，不同 N_f 用不同点对。本子情形适用于单问插值；多问反解须用统一拟合，见下一子情形。
- 【错误签名】轨迹对所有 S-N 数据点做一次 log-log 线性回归（或等价地拟合 Basquin σ_a = a·N^b），用同一条回归线对所有所求寿命插值。核对特征：轨迹出现"fit/regression of all data points""Basquin fit""log-log regression"等表述且只产生一组 (a, b) 参数用于全部插值；或轨迹对每个所求 N 未分别定位其相邻数据点对。结果：各应力幅系统性偏移（部分偏大、部分偏小），与逐段局部插值给出的结果在 5% 以外。

### 子情形：多问 S-N 疲劳——S–log N 半对数图解 vs log-log Basquin 回归/逐问局部插值
- 【正确方法】当 S-N 疲劳数据以离散表格给出、且题目以多个子问要求从同一组数据反解多个量时，教材标准做法是：先剔除疲劳极限水平段数据点（寿命趋于无穷的恒定应力点），在 **S–log N 半对数空间**（应力 S 线性、log N 线性）对剩余有限寿命点做统一线性拟合或图解直线，再用这一条 S–log N 直线统一反解所有子问。关键：教材 S-N 曲线绘在 S–log N 半对数坐标上（不是 log S–log N 全对数坐标），图解读数/线性插值均在 S–log N 空间进行。多个子问应共用同一条 S–log N 拟合线以保证内部一致性。关键判据：拟合/插值须在 S–log N（半对数）空间而非 log S–log N（全对数）空间；各子问结果须来自同一条 S–log N 直线。
- 【错误签名】轨迹在 **log S–log N 全对数空间**做统一最小二乘线性拟合（Basquin 幂律关系 σ_a = σ_f'·N^b，即对应力幅也取对数），误将教材的 S–log N 半对数图解当成 log–log Basquin 回归——因 S–log N 与 log S–log N 在数据非线性时给出不同斜率/截距，log–log 拟合会系统性偏移反解结果。或轨迹对每个子问分别取紧邻两点做局部插值（无论半对数还是全对数），不同子问用不同点对/斜率。核对特征：轨迹的拟合方程形式为 **log S = a + b·log N** 或等价的 **S = A·N^b**（应力轴也取对数），而非 **S = a + b·log N**（应力线性、仅 N 取对数 = 正确的半对数）；轨迹出现"Basquin fit σ_a = A·N^b""fit over all data points in log-log space"等表述且拟合确在全对数空间。**排除情形**：轨迹虽提及"loglog"一词（如技能名或自述"NOT log-log"），但实际拟合方程为 S = a + b·log N（S 线性、仅 log N），此为正确的 S–log N 半对数方法，**不命中**；须核对方程形式而非仅看措辞。结果：各子问数值与 S–log N 半对数统一拟合给出的结果存在系统偏差（部分子问超出 5% 相对误差）。

### 子情形：焊缝群——轴向加载误用偏心弯曲模型（混淆截面维度与焊缝长度）
- 【正确方法】载荷沿构件长度方向且通过截面形心时，焊缝群受纯轴向剪切（无偏心、无弯曲）。正确做法：按"焊缝群形心落在载荷线上"分配各焊缝长度（平衡设计），再由焊缝 throat 许用剪切定总长。构件的截面维度（如角钢腿宽）是焊缝间距/几何参数，不是焊缝可用长度上限——焊缝沿构件长度方向布置，可用长度由构件长度而非截面维度决定。关键判据：载荷线过形心 → 纯轴向，不产生弯曲；不可将截面维度误当焊缝长度上限而判平衡设计"不可行"并切换到偏心模型。
- 【错误签名】轨迹将构件截面维度（如角钢腿宽）误当焊缝可用长度上限，据此判平衡焊缝长度"超过上限、不可行"，转而采用全长焊缝+偏心弯曲叠加模型反求焊脚。实际上载荷过形心属纯轴向、无弯曲，平衡设计可行。核对特征：轨迹出现"balanced length > 某截面维度 → infeasible"的判断，随后切换到偏心/弯剪叠加模型；或轨迹把截面维度与焊缝长度混用。结果：误用带弯曲偏心判据（本应纯轴向），所得焊脚/焊缝尺寸与纯轴向结果显著偏差。

### 子情形：Regular-solution 稀溶液溶解度——Ω<0 时勿用 |Ω| 伪造 miscibility gap
- 【正确方法】Regular-solution 模型中 B 在 A 中的稀溶液溶解度公式为 x_B=exp(Ω/(RT))（Ω 为有符号交互参数）。当 Ω<0（A-B 交互优于同种对、完全互溶体系）时，不存在 miscibility gap，solvus/binodal 方程在 0<x_B<1 内无解，应直接用稀溶液公式计算。若需检查稀溶液近似的适用性，应确认 x_B 足够小（如 x_B≪1），而非引入"精确 solvus"方程——该方程在 Ω<0 时本就无物理解，解出的任何 x_B<1 根都是数值伪造。
- 【错误签名】轨迹先正确算出稀溶液值 x_B=exp(Ω/(RT))，随后另引入"精确/自洞性 solvus"方程，但把有符号 Ω 换成 |Ω|（或等价地翻转交互项符号），使该方程在 Ω<0 时凭空产生一个 x_B<1 的根——该根是符号翻转伪造的 miscibility gap，物理上不存在。轨迹以"model-validity-range""activity correction""exact solvus""self-consistent"等理由用该伪造根覆盖稀溶液结果。核对特征：轨迹中出现 |Ω| 或等价的交互项符号翻转、且 Ω<0；轨迹引入 solvus/binodal 方程并解出与稀溶液公式显著不同的值；轨迹自述"dilute approximation is X% low"以合理化切换到"精确"值。

### 子情形：X 射线产生——K 发射线能量公式 vs K 吸收边电离阈
- 【正确方法】题目要求"产生 Kα X 射线所需最小加速电压/最小能量"时，入射电子须先电离 K 壳层电子产生空位，最小加速电压等于 K 壳层电子的结合能（K 吸收边 / K-edge），这是**电离阈能**，须查该元素的实验 K-edge 结合能值（查表），不能用发射线能量公式代替。Moseley 定律（E_Kα ≈ 13.6(Z−1)² eV 或类似形式）描述的是 Kα **发射光子能量**（K 壳层与 L 壳层能级差 E_K − E_L），是发射线能量、不是电离阈能——发射线能量 < K-edge（因 L 壳层结合能为正，E_Kα = E_K − E_L < E_K）。关键判据：求"最小加速电压/最小能量产生 Kα X 射线"须用 K 吸收边（K 壳层电离阈能，查实验值），不能用 Kα 发射线能量公式（Moseley 定律）代替。
- 【错误签名】轨迹用 Moseley 定律 13.6(Z−1)² eV（或类似的 Kα 发射能量公式）计算最小加速电压或 K 吸收边，把发射线能量当电离阈能。核对特征：轨迹出现"13.6(Z−1)²""Moseley"等发射线公式用于求最小加速电压/K 吸收边/K-edge；或轨迹算出的电压对应 Kα 光子能量而非 K 壳层结合能（结果系统性偏高，因发射线能量公式给出的值与实验 K-edge 差异显著）；或轨迹将发射线能量与电离阈能混用而未区分二者物理含义。
