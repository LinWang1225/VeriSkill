## 题目
Calculate and compare the maximum magnetization we would expect in iron, nickel, cobalt, and gadolinium. There are seven electrons in the $4 f$ level of gadolinium. Compare the calculated values with the experimentally observed values. Give your answer as a tuple: (Fe_magnetization_Oe, Co_magnetization_Oe).
Give your final answer in units of (Oe, Oe).

## 过程
The maximum (saturation) magnetization is estimated from the **net spin magnetic moment** of each atom, i.e. the number of unpaired electrons × μ_B, distributed over the atomic number density:

$$M_s = N \, n \, \mu_B$$

where N = atoms per unit volume (from crystal structure), n = unpaired-electron count, μ_B = 9.2732×10⁻²⁴ A·m².

**Unpaired electrons (spin-only moment, in μ_B):**
- Fe (3d⁶4s²): 4 unpaired → 4 μ_B
- Co (3d⁷4s²): 3 unpaired → 3 μ_B
- Ni (3d⁸4s²): 2 unpaired → 2 μ_B
- Gd (4f⁷): 7 unpaired → 7 μ_B (half-filled f-shell, L = 0, g_J = 2 ⇒ 7 μ_B)

**Atomic number densities N (atoms/m³):**
- Fe, BCC (a = 0.2866 nm): N = 2/a³ = 8.496×10²⁸
- Co, HCP (a = 0.2507 nm, c = 0.4070 nm), V = (√3/2)a²c: N = 9.028×10²⁸
- Ni, FCC (a = 0.3524 nm): N = 4/a³ = 9.140×10²⁸
- Gd, HCP (a = 0.3636 nm, c = 0.5783 nm): N = 3.021×10²⁸

(Densities check out: Fe 7.88, Co 8.84, Ni 8.91, Gd 7.89 g/cm³ — all correct.)

**Calculated M_s (A/m → Oe via 1 emu/cm³ = 10³ A/m = 1 Oe):**

| Element | M_s calc (A/m) | M_s calc (Oe) | M_s exp (Oe) |
|--------|----------------|---------------|--------------|
| Fe | 3.15×10⁶ | **3151** | 1700 |
| Co | 2.51×10⁶ | **2512** | 1450 |
| Ni | 1.70×10⁶ | 1695 | 510 |
| Gd | 1.96×10⁶ | 1961 | 560 |

The calculated values exceed the experimental ones because the real atomic moments are reduced by orbital coupling/band-structure effects (Fe ≈ 2.22 μ_B, Co ≈ 1.72 μ_B, Ni ≈ 0.60 μ_B instead of 4, 3, 2). Gd is closest to its spin-only value (≈ 7 μ_B) but its room-temperature M_s is low because T_room ≈ T_C(Gd) = 293 K.

## 最终答案
(3151, 2512)
