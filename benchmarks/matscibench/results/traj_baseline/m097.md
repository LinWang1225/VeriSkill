## 题目

## 过程
For the same diffusion result, the product $D t$ must be equal:

$$D(T_1)\,t_1 = D(T_2)\,t_2$$

With $D = D_0\exp\!\left(-\dfrac{Q_d}{RT}\right)$, and the same $D_0$ (C in $\gamma$-Fe) on both sides, $D_0$ cancels. Given $T_1 = 1000+273 = 1273\ \text{K}$, $t_1 = 12\ \text{h}$, $t_2 = 4\ \text{h}$:

$$\exp\!\left(-\frac{Q}{RT_2}\right)\cdot 4 = \exp\!\left(-\frac{Q}{RT_1}\right)\cdot 12$$

$$\Rightarrow \frac{D(T_2)}{D(T_1)} = \frac{12}{4} = 3 \;\Rightarrow\; -\frac{Q}{RT_2} = \ln 3 - \frac{Q}{RT_1}$$

$$\Rightarrow \frac{1}{T_2} = \frac{1}{T_1} - \frac{R}{Q}\ln 3$$

Using $Q_d = 148{,}000\ \text{J/mol}$ (C in $\gamma$-Fe) and $R = 8.31\ \text{J/(mol·K)}$:

$$\frac{1}{T_2} = \frac{1}{1273} - \frac{8.31}{148000}\ln 3$$

$$T_2 \approx 1381.5\ \text{K}$$

## 最终答案
1381
