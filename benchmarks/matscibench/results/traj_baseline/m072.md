## 题目
The unit cell for $\mathrm{Al}_{2} \mathrm{O}_{3}$ has hexagonal symmetry with lattice parameters $a=0.4759 \mathrm{~nm}$ and $c=1.2989 \mathrm{~nm}$. If the density of this material is $3.99 \mathrm{~g} / \mathrm{cm}^{3}$, calculate its atomic packing factor. For this computation use ionic radii listed in  table 3.4 .

## 过程
For a hexagonal unit cell, the volume is

$$V_c = a^2 c \sin 120^\circ = a^2 c \frac{\sqrt{3}}{2}$$

First determine the number of formula units per unit cell from the density:

$$\rho = \frac{nM}{V_c N_A}\;\Rightarrow\; n = \frac{\rho V_c N_A}{M}$$

with $M_{\mathrm{Al_2O_3}} = 2(26.98)+3(16.00)=101.96\ \mathrm{g/mol}$.

Using $a=0.4759\ \mathrm{nm}$, $c=1.2989\ \mathrm{nm}$:

$$V_c = (0.4759)^2(1.2989)\sin120^\circ = 0.25476\ \mathrm{nm^3}$$

$$n = \frac{3.99 \times (0.25476\times10^{-21}\ \mathrm{cm^3}) \times 6.022\times10^{23}}{101.96} \approx 6.0$$

So there are 6 formula units per unit cell (corundum structure).

The atomic packing factor is

$$\mathrm{APF} = \frac{n\left[2\left(\frac{4}{3}\pi r_{\mathrm{Al^{3+}}}^3\right)+3\left(\frac{4}{3}\pi r_{\mathrm{O^{2-}}}^3\right)\right]}{V_c}$$

with $r_{\mathrm{Al^{3+}}}=0.053\ \mathrm{nm}$, $r_{\mathrm{O^{2-}}}=0.140\ \mathrm{nm}$:

$$\mathrm{APF} = \frac{6\left[2\frac{4}{3}\pi(0.053)^3 + 3\frac{4}{3}\pi(0.140)^3\right]}{0.25476} = 0.842$$

## 最终答案
0.842
