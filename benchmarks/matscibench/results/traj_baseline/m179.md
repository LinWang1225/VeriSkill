## 题目
The number of independent slip systems is the same as the number of the strain components, $\varepsilon_1$, $\varepsilon_2$, $\gamma_{23}$, $\gamma_{31}$, $\gamma_{12}$, that can be accommodated by slip. Find the number of independent slip systems in crystals of the NaCl structure that deform by $\langle 110 \rangle \{1 \overline{1} 0\}$ slip.

## 过程
For NaCl deforming by $\langle 110\rangle\{1\overline{1}0\}$ slip, I enumerate the slip systems. The $\{110\}$ family has 6 planes, and each $\{110\}$ plane contains exactly **one** $\langle 110\rangle$ direction lying in it (since a direction $[uvw]\in\langle 110\rangle$ must satisfy $hu+kv+lw=0$). This gives 6 slip systems:

| Slip plane | Slip direction |
|---|---|
| $(1\overline{1}0)$ | $[110]$ |
| $(110)$ | $[1\overline{1}0]$ |
| $(101)$ | $[10\overline{1}]$ |
| $(10\overline{1})$ | $[101]$ |
| $(011)$ | $[01\overline{1}]$ |
| $(01\overline{1})$ | $[011]$ |

Each slip system contributes a plastic strain tensor
$$\varepsilon_{ij}=\tfrac{1}{2}(b_i n_j+b_j n_i),$$
which is symmetric and traceless (since $\mathbf{b}\perp\mathbf{n}$), so it has 5 independent components $(\varepsilon_{11},\varepsilon_{22},\varepsilon_{12},\varepsilon_{13},\varepsilon_{23})$. Stacking the 6 slip systems gives a $6\times 5$ matrix. The number of independent slip systems equals the rank of this matrix.

Computing numerically (with unit $\mathbf{b},\mathbf{n}$), the matrix is
$$
\begin{pmatrix}
0.5&-0.5&0&0&0\\
0.5&-0.5&0&0&0\\
0.5&0&0&0&0\\
0.5&0&0&0&0\\
0&0.5&0&0&0\\
0&0.5&0&0&0
\end{pmatrix}
$$
with singular values $(1.225,\ 0.707,\ 0,\ 0,\ 0)$. Only **2** are nonzero, so $\operatorname{rank}=2$.

This is the classic result: $\{110\}\langle110\rangle$ slip in rock salt provides only 2 independent slip systems — far fewer than the 5 required by the von Mises criterion, which is why NaCl is brittle.

## 最终答案
2
