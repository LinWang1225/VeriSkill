## 题目
A cylindrical specimen of stainless steel having a diameter of 12.8 mm ( 0.505 in.) and a gauge length of 50.800 mm (2.000 in.) is pulled in tension. Use the load-elongation characteristics shown in the following table. Compute the modulus of resilience.

| N | $l b{f}$ | mm | in. |
| 0 | 0 | 50.800 | 2.000 |
| 12,700 | 2,850 | 50.825 | 2.001 |
| 25,400 | 5,710 | 50.851 | 2.002 |
| 38,100 | 8,560 | 50.876 | 2.003 |
| 50,800 | 11,400 | 50.902 | 2.004 |
| 76,200 | 17,100 | 50.952 | 2.006 |
| 89,100 | 20,000 | 51.003 | 2.008 |
| 92,700 | 20,800 | 51.054 | 2.010 |
| 102,500 | 23,000 | 51.181 | 2.015 |
| 107,800 | 24,200 | 51.308 | 2.020 |
| 119,400 | 26,800 | 51.562 | 2.030 |
| 128,300 | 28,800 | 51.816 | 2.040 |
| 149,700 | 33,650 | 52.832 | 2.080 |
| 159,000 | 35,750 | 53.848 | 2.120 |
| 160,400 | 36,000 | 54.356 | 2.140 |

| 124,700 | 28,000 | 56.642 | 2.230 |
|  |  |  |  |
Give your final answer in units of J/m^3.

## 过程
The modulus of resilience is the area under the elastic (linear) portion of the engineering stress–strain curve:

$$U_r = \tfrac{1}{2}\sigma_y \varepsilon_y = \frac{\sigma_y^2}{2E}$$

**Geometry**
- $d_0 = 12.8\text{ mm}$, $l_0 = 50.800\text{ mm}$
- $A_0 = \pi(6.4\times10^{-3})^2 = 1.2868\times10^{-4}\text{ m}^2$

**Identify the proportional limit.** Computing the slope between consecutive data points (N per mm elongation), the slope is essentially constant at ≈ $5.0\times10^{5}$ N/mm through the point (76,200 N, 50.952 mm), then drops to ≈ $2.5\times10^{5}$ N/mm for the next segment. Hence the elastic limit is the last linear point:

- $F_y = 76{,}200\text{ N}$, $l_y = 50.952\text{ mm}$

**Yield stress and strain**
- $\sigma_y = F_y/A_0 = 76200 / 1.2868\times10^{-4} = 5.922\times10^{8}\text{ Pa} = 592.2\text{ MPa}$
- $\varepsilon_y = (l_y-l_0)/l_0 = 0.152/50.800 = 0.002992$

**Elastic modulus** (from the linear region, points 0–5): $E \approx 197.5\text{ GPa}$ (consistent with $\sigma_y/\varepsilon_y = 197.9\text{ GPa}$).

**Modulus of resilience** (triangular area under the elastic curve):

$$U_r = \tfrac{1}{2}\sigma_y\varepsilon_y = \tfrac{1}{2}(5.922\times10^{8})(0.002992) \approx 8.86\times10^{5}\text{ J/m}^3$$

Numeric evaluation via Python gives $8.86\times10^{5}\text{ J/m}^3$ (using $\sigma_y^2/2E$ gives $8.88\times10^{5}$; the direct triangular area $0.5\sigma_y\varepsilon_y = 8.86\times10^{5}$).

## 最终答案
8.86e5
