## 题目
A steel sheet that has an $R$ value of 1.75 in all directions in the sheet was stretched in biaxial tension with $\sigma_z = 0$. Strain measurements indicate that throughout the deformation, $\varepsilon_y = 0$. Find the stress ratio, $\alpha = \sigma_y / \sigma_x$, that prevailed according to the Hill yield criterion and with the nonquadratic yield criterion with $a = 8$.

## 过程
The sheet has **normal anisotropy** (R = 1.75 in all directions), so a single R characterizes it. With σ_z = 0 (plane stress) and the constraint ε_y = 0, the associated flow rule requires ∂f/∂σ_y = 0.

**Hill (quadratic) criterion.** For normal anisotropy the plane-stress yield function is

$$f = \sigma_x^2 + \sigma_y^2 - \frac{2R}{1+R}\sigma_x\sigma_y$$

Flow rule: dε_y ∝ ∂f/∂σ_y = 2σ_y − [2R/(1+R)]σ_x = 0, giving

$$\alpha = \frac{\sigma_y}{\sigma_x} = \frac{R}{1+R} = \frac{1.75}{2.75} = 0.6364$$

**Nonquadratic (Hosford) criterion, a = 8.** The yield function is

$$F = |\sigma_x-\sigma_y|^{a} + R|\sigma_x|^{a} + R|\sigma_y|^{a}$$

With σ_x > σ_y > 0, ∂F/∂σ_y = −a(σ_x−σ_y)^{a−1} + aR σ_y^{a−1} = 0, so

$$\sigma_x - \sigma_y = R^{1/(a-1)}\sigma_y \;\Rightarrow\; \alpha = \frac{1}{1+R^{1/(a-1)}} = \frac{1}{1+1.75^{1/7}} = 0.4800$$

## 最终答案
Hill: α = 0.6364; nonquadratic (a = 8): α = 0.4800
