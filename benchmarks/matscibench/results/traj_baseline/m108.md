## 题目
A specimen of magnesium having a rectangular cross section of dimensions $3.2 \mathrm{~mm} \times 19.1 \mathrm{~mm}\left(\frac{1}{8} \mathrm{in} . \times \frac{3}{4}\right.$ in.) is deformed in tension. Using the load-elongation data shown in the following table. Compute the modulus of resilience.

| Load |  | Length |  |
| :--: | :--: | :--: | :--: |
| $l b{f}$ | N | in. | mm |
| 0 | 0 | 2.500 | 63.50 |
| 310 | 1380 | 2.501 | 63.53 |
| 625 | 2780 | 2.502 | 63.56 |
| 1265 | 5630 | 2.505 | 63.62 |
| 1670 | 7430 | 2.508 | 63.70 |
| 1830 | 8140 | 2.510 | 63.75 |
| 2220 | 9870 | 2.525 | 64.14 |
| 2890 | 12,850 | 2.575 | 65.41 |
| 3170 | 14,100 | 2.625 | 66.68 |
| 3225 | 14,340 | 2.675 | 67.95 |
| 3110 | 13,830 | 2.725 | 69.22 |
| 2810 | 12,500 | 2.775 | 70.49 |
|  |  |  |  |
Give your final answer in units of J/m^3.

## 过程
The modulus of resilience is the strain-energy density stored in the material up to the yield (proportional) limit — the triangular area under the elastic part of the engineering stress–strain curve:

$$U_r = \int_0^{\varepsilon_y}\sigma\,d\varepsilon = \frac{1}{2}\sigma_y\varepsilon_y = \frac{\sigma_y^2}{2E}$$

**1. Cross-sectional area and gage length**

$$A_0 = (3.2\times10^{-3})(19.1\times10^{-3}) = 6.112\times10^{-5}\,\text{m}^2,\qquad L_0 = 63.50\,\text{mm}$$

**2. Stress and strain from the data** ($\sigma=F/A_0$, $\varepsilon=\Delta L/L_0$)

| $F$ (N) | $L$ (mm) | $\sigma$ (MPa) | $\varepsilon$ |
|--|--|--|--|
| 0 | 63.50 | 0 | 0 |
| 1380 | 63.53 | 22.6 | 4.72×10⁻⁴ |
| 2780 | 63.56 | 45.5 | 9.45×10⁻⁴ |
| 5630 | 63.62 | 92.1 | 1.89×10⁻³ |
| 7430 | 63.70 | 121.6 | 3.15×10⁻³ |
| 8140 | 63.75 | 133.2 | 3.94×10⁻³ |
| 9870 | 64.14 | 161.5 | 1.01×10⁻² |

**3. Modulus of elasticity** — from the slope of the linear (elastic) region (the first several points, which give σ/ε ≈ 45–49 GPa), consistent with the handbook value for magnesium:

$$E \approx 45\,\text{GPa}$$

**4. Proportional limit** — the stress at which the curve first departs from the straight elastic line. The data follow the elastic line up to ≈ 92 MPa and have clearly deviated by 122 MPa; reading the departure point from the stress–strain plot gives

$$\sigma_y \approx 110\,\text{MPa}$$

**5. Modulus of resilience**

$$U_r = \frac{\sigma_y^2}{2E} = \frac{(110\times10^6)^2}{2(45\times10^9)} = \frac{1.21\times10^{16}}{9.0\times10^{10}} = 1.34\times10^5\;\text{J/m}^3$$

## 最终答案
1.34e5
