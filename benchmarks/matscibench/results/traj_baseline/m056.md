## 题目
Given that the mobility of electrons in copper is $32 \mathrm{~cm}^{2} / \mathrm{V} \cdot \mathrm{s}$ and conductivity σ=5.97×10^5 S/cm. What is the number of conduction electrons contributed per Cu atom?

Reference: $\begin{gathered}\rho=8.96 \mathrm{~g} / \mathrm{cm}^3=8960 \mathrm{~kg} / \mathrm{m}^3, \quad M=63.546 \mathrm{~g} / \mathrm{mol}=63.546 \times 10^{-3} \mathrm{~kg} / \mathrm{mol} \\ N_{\mathrm{A}}=6.022 \times 10^{23} \text { atoms } / \mathrm{mol}\end{gathered}$
Note: No supplementary information needed.

## 过程
Conductivity relates to conduction electron density by $\sigma = n e \mu$, so the conduction electron density is

$$n = \frac{\sigma}{e\mu} = \frac{5.97\times10^{5}}{(1.602\times10^{-19})(32)} = 1.1646\times10^{23}\ \text{electrons/cm}^3$$

The number of Cu atoms per cm³ is

$$N = \frac{\rho N_A}{M} = \frac{(8.96)(6.022\times10^{23})}{63.546} = 8.491\times10^{22}\ \text{atoms/cm}^3$$

Conduction electrons contributed per Cu atom:

$$z = \frac{n}{N} = \frac{1.1646\times10^{23}}{8.491\times10^{22}} \approx 1.372$$

## 最终答案
1.37
