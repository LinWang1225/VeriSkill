## 题目
The following table gives a number of yield strength values (in MPa) that were measured on the same aluminum alloy. Compute average and standard deviation yield strength values.

| 274.3 | 277.1 | 263.8 |
| :-- | :-- | :-- |
| 267.5 | 258.6 | 271.2 |
| 255.4 | 266.9 | 257.6 |
| 270.8 | 260.1 | 264.3 |
| 261.7 | 279.4 | 260.5 |

 Give your name as a tuple (mean, average).
Give your final answer in units of (MPa, MPa).

## 过程
The 15 measured yield-strength values (MPa) are:

274.3, 277.1, 263.8, 267.5, 258.6, 271.2, 255.4, 266.9, 257.6, 270.8, 260.1, 264.3, 261.7, 279.4, 260.5

**Mean:**
$$\bar{x}=\frac{1}{N}\sum_{i=1}^{N}x_i=\frac{3989.2}{15}=265.947\ \text{MPa}$$

**Standard deviation** (using the sample estimator with $N-1$ in the denominator, as is standard for a set of measurements drawn from a population):
$$s=\sqrt{\frac{1}{N-1}\sum_{i=1}^{N}(x_i-\bar{x})^2}=\sqrt{\frac{1}{14}\sum(x_i-265.947)^2}=7.337\ \text{MPa}$$

Numeric evaluation via Python confirms: mean = 265.9467 MPa, sample standard deviation = 7.3374 MPa.

## 最终答案
(265.95, 7.34)
