## 题目
For a BCC iron-carbon alloy that contains $0.1 \mathrm{wt} \% C$, calculate the fraction of unit cells that contain carbon atoms.
$A_{\mathrm{C}}=12.011 \mathrm{~g} / \mathrm{mol}$
$A_{\mathrm{Fe}}=55.85 \mathrm{~g} / \mathrm{mol}$
$\varrho_{\mathrm{C}}=2.25 \mathrm{~g} / \mathrm{cm}^3$ 
$\varrho_{\mathrm{Fe}}=7.87 \mathrm{~g} / \mathrm{cm}^3$
Give your final answer in units of atoms/unit cell.

## 过程
For a BCC Fe–C alloy, each unit cell contains 2 Fe atoms. The fraction of unit cells containing a carbon atom equals the number of C atoms per unit cell (valid at this low concentration, where multiple C atoms in one cell is negligible).

1. **Alloy density** (rule of mixtures):
$$\frac{1}{\rho}=\frac{w_C}{\rho_C}+\frac{w_{Fe}}{\rho_{Fe}}=\frac{0.001}{2.25}+\frac{0.999}{7.87}\Rightarrow \rho\approx 7.850\ \mathrm{g/cm^3}$$

2. **Carbon atoms per cm³**:
$$n_C=\frac{w_C\rho}{A_C}N_A=\frac{0.001\times 7.850}{12.011}(6.022\times10^{23})\approx 3.936\times10^{20}$$

3. **Iron atoms per cm³**, then unit cells per cm³ (BCC, 2 atoms/cell):
$$n_{Fe}=\frac{w_{Fe}\rho}{A_{Fe}}N_A\approx 8.456\times10^{22},\qquad n_{cell}=\frac{n_{Fe}}{2}\approx 4.228\times10^{22}$$

4. **Fraction**:
$$\frac{n_C}{n_{cell}}=\frac{3.936\times10^{20}}{4.228\times10^{22}}\approx 9.31\times10^{-3}$$

## 最终答案
9.31e-3
